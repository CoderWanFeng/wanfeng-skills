# 写作规范详解

本文是 SKILL.md 第 2–3 步的展开，面向中文 AI 科普类长文（公众号、知乎专栏）。

---

## 一、定位与语气

**目标读者**：对 AI 感兴趣的普通人，不是程序员。

**五大原则**：

1. 内容价值优先——读完能直接用
2. 绝对零门槛——不用代码、编程术语、行业黑话
3. 信任优先——不制造焦虑、不割韭菜、帮读者避坑
4. 聚焦不发散——严格围绕 AI / 科技主线
5. 阅读友好——适配手机长文阅读习惯

**语气公式**：像朋友聊天，不像论文，也不像新闻稿。

---

## 二、标题写作

### 硬指标

- 长度 15–32 字（硬上限 36 字）
- 必须出现具体对象（产品名、大厂名、价格、数字）
- 必须有情绪或悬念

### 五种高点击模板

| 类型 | 模板 | 示例 |
|------|------|------|
| 数字冲击 | X 变成 Y | `Copilot涨价26倍，AI免费时代结束了` |
| 反常识 | 明明A，为什么B | `明明是国产AI，为什么反而不懂中文` |
| 个人体验 | 我用了X天 | `我用Codex一周，发现它最意外的不是写代码` |
| 避坑提醒 | 别急着X，先看Y | `别急着买AI电脑，先看这3个问题` |
| 结果导向 | 用X做Y，结果Z | `AI编码太贵？开源神器token直降95%` |

### 禁忌

- 空泛：`AI趋势分析`
- 虚假夸张：`最强` `全球第一`
- 太长（>36字手机显示不完整）
- 太专业（普通读者看不懂）

---

## 三、正文结构

### 四段式

```
[1] 标题
[2] 开头钩子（80-150字）：事件 + 情绪 + 核心问题
[3] 主体内容（1200-1800字）：最多3个 ## 小节，语义递进
[4] 结尾（150-250字）：升华 + 互动 + Slogan + 参考链接 + 相关阅读
```

### AI 知识段（必含）

每篇至少一段讲透一个 AI 原理，公式：

```
热点现象 → 但你知道为什么吗？→ 原理（大白话）→ 所以你会看到 → 回到现实
```

### 开头禁止

- `随着人工智能技术的发展……`
- `近年来，AI 逐渐进入大众视野……`
- `本文将从三个方面分析……`

### 小标题要求

- 必须像判断，不像论文目录
- ✅ `真正贵的不是价格` / ❌ `背景介绍`
- 禁止 `晚枫点评` `总结` `我的看法`

---

## 四、排版铁律

1. 每段 ≤ 3 行
2. 章节间用 `---` 分隔
3. `##` 章节 + `###` 子标题，不跳级
4. 核心观点/数据/金句用 `**加粗**`（每段不超 2 处）
5. 3 个以上并列项用列表
6. 有对比关系用表格
7. 图片放在它解释的文字之后，下方斜体标注来源

---

## 五、Frontmatter 格式

```yaml
---
title: 文章标题（与正文主标题一致）
date: YYYY-MM-DD HH:MM:SS（与当前系统时间一致）
tags: [公众号文章, 具体标签1, 具体标签2]
categories: [公众号文章]
cover: 已验证可访问的图片URL
---
```

- `tags` 第一个固定 `公众号文章`
- `cover` 必须有值且 URL 可访问
- YAML 中能用引号就用，遇到 `:` `,` `#` 等特殊字符必须加引号

---

## 六、结尾固定结构

按顺序：

1. 升华式总结（一句话戳透核心，不列 123）
2. 互动提问（具体，不是"大家怎么看"）
3. 固定 Slogan：
   ```
   **科技不高冷，AI很好用。**
   我是晚枫，关注我，带你一起玩AI！
   ```
4. `### 参考链接`（≥ 3 条官方/权威来源）
5. `## 相关阅读`（2–4 篇相关公众号文章）
6. 正文底部引导图（单独一行）

---

## 七、链接格式

**非微信链接**统一写：

```markdown
[标题：完整URL](完整URL)
```

中括号里必须带完整 URL，原因：公众号编辑器对超链接保留不稳定，读者复制正文就能拿到链接。

**三个例外**：

| 类型 | 写法 |
|------|------|
| 微信链接 | `[标题](https://mp.weixin.qq.com/s/xxx)` 不重复 URL |
| 图片 | `![alt](URL)` alt 里不写 URL |
| 代码块内链接 | 给读者复制执行的命令，不加标题 |

---

## 八、真实感要求

每篇至少 2 处来自亲身体验的表述：

- "我最近实际用了……"
- "有读者/群友问我……"
- "我试着让它做了三件事……"
- "最让我意外的是……"

**不要写成公关稿。**

---

## 九、黑色幽默

每篇至少 1 处，公式：`具体嘲讽对象 + 反差感 + 一句话点到为止`

只嘲讽行为和现象，绝不嘲讽具体的人。
