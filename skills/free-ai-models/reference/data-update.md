# 数据更新机制

> **目的**：保证 `reference/*.md` 里的「免费大模型」数据**始终新鲜**，避免误导用户。

---

## 核心原则

1. **本地优先**：用户问的问题，本地 30 天内的数据 → 直接答（速度第一）
2. **WebFetch 兜底**：本地没有 / 超过 30 天 / 用户主动质疑 → 主动联网查
3. **更新带日期**：任何数据点必须标"截至 YYYY-MM-DD"
4. **不污染本地**：抓回来的信息必须可信源（官方页）才写入

---

## 数据生命周期

```
┌─────────────────────────────────────────────────────┐
│ 数据写入 reference/*.md（带 data_date）             │
└─────────────────────────────────────────────────────┘
                     ↓
              距今 < 30 天？
                     ↓
            ┌────────┴────────┐
            ↓                 ↓
        ✅ Yes             ❌ No
       直接用            WebFetch 重抓
            ↓                 ↓
            └────────┬────────┘
                     ↓
              抓到 → 更新 data_date
              抓不到 → 提示用户"数据可能已变化"
```

---

## WebFetch 触发条件（满足任一即触发）

1. **本地缺失**：用户问的模型/平台在 `reference/*.md` 里完全没有
2. **数据陈旧**：本地记录的 `data_date` 距今 > 30 天
3. **用户质疑**：用户说"现在还免费吗""额度变了吗"
4. **活动过期**：本地记录的"活动/截止时间"已过期
5. **重大变化**：平台官方公告了重大调整（如 Anthropic 取消 Pro 试用）

---

## WebFetch 执行流程

### Step 1：定位官方源

```bash
# 优先用以下顺序找 URL
# 1) 本地 reference/*.md 里已经记录的 URL
# 2) 模型/平台官网（domain + /pricing）
# 3) 模型/平台官方文档

# 例：查 DeepSeek 免费额度
URL="https://platform.deepseek.com/api-docs/pricing"

# 例：查 Gemini 免费额度
URL="https://ai.google.dev/gemini-api/docs/rate-limits"

# 例：查 Cursor 免费模型
URL="https://cursor.com/pricing"
```

### Step 2：抓取页面

```bash
# 用 WebFetch 工具
WebFetch "$URL"  # 抓回来返回 markdown 格式内容
```

**抓取关键词过滤**（提高信噪比）：

| 类别 | 关键词 |
|---|---|
| 免费 | `free`, `free tier`, `免费`, `限额`, `quota`, `rate limit`, `RPM`, `RPD`, `TPM` |
| 额度 | `200 million tokens`, `200 万 token`, `tokens per day` |
| 限制 | `limit`, `limited`, `限制`, `最多` |
| 截止 | `until`, `expire`, `截止`, `过期` |

### Step 3：判断结果

| 抓取结果 | 行动 |
|---|---|
| 找到"仍免费"明确字样 | 更新本地 + 标新日期 |
| 找到"已转付费"明确字样 | 修改本地 + 标"⚠️ 活动已结束" |
| 找到"免费但有变更"（额度变了） | 更新本地 + 标"⚠️ 额度有变化" |
| 页面找不到关键信息 | 提示用户"页面结构变了，请人工确认" |
| 抓取失败（超时/403） | 见下方"WebFetch 失败兜底" |

### Step 4：更新本地

```markdown
| 平台 | 模型 | 免费额度 | 申请方式 | 数据日期 |
|---|---|---|---|---|
| DeepSeek | V3 | 注册送 200 万 token（一次性）| 手机号 | 2026-07-12（WebFetch 重抓）|
```

**更新规范**：
- 整张表加列 `数据日期` 或在表头加 `（数据日期：YYYY-MM-DD）`
- 修改条目时保留**原条目**到 changelog（防止数据丢失）

---

## WebFetch 失败兜底

| 失败情况 | 兜底话术 | 后续 |
|---|---|---|
| 抓取超时 | "网络抽风了，{本地数据} 上次更新是 {date}，要不要我过会儿再试？" | 让用户决定 |
| 反爬 / 403 | "官方页有反爬，建议你直接打开 {URL} 看，我基于本地数据 {date} 给你答" | 不更新本地 |
| 抓到但结构变了 | "页面结构变了，没法准确判断，你打开 {URL} 确认下？" | 不更新本地 |
| 找不到官方源 | "找不到官方源，先告诉你本地数据 {date}，等你确认" | 暂不更新 |

## 不抓的原则

> **避免污染本地数据 + 节省 AI token**

- ❌ 不抓论坛（Reddit / V2EX / 知乎 / 即刻）
- ❌ 不抓非官方汇总站（"AI 导航网"之类）
- ❌ 不抓需要登录的页面
- ❌ 不抓 Twitter / X 推文（除非是官方账号）
- ❌ 不抓 GitHub Issue 评论区（观点不可信）

✅ **只抓**：
- 模型平台官方 Pricing 页
- 模型平台官方控制台文档
- 软件官方 Pricing 页
- 软件官方 changelog
- 软件官方 README

## 月度维护流程（每月 1 号）

> 建议给本 skill 加一个 cron / 提醒，每月 1 号跑一次全量 WebFetch。

```bash
# 伪代码：每月 1 号
for URL in $(grep -oE 'https?://[^ )]+' reference/*.md | sort -u); do
  echo "===== $URL ====="
  WebFetch "$URL"
  # AI 自己判断是否需要更新本地
done
```

**优先级**（按数据变化频率）：

| 优先级 | 类别 | 原因 |
|---|---|---|
| 🔴 高 | 平台免费额度 | 平台最爱调"免费层" |
| 🔴 高 | 软件定价 | Cursor/Cline 经常调 |
| 🟡 中 | 直接免费用清单 | 相对稳定，但 GPT/Claude 经常动 |
| 🟢 低 | 本地模型 | Ollama/LM Studio 几乎不变 |

## 数据准确性自检清单

> AI 每次回答用户前，先用这个清单自检：

- [ ] 提到的每个数字（200 万 token / 60 RPM）都标了来源日期
- [ ] 没把"新用户免费"说成"永久免费"
- [ ] 没把"限时活动"说成"长期活动"
- [ ] 海外产品标了"需海外网络"或"需海外卡"
- [ ] 国内产品标了"国内可用"或"国内受限"
- [ ] 模型名精确（"GLM-4-Flash"不是"GLM"）
- [ ] 引用的 URL 都在 `reference/*.md` 里能找到

## 数据备份与回滚

- **每次更新**：保留上一版本到 `reference/changelog/YYYYMMDD-{slug}.md`
- **回滚方式**：`git checkout reference/direct-free.md`（前提是本 skill 在 git 里）
- **彻底重置**：删除 `reference/changelog/` 外的所有文件，按初始快照恢复

---

## 关键提醒

1. **数据 30 天有效**——超过必须重抓
2. **官方页是唯一可信源**——不抓论坛不抓二手汇总
3. **抓不到就说抓不到**——不要硬编数字
4. **用户主动问就重抓**——别偷懒
5. **国内平台"免费"变化慢**——海外平台"免费"变化快（按这个优先级维护）
