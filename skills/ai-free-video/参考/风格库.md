# 风格库

8 种已验证可用的 MG 风格。每种都有完整可跑的渲染器，在 `模板/风格库/` 下。

**所有风格共同规格**：1080×1920 / 30fps / H.264 / yuv420p / 无音轨 / 24–25 秒 / 9 个场景。

## H · 工笔重彩画风

**渲染器**：`模板/风格库/MG样片-工笔画/build_mg_gongbi.py`

| 项 | 值 |
|---|---|
| 底色 | `#F2EAD8` 绢本米黄 + 3px 细横纹 + 做旧压暗 + 石青/赭石云气 |
| 石青 | `#1E5698` / 淡青 `#9EC8E4` |
| 石绿 | `#22805C` / 淡绿 `#A6D8BA` |
| 朱砂 | `#CA3424` / 淡朱 `#F8A894` |
| 赭石 | `#985A28` / 淡赭 `#E6BE90` |
| 藤黄/描金 | `#D8A41E` / `#FADC8A` |
| 胭脂 | `#B0284E` |
| 正文 | `#3A332C` 浓墨 / `#786C5C` 淡墨 |
| 字体 | 标题 Songti SC（index=1 粗），小字 Hiragino Sans GB W6 |

**动效语汇**：三矾九染（`wash()` 每遍画在透明胶子上再合成，`prog` 控制染了几遍，颜色由淡到浓长出来）、游丝描勾线（`outline_rect` 四条边按顺序长出 + 极轻笔锋抖动）、描金线、**落印**（朱砂印从 1.34 倍压到 1.0 + 回正，印面边缘磕碰不规则）、**朱笔圈点**（`corner_brackets` 只画四角括号）、折枝花叶、花瓣飘落、竖排落款。

**截图处理**：用**亮版**证据图，降饱和 0.82 + 罩 7% 绢色，再装裱成立轴（上下石青绫边 + 描金轴杆），让截图"入画"。

**气质**：雅致、重彩、辨识度最高，一眼记得住。

**适合**：国潮/文化调性、系列封面、要和其他账号拉开差距的时候。

**注意**：
- **不是水墨写意**。矿物颜料必须染到看得见：`wash()` 的 `depth` 默认 0.85，色卡用饱和值而不是淡色；淡色只用于大面积底。
- `ImageDraw.Draw(im, "RGBA")` 是**把 RGBA 值写进去**，不是混合。在它上面再画半透明会把已画的色整片擦掉——所有叠色必须走 `wash()` 的"胶子 + alpha_composite"路径。
- 标题用宋体，但小字必须换回黑体，宋体 30px 以下在视频里会糊。
- 证据图上标重点只能用圈点，不能涂色块——涂了就把截图盖死。

## 风格选择速查

| 情况 | 选 |
|---|---|
| 要讲价格、参数、模型对比 | A / D |
| 要讲怎么用、给泛用户 | B / F / G |
| 要把复杂原理讲简单 | G |
| 要做系列、要有辨识度 | C / H |
| 要吸睛、封面 | D / E |
| 要年轻化、破圈 | E |
| 要国潮调性、和文化内容搭 | H |
| 账号调性还没立起来 | C 或 E |
| 账号要做专业人设 | A |

**组合拳**：D/E 做钩子（0–3s）+ A/B 做正文（3s 后），最后 2s 回到 E 的 CLEAR 画面收尾。
G/H 是强风格，一旦选了建议整片统一，不要和其他风格拼。

## 改风格的最小改动

每个渲染器的结构一致，改这几处即可换皮：

1. **顶部色卡常量**（`BG` / `CARD` / `ACCENT` / `INK` 等）
2. **字体路径 + index**（`F7` / `F3` / `F7_IDX` / `F3_IDX`）
3. **`load_shot()` 的调色参数**（亮度/饱和/反相）
4. **`build_scenes()` 里的场景定义**

字体可用：

| 字体 | 路径 | index |
|---|---|---|
| Hiragino Sans GB | `/System/Library/Fonts/Hiragino Sans GB.ttc` | 0=W3, 2=W6 |
| Songti SC | `/System/Library/Fonts/Supplemental/Songti.ttc` | 1=Bold, 6=Regular |
| 腾讯 Sans | `/Users/wanfeng/Library/Fonts/TencentSans-W7.ttf` | — |

## 新增风格时的两条硬约定

1. **`card()` 一律返回 pad=0 并调 `set_content_offset(im, 0, 0)`**。带阴影 padding 的风格（F）会让重叠检测坐标和肉眼位置差一个 pad，报告不可信。
2. **半透明叠色不要直接 `ImageDraw.Draw(layer, "RGBA")` 画在有内容的层上**——Pillow 是写入而非混合，会把已绘内容擦掉。要么画在透明胶子上再 `alpha_composite`（见 H 的 `wash()`），要么先铺不透明底再罩染。
