# 动画优先 · 两阶段成片（animation-first.md）

> **这是 mograph-pro 的一条支线，不是替代主线。** 主线是「Step 0 + 八步 A–H 一次出成片」（见 `wanfeng-path.md` §2）；
> 本支线用于**用户已剪好成片 + 自带 SRT、要求先看动画效果、且对「画面不能停」有硬要求**的场景。
> 首次实证：72 号「AI 全流程做视频」，131.494s / 1080×1920@30 / 83 句 SRT / 16 核心分镜 + 8 过渡段。
>
> **一句话**：先把动画层做成一条能播的 Demo 给用户确认，确认后再叠真人层、接声音、做封面和发布包。
> 顺序不能倒 —— 用户明确说过「先做动画效果，先不要去加人那个头像，我确认了，然后再往下做」。
> **画幅同样遵守主线的宽屏选择（W25 / `aspect-ratio.md` §1）**：Demo 排版前确认一次，不重复问已指定的画幅；
> 按已选画幅分别使用 `CANVAS` 出静帧及 Demo —— **别等阶段 ② 才补问画幅**，
> 否则纯动画 Demo 的静帧复核全白做。横版 Demo 走左右分栏骨架，禁止拉伸竖版帧。

---

## 0. 什么时候走这条线（入口判定）

三个条件**任一成立**就走本支线，并把本文件作为执行依据；都不成立则走主线 Step A–H。

| 信号 | 判定 | 动作 |
|---|---|---|
| 用户给的是**已删减成片 + 现成 SRT** | 主线 Step 0 删减会破坏 SRT 对齐 | **跳过 Step 0**，不跑 `cut_plan.py`，不重新识别字幕，原片 + 原 SRT 恒等映射 |
| 用户说「先做动画 / 先别加人 / 我确认了再往下」 | 需要先看效果再定 | 进入**两阶段**：① 纯动画 Demo → 用户确认 → ② 真人层 + 声音 + 封面 + 发布包 |
| 用户说「画面停太久 / 都要是动画 / 不能超过 3 秒」 | 主线入场动效不满足 | 执行 §4 全片节拍化 + §5 数据验证 |

**忽略旧素材**：用户说「忽略之前的素材，直接基于我提供的这个原始素材」时，旧目录（`01-script/`、`02-assets/`、`digital-human/`、`IMG_2524.MOV` 等）一律不读、不引用。
只认用户本次点名的文件；文件名变了（如 `xxx-2.mov/.srt`）要**重新 ffprobe 探测**画幅、帧率、时长、音轨、SRT 条数，不沿用旧探测结果。

## 1. 两阶段总流程（阶段闸是硬约束）

```
阶段 ①  纯动画 Demo（本支线核心，用户确认之前不许越过）
  1.0 素材判定与重探测        → 成片+SRT 恒等映射；忽略旧素材；缺截图一次性问用户
  1.1 口播拆镜               → 逐句标锚点、归意图、查基元、抽参数（semantic-to-effect.md S1–S5 / W24），
                                定 16 核心分镜 + 过渡段；产出逐句对照表，参数不写死
  1.2 分镜→参考项目映射      → 每个分镜挂一个参考风格，先核实许可证，结论落盘
  1.3 逐帧自绘动画           → 每个动画都有「过程」，禁止整块淡入冒充
  1.4 全片节拍化             → 任一单一画面 ≤3s，看清就切，快慢有区分
  1.5 数据验证               → 帧差/单拍时长/连续静止段三项全过才进静帧复核
  1.6 交付 Demo              → 静帧联络表 + 过程总览 + 可播预览 MP4，等用户确认
──────────────────── 用户明确确认后，才进入阶段 ② ────────────────────
阶段 ②  真人层 / 声音 / 封面 / 发布包
  2.1 圆形真人头             → 从当前原片帧实时裁脸；开场即展示；场景级位置参数
  2.2 图层顺序与遮挡避让     → 氛围层在内容之前；圆头不被任何元素压住
  2.3 接声音                 → 抽原片真人真声 loudnorm 归一 + 程序化分镜音效 + 氛围垫
  2.4 封面（Step H / W12）   → 固定底图换字换 logo，人像不动；文案要点题
  2.5 发布包                 → 放选题根；横版成品另进横版视频子目录，交接文档留工程
```

> **阶段闸**：阶段 ① 未获用户确认，不许做阶段 ② 的任何一项，尤其不许提前叠真人头、不许提前出「成片」口径。
> 用户曾在确认前就问「封面呢 / 生成发布包了吗」，正确回应是「这一版 Demo 还没做，等确认后按 Step H 补」，不要为了凑齐交付物越过闸。

## 2. 阶段 ① · 纯动画 Demo

### 2.1 素材与字幕：恒等映射

- 成片时长与 SRT 必须**逐句对齐**（72 号：131.494s / 83 句）。
- 用户已提供识别好的 SRT → **不重新识别**；已删减 → **不再删减**。删减会整体偏移，字幕与画面全部错位。
- 时间轴 = 成片时间轴，直接按 SRT 起止切场景，不做 `map_t()` 变换、不做语速调整。
- 需要额外截图时，**一次性列清要哪几张**（如「干净软件界面」「后台真实数据」），让用户去截；不自己编造数据。

### 2.2 分镜 → 参考项目映射（许可证是硬门槛）

用户要求「做动画时参考文档里那些项目，每个分镜找一个合适的参考」时：

1. 先按口播抠出**点名「动画/特效」**的分镜（时间区间 + 关键词），列成映射表；
2. 逐个核实参考项目**开源协议**：必须 **免费商用 + 可二次开发 + 可闭源**；
   用 GitHub API `license.spdx_id` 逐个确认，不接受 README 自述；
3. **研究结论落盘**到项目内私有研究目录（文件名如 `code-first-skills-animation-refs.md`，**不随 Skill 分发**），再继续做视频；
4. 只借**风格名称、运动语言、方法论**，用 Python + Pillow + ffmpeg **从头逐帧自绘**；
   不复制源码、不引入素材/字体/音频/依赖 —— 思想与风格不受著作权保护，代码才受。

首次核实的 5 个项目（2026-11-20，全部通过）：

| 项目 | SPDX | 借用点 |
|---|---|---|
| Huashu Motion | MIT | 卡点转场、景深推拉、hero 收束 |
| MG Styles 15 | MIT | 综艺花字、Bauhaus 节拍柱、HUD/FUI 锁定框、等距结构、风格画廊 |
| Animate | MIT | math 数字滚动、坐标变量、storyboard |
| Anidoodle | Apache-2.0 | 一笔自动描绘 |
| Impeccable | Apache-2.0 | 配色/排版质检 |

> **风险边界**：许可管的是源码，仓库内第三方素材另有一套条款（GSAP Standard、SIL OFL、CC BY 4.0 等）。
> 零风险路径就是「只学怎么做，不搬做出来的东西」。参考清单本身是私有研发资料，不随 Skill 分发。

### 2.3 动画必须是「有过程的运动」（W19）

**禁止「整块淡入」冒充动画。** 逐帧纯函数 `render_frame(t)` 只依赖时间 t，任意帧可单独渲染、可抽检、可复现。
口播里点名什么，画面里就要真的发生什么：

> ⚠️ **下表是 72 号「那一份文稿」的实例，里面 `6,000→50,000`、`×8.3` 都是从那期口播里抽出来的参数，是示范不是默认值。**
> **换任何一份文稿都该按通用引擎重抽一遍**：逐句标锚点 → 归意图 → 查基元 → 参数从该句抽。
> 通用映射表 / 效果基元库 / 指令通道 / 逐句对照表见 [`semantic-to-effect.md`](semantic-to-effect.md)（§3.8 / W24）。

| 口播点名（72 号实例） | 必须看到的逐帧过程 | 通用基元 |
|---|---|---|
| 数字滚动（6,000→50,000） | 翻牌器一帧帧滚（odometer 窗口=字高 + 滚筒渐隐渐显，否则新旧数字重影） | `odometer` |
| 柱子 / 涨了 8 倍 / 10 倍 | 柱子从 0 长到目标高，×8.3 徽章 → ×10 目标虚线柱继续冲顶 | `grow_bar` + `counter_badge` |
| 打字机 / 变色 | 逐字打出，已打字逐字变色 | `typewriter` + `keyword_pop` |
| 画框画箭头 | 红框逐段描出、箭头逐指、标签弹入 | `trace_box_arrow` |
| 放大镜 / 局部放大 | 真的 scale 1→2.2 加焦点，不是贴个圆圈 | `magnifier` |
| 流程层级 / 控制出现时间 | 节点按时间逐个连线生长、逐级点亮 | `node_chain` |
| 风格可选 | 色卡真实位移轮播，不是换张静态图 | `swatch_carousel` |

缓冲库自己写：`ease_out_cubic / ease_out_quint / ease_out_back / ease_in_out`。

**阶段 ① 拆镜（§1 的 1.1）就要调用通用引擎的 S1–S5**：不只抠「点名动画」的句子，而是逐句标锚点、查基元、抽参数，
产出逐句对照表；长静态句按 `semantic-to-effect.md` §3 最后一类走 `beat_card` 短句卡点。

### 2.4 全片节拍化：任一单一画面 ≤3s（W20）

用户红线原话：「不能有这种超过 3 秒以上的画面，最好是就能看清楚就行了，然后都是动画，有的地方可以动画慢一点」。
**不是单纯缩短，是「看清就切 + 全程在动 + 快慢有区分」**。三个杠杆：

| 手段 | 适用 | 做法 |
|---|---|---|
| 过渡段拆短句卡点 | `fill()` 型静态过渡（如「零门槛」6.5s、「学不会」11s） | 拆成 ≤2.3s 一拍，每拍一个短句 + 一种动效，pop/type/slide/count/orbit 轮换；快拍为主 |
| 长核心分镜拍内重播 | 动画跑完就停尾巴的长分镜（12s / 9s 级） | 每 BEAT 秒完整重放一次动画过程，形成呼吸感 |
| 落版呼吸化 | 片尾 hero frame | 光环呼吸、轨道点旋转、边框脉冲；稳但不静，刻意放慢做节奏对比 |

**跨拍不撞同相位**：加一条全时段、跨拍不重复的运动底（宽光带横扫 + 背景刻度环 + 漂浮粒子），
否则拍内重播在边界会出现「两帧撞同相位」的瞬间近似静止。

### 2.5 数据验证（W20 的验收口径，不靠目测）

改完必须跑这三项，全部达标才进静帧复核。`content()` 裁内容区（排除圆头/字幕/角标），转灰阶缩小后算 RMS 帧差：

| 检查 | 方法 | 达标线 |
|---|---|---|
| A. 逐场景动态度 | 每个 >3s 场景，相邻 0.5s 帧差 | `avg ≥ 7` 且 `min ≥ 2.0` |
| B. 单一画面最长停留 | 按拍数算 `场景时长 / 拍数` | **≤ 3.0s** |
| C. 全片连续静止段 | 0.3s 步长采帧，帧差 <1.2 视为静止，统计最长连续段 | **≤ 1.5s** |

补充口径：全片每 2.3s 窗口首末帧差不得 <5（防局部拖沓）。
72 号实测：最长单拍 **2.60s**、观感尺度最长连续静止 **0.3s**（=检测粒度本身）、57 个窗口零静止。

> **抽样会误判**：4 点等距采样容易撞上「拍内重播」的同相位，把一直在动的场景误报为静止。
> 用相邻 0.5s 帧差（真实观看尺度）复核，别只信一次抽样。

### 2.6 阶段 ① 交付物与确认

- 静帧联络表（多帧拼图，**逐张读图**：圆头未加时检查文字溢出/重叠/黑块）；
- 过程总览图（每个核心分镜抽 4 个进度点，证明「有过程」）；
- 可播预览 MP4（纯动画层、无真人、无音轨即可）；
- 明确告诉用户「这是纯动画 Demo，等你确认后再叠真人层」，然后**停下等确认**。

## 3. 阶段 ② · 真人层 / 声音 / 封面 / 发布包

### 3.1 圆形真人头：实时裁帧 + 开场展示（W4 / W21）

按 `wanfeng-path.md` §5.3，但本支线有三条加严：

1. **从当前原片帧实时裁脸** —— 圆头里人在动、口型在动，**不是贴静态照片**。取帧器按 t 逐帧解码原片。
2. **开场就要展示** —— 用户明确「我口播那个视频的人脸之类的也要加在这里面，并且开场就要展示」。
   开场 hook 走**左下大圆头**，其余场景走**右上**；位置与半径是**场景级参数**，不写死在渲染循环里。
3. **新素材必须重新画网格实测** —— 在帧上画 50/200px 刻度网格，读出头顶、下巴、脸左右边界；
   **抽多帧验证活动幅度**（72 号 t=2/30/60/100 四帧，幅度 ±20px），再定圆心与半径。
   72 号实测 `(495,700) r450`，旧素材是 `(500,630) r450` —— 差 70px，套旧值真会裁歪。
4. **圆头必须留手机安全边距** —— 72 号发布后手机端反馈：右上 `(858,232) r200` 顶边仅 32px 贴顶「看着很奇怪」，
   开场左下 `(250,1610) r220` 被视频号底部 UI 遮住「有的手机都看不见」。圆头往垂直中带收：
   **顶边距画面顶 ≥180px、底边距画面底 ≥320px**（`wanfeng-path.md` §5.3 有参考值）；
   `HEAD_PLAN` 场级参数按此复核，静帧上画安全区框读图确认。

### 3.2 图层顺序与遮挡避让（W22 / W23）

渲染顺序固定：**`ambient_layer`（氛围） → 场景函数（内容） → `beat_layer`（UI） → `draw_head`（圆头） → `overlay`（字幕/角标）**。

| 坑 | 后果 | 正解 |
|---|---|---|
| 氛围光带/粒子画在 overlay 层 | 不透明宽带（9×26px 连成 230px）扫过正文，把白字盖成背景色 | 氛围层移到**内容之前**画；UI 元素才留内容之上 |
| 顶部标注条（`S01 · REF …`） | 压住右上圆头头顶，切掉一截 | 支线里**整条删掉**，只留底部字幕 + 角落角标 |
| 小标签 / 长标题 / 卡片压到圆头 | 圆头被挡，用户明确不接受 | 按圆头位置**逐场景避让**：chip 挪出圆头区、长标题缩短、卡片下移 |

避让改完必须重出静帧联络表逐帧读图（W1 / W5），确认圆头完整、无裁额头/下巴、无元素被压。

### 3.3 接声音：真声 + 程序化音效（不用 TTS）

成片自带真人真声且与动画时间轴逐句对齐时，**直接抽原片音轨**，不要 TTS、不要重新配音：

- `loudnorm` 两遍法归一到 **-14 LUFS / TP -1.0**（72 号原声 -20.71 LUFS，成品实测 -14.54 / TP -1.32）；
- 分镜音效**本地程序化合成**（numpy），零外部素材、可商用可二开：
  16 个核心分镜起点各一组对齐动效（数字滚动细密 tick、柱子生长上升扫频、打字机、HUD blip、确认 ding、片尾收束和弦），
  过渡段极轻 whoosh，底下垫 55/110/165Hz 低频氛围，片头淡入片尾淡出；
- 音效垫压在约 **-18dB**，不抢人声；另出一版「仅人声」备用，方便 A/B；
- **mux 用 `apad + -t <全长>` 锁定视频全长**，别用 `-shortest`（会截短 67ms 导致音画不齐）；
- 视频流 `copy`，画面一帧不动；出片后 `ffprobe` 验 video=audio 时长（W9）、末尾 3s 解码、波形无断裂无削波。

### 3.4 封面与发布包

- 封面仍走 **Step H / W12**：竖版固定底图换字换 logo；宽屏按 `aspect-ratio.md` §4.7 独立排版，保留同一期竖版成品中的确切肖像；文案要**点出选题主题**
  （72 号原版「剩下全是AI」不够，改成「剩下AI剪完」才体现「AI 剪辑」）。
  可批量出 4 组候选 + 对比总览让用户挑，主推版落正式发布包位；拉丁段字号 `int(中文字号*0.95)`。
- **发布包是 `<选题根>/发布包/`**：根目录放已选非横版的发布视频、封面，以及可共用的发布文案。已选宽屏时，横版发布视频和独立封面放 `发布包/横版视频/`，执行 [`aspect-ratio.md`](aspect-ratio.md) §4.7。
- 母版、仅人声备用（未指定对外发布时）、动画 Demo、静帧、工程与八节 `交接文档.md` 放同级 `剪辑过程/` 或独立工程区，不放发布包。同步修正脚本输出路径和交接文档的相对链接。

## 4. 本支线新增踩坑（每条真实踩过）

| # | 坑 | 表现 | 解法 |
|---|---|---|---|
| 1 | 成片 + SRT 再跑删减 | 字幕整体偏移，逐句对不上 | 恒等映射，跳过 Step 0，不重识别 |
| 2 | 沿用旧素材文件名 | `xxx-2.mov` 换了名，旧路径全失效 | 重新 ffprobe 探测，只认本次点名文件 |
| 3 | 不透明宽光带画在 overlay | 扫过时把中央白字整块盖掉，缩略图看着像乱码碎片 | 氛围层移到内容之前 |
| 4 | odometer 窗口 > 字高 | 快速滚动新旧数字同亮，出现重影 | 窗口 = 字高 + 滚筒渐隐渐显 |
| 5 | 呼吸光环半径可能变负 | 动画未落定时 `34*sin(...)` 推成负数，draw_ellipse 直接崩 | 先 `max(0, …)` |
| 6 | 拍内重播撞同相位 | 抽帧等距采样误判「静止」，实际一直在动 | 相邻 0.5s 帧差复核 |
| 7 | 顶部标注条压圆头 | 右上圆头被切掉头顶 | 整条删除 + 逐场景避让 |
| 8 | `-shortest` 封装 | 视频流被截短 67ms，音画不齐 | `apad + -t <全长>` |
