# 晚枫自动剪视频 · mograph

> SkillHub 安装：https://skillhub.cn/skills/user_bf8c5b73/wanfeng-mograph

一句话：**给一条真人口播视频，按你讲话的内容，自动在人的上下左右弹出字卡 / 数据 / 图表 / 对比框，做成成片。**

- v1 采用「**不自带现成效果**」的做法：skill 本身不自带现成的卡片效果，运行时由你本地的 AI 联网找社区里的最新实现
- 零第三方 Python 依赖（只要 Python 自带的标准库）
- **不调用任何付费接口**（不联网生成、不花云端算力）
- 三条落地路线：Remotion → HyperFrames → 实在不行就用 ffmpeg

> 💡 **想要完整维护的晚枫成片工作流？**
> 本 skill 继续免费保留通用路径、晚枫专用路径和封面示例，可用于基础体验。
> 付费版 **晚枫自动剪视频-Pro（`mograph-pro`）** 提供完整维护版、配套资产、持续更新与交付支持。

## 一、30 秒看懂它怎么用

![晚枫自动剪视频 · 通用路径执行流](assets/execution-flow.png)

```bash
cd mograph

# ① 先出骨架（离线、秒级、零风险）——看看它会给你出几张卡、放在哪
python3 scripts/make_spec.py \
  --script 我的口播稿.md --video 我的口播.mp4 --duration 85 --stdout

# ② 满意了再在对话里说：
#    「用 mograph 自动剪辑这条口播视频，稿子和视频在这儿」
#    agent 会联网找实现（Step 2）→ 填动画描述 → 选引擎渲染 → 自检交付
```

> **开工前先定风格路径**（第二步）：做自己的号选「晚枫专用」，流程和上面完全不同 —— 见第二节。
> 命令行上就是加一个 `--style-path wanfeng`。

期望先看到这样一段（下面是本仓库真实稿件 `什么是Token` 跑出来的）：

```
== 口播动效骨架 ==
源视频：未提供｜85.0s（时长来源：given）｜9:16
时间戳：估算（4 字/秒）｜动画卡：8 张｜覆盖 26.1%｜单屏最多 1 张｜弃卡 0 条
分布：bottom 1｜left 1｜right 3｜top 3
类型：分屏对比(split-compare) 3｜清单逐条(checklist) 2｜品牌/产品名卡(logo-card) 2｜数字滚动卡(number-roll) 1
⚠️ 时间戳为估算（4 字/秒），交付前必须试听对齐
提示：覆盖率 26.1%，低于 Step 6 的 40% 交付闸 —— 回 Step 3 手工补卡
```

**为什么骨架只出 8 张、覆盖率 26%**：正则只能命中「阿拉伯数字 + 单位」「不是 A 而是 B」「第一/第二」这类显式结构。中文数字（一到两个）、隐含对比、需要视觉化的抽象概念，**留给 agent 在 Step 3 补**——这是设计分工，不是没做完。

## 二、两条风格路径（开工前先选一条）

| 路径 | 什么时候用 | 产出 | 渲染器 |
|---|---|---|---|
| **通用**（默认） | 给任何口播视频做通用包装 —— **普通用户走这条** | `overlay-spec.json` | Remotion / HyperFrames / ffmpeg 兜底 |
| **晚枫专用** | **只有晚枫本人**做晚枫工作室账号的成片时才走 | `wanfeng-scene-plan.json` 场景骨架 → 手写场景表 | **Pillow 自绘**（2 倍超采样） |

> **「晚枫专用」是个隐藏彩蛋**：它是为晚枫本人的账号量身定制的打法，设计令牌、版式、
> 封面底图全部绑死晚枫工作室的调性。不熟悉的用户**可以去体验，但别拿来当主力** ——
> 普通用户请走通用路径。**不确定自己该走哪条 → 一律走通用**，不用问。

**晚枫专用路径是什么来头**：它是晚枫工作室自己账号的成片打法，从真实交付的片子（81.23s / 1080×1920@30）反推出来的完整流程 —— 冷深蓝 + 品牌绿的设计令牌、`fs` 全屏设计版式（有人脸、有步骤、有背景色和字）、圆形人头、步骤条、语速映射、两遍法响度归一，全部固化在 `references/wanfeng-path.md`。

**封面也是这条线的一部分**：成片交付后还有 Step H —— 在混元封面底图上「换字、换 logo，人像一像素不动」（用户以后都穿同一件衣服录视频，人像永远复用）。模板脚本已与真实成品逐像素对齐（max diff = 0），见 `references/wanfeng-cover.md`。

**这条路径不走联网检索**，不装 Node，不起浏览器 —— 只要 Python + Pillow + ffmpeg，在任何机器上都能复现出同一条片子。

```bash
python3 scripts/make_spec.py \
  --script 我的口播稿.md --srt 我的字幕.srt \
  --style-path wanfeng --stdout
```

```
== 晚枫专用路径 · 场景骨架 ==
源视频：未提供｜84.27s（时长来源：timeline）｜9:16
时间戳：实测｜场景：9 场｜渲染器：pillow-frame
版式：cta 1｜evidence 3｜hook 1｜statement 1｜step 3
  #1    0.13–  5.87s  hook      fs      开场钩子（fs 全屏设计版式 + 圆形人头）
  #2    6.60– 20.67s  evidence  overlay 证据卡 / 数字卡（overlay）
```

场景骨架只是**时间区间 + 建议版式**。正式渲染前要按 `references/wanfeng-path.md` §5/§6 手写每一场的版式与文案 —— 这一步不交给正则，交给你（或你的 agent）的审美。

### 原始口播：先选择是否删减（两条路径共用）

无论选「通用」还是「晚枫专用」，拿到一口气录完的原始口播时，都会先把删减的影响解释清楚，
再由你明确选择。**不会默认开剪**：

- **允许删减**：删除重录废稿、半截句、孤立口水词，并把长停顿收紧到约 0.7 秒；默认不重排。
  完成后给你 `base.mov` 干净底片和 `clean-script.md` **完整保留口播稿**（不是刀口清单），
  然后直接继续做你要的视频，不停在删减阶段。
- **不允许删减**：原视频、音频、原稿、内容顺序、停顿和时长都不动，只做后续已授权的包装。
- **想调整片段顺序**：需要另行明确同意；「允许删减」本身不包含重排授权。

只有在你允许删减后，才会运行：

```bash
cd scripts
python3 cut_plan.py --video 原片.MOV --out plan.json --report plan.md   # 出计划 + 人可复核的报告
python3 cut_plan.py --video 原片.MOV --out plan.json --apply 底片.mov    # 出底片
```

`clean-script.md` 由 agent 按最终保留内容整理，并对照计划与底片复核；当前脚本不会自动生成它。
跑完照 `references/cut-feature.md` §5 的清单核对。该功能也能在你只要求删减时脱离动效包装单独跑：
只要 ffmpeg（ASR 可选），不装 Node、不起浏览器、不需要 Pillow。

已用 71 号原片验证：184.14s → 114.32s（保留 62.1%），7 处刀口 100% 命中人工标注，零误删。

### 顺带：配图素材与样片

**配图** —— 两条路径都会按你讲的主题去找图：

1. 先问你一次：有没有现成截图可以直接用？有没有链接我可以自己去截？都没有的话我按主题去网上找？
2. 来源优先级：用户给的截图 → 用户给的链接（自己截）→ 自己联网找 → **动画兜底**
3. **图上出现的东西，必须正是那一句口播在讲的东西** —— 讲「点搜索框」就不能配一张别的界面
4. **该标注的地方会标**：操作类和知识分享类配图加步骤编号、箭头或高亮框
5. 每张图的来源、截取日期记进 `assets/asset-manifest.json`

规范见 `references/visual-assets.md`。

**样片** —— 通用路径在所有选择（引擎、版式、卡片、配图、文案）都定完之后，会主动问你「要不要先出 5 秒样片」。只渲那一小段、不渲全片，确认满意再进全片。

## 三、为什么做成「联网现搜」而不是自带素材库

| 自带素材库 | 检索驱动（本 skill） |
|---|---|
| 发布即开始过期 | 每次运行都是社区当下最新 |
| 体积大（组件 + demo + 依赖） | 一个脚本 + 五份文档 |
| 风格被素材库锁死 | 风格由你的账号 / 参考片决定 |
| 许可责任在我（每次分发都要核对） | 许可责任在运行时确认（协议里有硬规则 R5 要求核对并记录） |
| 首次运行快 | 首次多花 3–8 分钟联网 |

**代价说清楚**：联网这一步的质量取决于你本地 agent 的检索能力。离线也能跑——走内置最小实现，动效会朴素一档，但**流程不会断**。

|---|---|---|
| 口播稿（`.md`/`.txt`） | 源视频或音频（用来实测时长与画幅） | SRT 字幕 / 词级时间戳 JSON |

## 五、三种机器的选择

| 你的机器 | 走哪条 | 效果 |
|---|---|---|
| 有 Node 18+，做数据/图表类动效 | Remotion | 最精细，组件可参数化复用。⚠️ Remotion 授权不是标准开源，商用先查官网 |
| 有 Node，且已在用 HyperFrames / 本仓库其他 skill | HyperFrames | MIT，HTML+GSAP，与封面/短视频链路视觉同源 |
| 只有 ffmpeg | 兜底路线 | 一定能出片，但数值滚动、逐条 stagger 会退化 |
| 什么都没有 | 只交付 `overlay-spec.json` + `research-notes.md` | 分镜与检索结果可带去别的机器渲染 |

> 走**晚枫专用**路径的话这张表不用看 —— 它只要 Python + Pillow + ffmpeg，不需要 Node，也不需要浏览器。

## 六、拍视频可以这么走（约 2 分钟）

| 段落 | 画面 | 口播要点 |
|---|---|---|
| 0–15s 痛点 | 一条干讲 60 秒的口播原片 vs 加了动效的同一条 | "同一段话，信息密度差三倍" |
| 15–40s 骨架 | 跑 `make_spec.py --stdout`，滚动出卡片分布 | "先不渲染，先看它打算在哪几秒放什么卡、放左边还是右边" |
| 40–80s 联网 | agent 按 `research-protocol.md` 搜社区实现，`research-notes.md` 一行行写下来 | "它不靠自己脑补，它去搜——搜到谁、什么许可、几行能迁移，全记下来" |
| 80–110s 成片 | 渲染 + 抽帧自检 | "卡片永远不压脸，因为有个安全区在拦着" |
| 110–120s 收尾 | 打开 `overlay-spec.json` | "换引擎不用重做分镜，这才是能长期用的东西" |

**演示时最好现场踩到的三个点**（观众最信这个）：

1. 卡片和人脸安全区冲突时**位置被自动挪走**，而不是叠上去；
2. 时间戳是估的 → 屏幕上明晃晃打出 `⚠️ 估算` —— 建立"它不会装_done_"的信任；
3. 搜不到实现时，它明说"本次未联网，走内置最小实现"，仍然出片。

## 七、常见问题

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 一张卡都没出 | 稿件太叙述化（没有数字 / 没有列举 / 没有对比） | `--density high` 再看；仍为 0 就是稿子问题，回稿件加"可视觉化的钩子" |
| 卡片时间和讲话对不上 | 你没用真实时间戳 | 给 `--srt` 或 `--timestamps`；或 `--duration` 至少把总时长钉准 |
| 覆盖率一直 <40% | 骨架只吃显式结构 | 正常，Step 3 由 agent 补卡；不要为了让数字好看硬塞无意义卡 |
| 横屏卡片挡住人 | 人物不在画面中间 | 按 `overlay-layout.md §2` 手动收紧安全区 x 范围 |
| 想要卡片浮在人前面 | 需要逐帧抠图 | v1 明确不做（R3）；坚持要就先把 `layer` 改 `front` 并接受质量风险 |
| 商用时发现组件是 Noncommercial | 检索到的社区库许可限制 | 按协议换 MIT/Apache 候选；实在要用只借鉴方法论不搬代码 |
| 「这个视频也是 AI 剪的」比预想慢 | 只改了音频没改画面时间轴 | 走晚枫专用路径 §7：底片预处理 + `map_t()` 映射，两边都要改 |
| 文字叠在一起了 | `text()` 默认基线锚点，给的 y 是基线不是字顶 | 字顶 ≈ 基线 − 字号×0.86；或显式传 `anchor="lt"` |
| 只有 SRT 没有稿件，脚本报"没解析出任何句子" | 旧版本要求稿件必须有句子 | v1.1 已修：有 `--srt` / `--timestamps` 时不再要求稿件分句 |
| 晚枫专用路径出不来想要的效果 | 场景骨架只给版式建议，内容是空的 | 按 `wanfeng-path.md` §5/§6 手写每一场的 layers，别指望正则 |
| 配图跟口播对不上 | 图上不是那句在讲的东西 | 查 `assets/asset-manifest.json` 的 `shows` / `proves`，写不出 `proves` 的图换掉 |
| 全片渲完才发现版式不对 | 跳过了样片 | 回 `SKILL.md` Step 5.5，先出 5 秒样片确认再渲全片 |
