# 动画描述规范与内置最小实现 · animation-brief.md

> Step 3 用这份文件把「命中了哪类动画」写成**可实现的描述**，填进 `overlay-spec.json` 的 `animation.brief`。
> 每类都给三样：**什么时候用 / brief 怎么写 / 内置最小实现**（无外部依赖，搜不到就用它）。

---

## 0. `brief` 字段的统一写法（一行，逗号分隔）

```
入场=<动作>/<时长>/<缓动>，主体=<元素级动作顺序>，出场=<动作>/<时长>，强调=<高亮什么>
```

示例（数字滚动卡）：

```
入场=右滑0.25s/ease-out，主体=标签淡入0.1s→数字从0滚到120万1.2s/ease-out-cubic→单位后缀弹0.15s，出场=下移淡出0.2s，强调=数字用主色+加粗，标签次要灰
```

**为什么固定格式**：agent 写完 brief，下一步无论走 Remotion 还是 HyperFrames，都能机械翻译成代码；换成别的渲染器也不用重新理解自然语言。

---

## 1. number-roll 数字滚动卡

- **命中语句**：`120 万参数`、`降到 30%`、`提升 3 倍`、`25 人`
- **位置**：`right`（竖屏）/ `right`（横屏）｜**不要用 top**，数字要占大字位
- **brief 模板**：`入场=右滑0.25s/ease-out，主体=标签淡入→数字0→目标值1.2s/ease-out-cubic→后缀弹入，出场=淡出0.2s，强调=数字主色700字重`
- **⚠️ 常见错**：把「一到两个」这类中文数字漏掉。`make_spec.py` 的正则只认阿拉伯数字 + 单位，**agent 必须在 Step 3 手工补卡**（这是设计好的分工，不是 bug）。
- **内置最小实现**：

```html
<div class="card num"><span class="label">参数规模</span>
  <span class="val" data-to="120">0</span><span class="unit">万</span></div>
<script>
// GSAP 路线（HyperFrames 可直接用）
gsap.to(".num .val", {textContent:120, snap:{textContent:1}, duration:1.2, ease:"power3.out"});
// 无 GSAP 时（纯 JS，ffmpeg 截图路线也能用）
// requestAnimationFrame 线性插值 + easeOutCubic: 1-(1-t)**3
</script>
```

## 2. bar-chart 对比柱图

- **命中**：`比 X 便宜一半`、`高 3 倍`、`涨了 40%`、`A vs B`
- **位置**：`right`（宽 ≥20% 屏幕）｜两柱以内
- **brief**：`入场=整体淡入0.2s，主体=柱A从底长出0.5s/ease-out→柱B长出0.5s，延迟0.15s→数值标签各弹0.1s，出场=淡出0.2s，强调=被比较对象用主色，基准用中性灰`
- **内置最小实现**：两根 div，`height` 由 `transform: scaleY()` 从 0 到 1（**不要用 height 动画**，会引起重排掉帧）。
- **⚠️ 数据纪律（R2）**：柱高比例只能来自稿件里的数字。稿件只说「便宜一半」→ 画 2:1，不许自己查资料改成 3:1。

## 3. split-compare 分屏对比

- **命中**：`不是…而是…`、`前者…后者…`、`以前…现在…`、`VS`
- **位置**：`top` + `bottom` 两条（上下对比）｜横屏可左右
- **brief**：`入场=左半左滑入/右半右滑入0.3s/ease-out同步，主体=两侧标题先入→各自要点逐条0.15s stagger→中间分隔线竖向拉长0.2s，出场=两侧同时滑出0.25s，强调=「而是」侧高亮，「不是」侧压暗30%`
- **内置最小实现**：两个 `position:absolute` 面板 + 一条 `scaleY` 分隔线。

## 4. checklist 清单逐条

- **命中**：`第一…第二…`、`首先/其次/最后`、`1. 2. 3.`
- **位置**：`left`（窄栏）｜≤4 条，超了拆两卡
- **brief**：`入场=整体淡入0.2s，主体=每条 图标弹0.12s→文字左滑0.2s，条间延迟0.35s，前条保持可见但降透明到45%，出场=整体下移淡出0.25s，强调=当前条满透+主色左边框`
- **要点**：**已经念完的条目必须留在屏上（降到 45%）**，全淡出等于白讲。

## 5. quote-card 引用卡

- **命中**：`「…」`、『…』、直接引语
- **位置**：`top`（横屏可 bottom）
- **brief**：`入场=引号放大淡入0.2s→正文按词分组浮现0.6s/stagger，主体=出处标签最后入0.2s，出场=淡出0.3s，强调=关键词荧光笔下划0.25s`
- **⚠️**：引语必须逐字照抄稿件，不许改写（R2）。

## 6. timeline 时间轴

- **命中**：`2024 年`、`去年/今年`、`第一阶段`、`3 个月前`
- **位置**：`bottom`（横条）｜≤4 个节点
- **brief**：`入场=轴线横向拉长0.5s/ease-out，主体=节点依次弹入0.15s，每个节点年份先入→事件文字后入0.2s，出场=淡出0.2s，强调=「当前」节点放大1.2倍+主色`
- **内置最小实现**：一条 `transform: scaleX()` 的线 + 圆形节点 `scale` 弹入。

## 7. logo-card 品牌/产品名卡

- **命中**：`ChatGPT`、`Cursor`、`Remotion`、任何专有名词
- **位置**：`top` 或 `right`
- **brief**：`入场=名称缩放0.9→1.0淡入0.25s/ease-out，主体=副标题（一句话定位）后入0.2s，出场=淡出0.15s，强调=名称用品牌色（不许猜色值，取稿件或用户给的风格档）`
- **⚠️ 不许画别人的 logo**（商标风险）。只排文字，或让用户自己提供授权素材。

## 8. keyword-pop 关键词弹字

- **命中**：`所谓…`、`本质上…`、`关键在于…`、`记住…`
- **位置**：`bottom`｜一句最多 1 个词
- **brief**：`入场=逐字砸入0.12s/字+轻微缩放1.3→1.0，主体=荧光笔下划从左到右0.25s，出场=下划保留、文字淡出0.2s，强调=单主色+黑底白字，不加渐变`
- **这是最不像「贴片」的一类，也是性价比最高的**：不遮脸、不需要数据、纯排版就能做。

## 9. 选类决策树（agent 一条语句只选一类）

```
句子里有阿拉伯数字+单位？ ────────→ number-roll
有「比/高于/涨/降」+ 数字？ ───────→ bar-chart
有「不是A而是B / 前者后者 / VS」？ ─→ split-compare
有「第一/首先/1. 2.」？ ───────────→ checklist
有引号原文？ ─────────────────────→ quote-card
有年份/阶段？ ────────────────────→ timeline
有专有名词且无上述？ ─────────────→ logo-card
有「所谓/本质上/关键」？ ──────────→ keyword-pop
都不是 → 不出卡（留白比硬凑好）
```

**优先级冲突**（同一句既像 number-roll 又像 bar-chart）：选**信息量更小**的那个。数字卡 1 秒能读完，柱图要 3 秒；口播节奏快时宁可轻。

## 10. 通用动效底线（不做就是 PPT）

| 规则 | 值 |
|---|---|
| 入场时长 | 0.15–0.35s，**不许 >0.5s**（观众等不及） |
| 出场时长 | 入场 × 0.7（出去要更快） |
| 缓动 | 入场 `ease-out`，出场 `ease-in`，数值滚动 `ease-out-cubic`。**默认不用 bounce/elastic** |
| 静止帧 | 任一卡可见期间，至少 1 个元素在动（哪怕是荧光笔扫描） |
| 动画属性 | 只用 `transform` + `opacity`（碰 `width/height/top/left` 会掉帧） |
| 每卡元素数 | ≤5 个可动元素，多了看不清 |
