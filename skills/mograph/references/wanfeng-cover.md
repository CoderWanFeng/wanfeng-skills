### 0.1 图片缺失时怎么办（换机器 / 分发渠道不带图片）

（`MOGRAPH_ASSET_CACHE` 可改目录），下完再跑脚本即可。**不要因为找不到图就跳过 Step H。**

下载源两档，路径完全一致（AtomGit 由 GitHub 同步）：

| 顺位 | 源 | 地址 |
|---|---|---|

| 2 | GitHub 原始文件 | `https://raw.githubusercontent.com/CoderWanFeng/wanfeng-skills/main/skills/mograph/cover-assets/<文件名>` |

> ⚠ **AtomGit 不能用 `.../raw/main/<路径>` 直链**（2026-11-17 实测：返回的是一个 64×48 的占位 SVG 和一段 HTML，不是原图）。
> 脚本走的是 `api/v5/repos/.../contents/<目录>?ref=main` 接口，从返回的 `download_url`（`raw.atomgit.com/.../blobs/<sha>/...`）下载。
> 手动下载请直接开目录页点文件。

**手动兜底**：打开上面任一目录页，下载 `封面-底图-混元WB.jpg` 与 `hy4-frame7.jpg`，
放进 skill 的 `cover-assets/`，或放到任一目录后用 `MOGRAPH_ASSET_DIR` 指过去。

> 下载只解决「图片从哪来」，**不改变授权范围**：封面底图与头发参考帧仍是受保护资产，
> 只能用于「在固定底图上换字换 logo」的封面换皮用途。

**环境**：托管解释器 `~/.workbuddy/binaries/python/envs/default/bin/python3`
（PIL 12.x + numpy + cv2 5.0 都在这里；`/usr/bin/python3` 没有 cv2，会直接报错）。

## 1. 五步流程

```
1. 复制模板   templates/cover_from_base.example.py → <选题>/AI剪辑输出/src/cover.py
2. 改 CONFIG  只改【每期必改】项：OUT、两行文案与配色、logo 三项
3. 跑脚本     托管解释器直跑，秒级出图 → <选题>/发布包/封面-XXX.jpg
4. 三闸自检   见 §3（净空闸 / 明度闸 / 字号闸，全部实测，不许目测）
5. 读图交付   Read 工具真读一遍成品，再放进发布包
```

### 1.1 CONFIG 每期改什么

| 项 | 说明 |
|---|---|
| `OUT` | 输出路径，放 `<选题>/发布包/封面-XXX.jpg` |
| `LINE1_SEGS` / `LINE2_SEGS` | 两行文案。**中文段 kind="cn"、拉丁/数字段 kind="latin"，必须拆段**（原因见坑 2） |
| `LINE1_FILL` / `LINE2_FILL` | 字色。第一行沿用蓝 `(16,43,99)`、第二行沿用红 `(160,19,21)`，都是从底图原字采样的，**换选题一般不用改** |
| `ERASE_LOGO` | `False` = 保留底图原 WorkBuddy 标识（推 WorkBuddy 的选题用）；`True` = 抹掉换成自己的 |
| `ICON_DRAWER` / `WORD_TEXT` | 新 logo 的图标画法函数名 + 字标文本（示例：`z_icon` / `"ZCODE"`） |

标了【勿改】的（BASE、HEAD_SRC、DX/DY、两行 cx/cy/size、ICON_X/Y/S、band 坐标）都是
底图配准值和「行距 82px / 净空 33px」的验证结果，动了必翻车。

## 2. 版式实测值（用户四轮反馈收敛的最终形态）

```
第一行  免费用GLM     cy=172  字号 207（拉丁 202）
第二行  每天领3亿     cy=490  字号 262（数字 248）   ← 行距 82px（从 65px 拉开过）
第二行字底      y=593
头发顶          y=626                          ← 净空 33px
投影收住线      y=615                          ← 投影不碰头发
logo 图标       (864,1150) 300px；字标 y=1301 字号 152 字距 -6（宽度 508px，不出画）
```

**取舍关系（用户已拍板）**：「行距拉大 + 字号不缩 + 绝不压头发」三者不可兼得。
最终解 = 字号微缩 3%（272→262、207 号不变），换来行距 65→82px、净空 24→33px。
下次想调字号，先算字底到 y626 的距离，投影模糊半径 16 + 偏移 13 都要收在净空内。

## 3. 三闸自检（全部用像素实测，目测不算）

```python
# 闸 1 · 净空闸：字底（含白边）到头发顶 ≥ 30px，投影收在头发顶之上
# 闸 2 · 明度闸：字色成品值 vs CONFIG 值，每个通道差 ≤ 6（防投影盖字的回归）
# 闸 3 · 字号闸：拉丁段字号 = int(中文号*0.98 / *0.95)，差 1 号边缘全糊
```

| 闸 | 怎么测 | 合格线 |
|---|---|---|
| 净空闸 | 沿第二行文字列做像素投影，找字底 y；暗色+偏暖判据找头发顶 y | 净空 ≥ 30px，投影收在头发顶上方 |
| 明度闸 | 抠成品字面中心像素和 CONFIG 颜色比对 | 逐通道差 ≤ 6（58 号实测蓝字 (19,45,100) vs 配置 (16,43,99)，合格） |
| 字号闸 | 检查 CONFIG 里拉丁字号是否等于 `int(中文号*0.98)`（行1）/ `int(中文号*0.95)`（行2） | 必须相等，手写错 1 号整个字形边缘偏移 |

**投影尾端怎么测（别用阈值法，会误判）**：取一段**纯墙面**（避开头发，如 x950-1250），
打印 y596→700 的逐行平均亮度。墙有竖向渐变，判据是「亮度**单调回升**到平台值」，
出现**局部暗带**才是投影残留。58 号实测：198.6(y596) → 210.1(y628) → 平台 208.4，
单调回升、无暗带 → 投影在 y620 前后收住，不碰头发（头发顶 y626）。

> ⚠️ 用「某行是否有像素 <195/185」这类阈值找投影最下沿会得到假阳性：JPEG 噪声 +
> 墙面竖向渐变本来就有暗值，58 号实测被误报成「投影止于 y633，距头发顶仅 1px」，
> 而真相是差 20px 以上。**一律看亮度曲线，不看单行阈值。**
> 同理找头发顶也别用单行阈值 —— 红色字身的暗红像素会命中「暗色+偏暖」判据，
> 必须从字底**下方**起扫，并要求连续 3 行成立。

## 4. 踩坑清单（每条都真实踩过，含用户直接打回的）

| # | 坑 | 表现 | 解法（已固化在模板里） |
|---|---|---|---|
| 1 | **投影盖字**（用户反馈「字怎么这么暗」） | `alpha_composite(文字, 投影)` 顺序反了，半透明投影压在字上，蓝字实测 (22,36,70)，暗了整整一档 | 必须 `alpha_composite(投影层, 文字层)`，**投影在下** |
| 2 | **TencentSans 拉丁是斜的** | 「GLM」「ZCODE」直接用中文字体排，字是歪的 | 中英拆段：拉丁/数字用 Arial Bold 直立体，按基线对齐 |
| 3 | **inpaint 抹字连头发一起抹**（用户反馈「发型很奇怪」） | 底图原字压在头顶上方，抹字后 y580-700 留一块模糊暗斑，发型缺一块 | 用 `hy4-frame7.jpg` 补回：底图人像就是这帧 1:1 贴入的，配准位移 dx=85/dy=390，逐像素贴回 + per-channel 色调增益 |
| 4 | **椅子颜色渗进墙面** | 铺平暗雾时取左侧墙色平均，把画面左下的椅子采进来了 | 只取右侧 y1020-1300 的**中位数**墙色，逐行填 |
| 5 | **换 logo 字标出画** | ZCODE 152 号仍右溢 | 字距收紧 -6，宽度落回 508px；字标用 `bbox` 垂直居中（`cy-(bb[1]+bb[3])/2`） |
| 6 | **行距太挤**（用户反馈） | 第二行 272 号时字底 602、头发顶 626，净空 24px，投影蹭发 | 字号微缩 3% + 第二行 cy 下移到 490，行距 82px、净空 33px |
| 7 | **从新视频抽帧自拼人像**（用户否决整个方案） | 人脸占 48% 过满，镜像补边 + 渐强虚化都救不回构图 | **不走这条路**。一律在混元底图上换皮，人像永远不动 |
| 8 | **用错解释器** | `No module named 'cv2'` | 换皮脚本必须在托管解释器跑（它要 PIL+numpy+cv2 三个都有） |

## 5. 与 wanfeng-path.md 执行流的关系

封面是**成片八步全部走完之后**的追加步（Step H），不插在中间：

```
Step 0 删减 → A 定版式 → A2 配图素材采集 → B 场景表 → C 静帧 → D 重渲 → E 终检 → F 响度归一 → G 交接
                                                                          ↓
                                                          Step H 封面（本文件）
```

- 交付目录：封面放 `<选题>/发布包/`，和发布版视频并列
- 交接文档（§9 规范）里补一行：封面用的哪套 CONFIG（字 / 色 / logo），方便下期换皮直接抄
- 发布包三件套齐了才算交付完：**发布版视频（响度归一）+ 封面 + 发布文案**
