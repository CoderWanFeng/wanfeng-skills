# 默认版全自动流水线（入口 ①，先做好的那条）

> **一句话**：用户什么都不用管 —— 有素材就上传，没素材我全代生成；之后换装、卡点音乐、合成短片**全部自动跑完**，直接给一条能发的 mp4。
> 本路径**不打开即梦网页、不手动拖拽**，全部用 WorkBuddy 内置生成能力 + 本地 ffmpeg 完成。
> 「我指定动作」是入口 ②，见 `workflow.md`，**下一步再做**。

---

## 1. 入口分叉（一次列全，选一次，不二次追问）

```
入口 ① 默认全自动            → 本文件（已实现，可测）
入口 ② 我指定动作（白膜驱动）→ workflow.md（占位，下一步启用）
```

默认版开工只要确认一次：

| 项 | 用户动作 | 默认值（不说就按这个走） |
|---|---|---|
| 模特全身照 | 上传 1 张 / 说「生成」 | 无 → 我代生成 1 张 |
| 衣服多面图 | 上传 N 套，每套 1 张多面拼图 / 说「生成」 | 无 → 我代生成 **3 套** |
| 成片比例 | 可指定 | **9:16 · 1080×1920** |
| 每套时长 / BPM | 可指定 | **2.0s / 120 BPM**（3 套 = 6.0s） |
| 是否让模特真的走起来 | 可指定 | **默认静帧推近动效**（省成本、跑得快）；要真动开 `--motion` |

**判断口径**：用户只在「有/没有素材」上做一次选择，其余一律走默认。不要把比例、时长、BPM 拆成多轮追问。

---

## 2. 资产规格（4 张图 = 1 张模特 + 3 套衣服）

| 资产 | 数量 | 规格 | 谁产出 |
|---|---|---|---|
| 模特全身照 | **1 张** | 9:16 竖版、正面全身、自然站立、纯色背景、白色紧身底版、商业人像摄影 | 用户上传 / `ImageGen` 文生图 |
| 衣服多面拼图 | **每套 1 张，共 3 张** | 一张图里 **2×2 四宫格：正面 / 背面 / 侧面 / 细节特写**，纯白底、平铺或挂拍、无模特 | 用户上传 / `ImageGen` 文生图 |
| 合计 | **4 张** | 1 + 3 = 4 | — |

**为什么每件衣服是「一张多面拼图」**：一次生成就把四个角度交给换装模型，服装配色/版型/图案/领型还原度最高；又不用为每个面单独调一次生成，成本与耗时都最省。这是带货视频的生命线。

**可配置参数**（别写死在流程里）：

```
GARMENTS = 3        # 服装套数，用户说「最少三套」；起号卡点变装可扩到 5–7
FACES    = 4        # 每套衣服拼图的面数（2×2 四宫格）
BPM      = 120      # 卡点速度
SEG      = 4*60/BPM # 每套 2.0s，切点必落在小节线
SIZE     = 1080x1920
```

改套数时**音乐、切点、拼接全部跟着变**：`beat_music.py --segments N` 与 `compose_video.py` 的 N 张图必须一致。

## 3. 五个自动阶段（A1–A5）

### A1 素材归位 / 代生成

**有素材**：收进 `<选题>/模特/` 和 `<选题>/服装/`，逐张 `ViewImage` 读图，确认是全身、纯色背景、多面拼图清晰。

**没素材 → 我代生成**（一次性列全提示词，参数从用户的话里抽，不写死）：

| 生成什么 | 工具 | 提示词要点 |
|---|---|---|
| 1 张模特全身照 | `ImageGen`，`size="1024x1536"`，`quality="high"` | `<年龄段><气质>亚洲女装模特，<发型>，<身材>，自然裸妆，正面全身照，自然站立，白色紧身衣，纯色背景，商业人像摄影风格，9:16`；明确「不露品牌 logo、不擦边」 |
| 3 张衣服多面拼图 | `ImageGen` × 3 | 每套一条提示词：`2×2 四格拼图，同一件<服装品类>的正面/背面/侧面/细节特写四张平铺图，纯白背景，电商商品图风格，四格之间留白均匀，无人物`，每套换 `<颜色/图案/版型>`，三套风格明显不同（换装才有看头） |

> 生成前**必须告知用户积分消耗**：`ImageGen` 约 5–10 积分/张，本步最多 4 张 ≈ 20–40 积分。用户确认后再调用。

**过闸**：模特图脸/手完整、9:16 全身、纯色背景；衣服拼图四格齐全、同一件衣服、白底干净。定稿模特图存 `<选题>/模特/模特-定稿.png`，是后续所有换装的**人物锚点**。

### A2 换装（3 张试衣图）

对每套衣服跑一次 `ImageGen` **图生图**：

```
image1 = 模特-定稿.png
image2 = 服装-0X-多面.png
prompt = 把 image2 四格展示的这件衣服穿到 image1 模特身上；
         脸、发型、身材、姿势与 image1 完全一致；
         服装配色/版型/图案/领型严格按 image2 正面那一格，背面与侧面细节一致；
         模特正面全身，纯色背景，商业服装摄影，写实
size = "1024x1536"
quality = "high"
input_fidelity = "high"
```

> `ImageGen` 最多接 3 张输入图，这里只用 2 张，够用且稳。

**过闸**（`ViewImage` 逐张亲眼看，按 `qc-gates.md` 图四查）：脸与定稿一致、服装还原、手指正常、无渗色。不合格**只重跑这一套**，带上「哪里不像」改提示词。输出 `<选题>/试衣/试衣-01.png … 03.png`。

### A3 卡点音乐（程序化，自己生成，不用外部音源）

```bash
python3 scripts/beat_music.py --out <选题>/音乐/卡点音乐.wav \
    --segments 3 --bpm 120 --report <选题>/音乐/beat-report.json
```

纯 `numpy` + 标准库合成：4/4 拍鼓组（kick / snare / hihat）+ bass + 和弦 pad + **每套切换点的 impact/riser**。切点写在 `report.json` 的 `cut_points`（默认 `[2.0, 4.0]`），与画面硬切一一对齐。**不依赖任何音乐素材、不产生版权问题**。

### A4 出片（两种画面来源）

```bash
# 默认：静帧推近动效，零视频生成成本
python3 scripts/compose_video.py \
    --images <选题>/试衣/试衣-01.png <选题>/试衣/试衣-02.png <选题>/试衣/试衣-03.png \
    --music  <选题>/音乐/卡点音乐.wav \
    --out    <选题>/成片/换装成片.mp4 --seg 2.0 --bpm 120 \
    --report <选题>/成片/compose-report.json
```

**可选：让模特真的走起来**（开 `--motion`）：对每张试衣图调 `VideoGen`，`image=试衣图` 作首帧、`aspect_ratio="9:16"`、`seconds=2`（或模型支持的时长），提示词统一用「模特朝镜头自信走来、自然摆臂、镜头缓慢跟随、写实」，3 段全部生成后把 3 个 mp4 按顺序传给 `compose_video.py --motion`。

> ⚠️ 开 `--motion` 前**必须告知**：`VideoGen` 约 50–100 积分 / 5 秒片段，3 段 ≈ 150–300 积分，且每段要等 1–3 分钟。默认版先测静帧动效，效果不满意再开。

脚本自动完成：每段精确 `trim` → 硬切 concat → 音乐 `-14 LUFS` 归一 → H.264/AAC → **faststart**，并输出 `report.json`（时长、切点、音轨、atom 顺序）。

### A5 质检与发布包

1. 跑 `scripts/qc_frames.py` 抽帧，`ViewImage` 逐帧读：脸是否漂移、服装是否跨套串色、切点是否干净。
2. `ffprobe` 复核：时长 = `N × SEG`、1080×1920、有音轨、`moov` 在前。
3. 发布包 `<选题>/发布包/`：`换装成片.mp4` + `发布文案.md`（按 `ops-playbook.md` 模板，**必带 AI 生成标注提醒**）。
4. 台账 `<选题>/台账.json`：4 张资产 + 3 张试衣图的提示词、参数、积分、日期、质检结论 —— 复现与迭代全靠它。

## 5. 与「指定动作版」的边界（必须对用户说清）

| | 入口 ① 默认全自动 | 入口 ② 我指定动作（下一步） |
|---|---|---|
| 操作场所 | WorkBuddy 内全自动 | 即梦网页（Agent 陪跑、不能代点） |
| 动作来源 | 提示词统一描述 / 静帧动效 | 用户提供参考视频 → 白膜化 → 驱动 |
| 视频模型 | WorkBuddy 内置 `VideoGen`（**无模型参数，不能指定 Seedance 2.0**） | 即梦 **Seedance 2.0** |
| 成本 | 默认仅图片生成积分；开真动才加视频积分 | 即梦积分 / 会员 |
| 适合 | 快速起量、先测效果、批量 | 要复刻特定爆款运镜 |

**模型名口径**：教程里说的「CDS2.0」实为 **Seedance 2.0**，只在入口 ② 使用；默认版不要许诺 Seedance。

## 6. 合规（发布前逐条打勾）

1. **AI 标注**：发布时打开平台「内容由 AI 生成」标识。
2. **肖像权**：用户上传的真人照片造模特，须确认本人同意；代生成的 AI 脸无此问题。
3. **不冒充真人**：文案不得暗示真人实拍，账号简介写明 AI 内容。
4. **服装图权利**：代生成的衣服是虚构款，可直接做内容；用户上传别家商品图带货需自有或授权。
5. **尺度**：避免擦边运镜与文案 —— 「AI 美女」类目平台审得最严的是擦边，不是 AI 本身。
