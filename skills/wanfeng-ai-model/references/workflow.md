# 五阶段 SOP：从参考视频到发布包（入口 ② 指定动作版）

> ⚠️ **本文件当前为占位、暂不启用**。用户要求先把「入口 ① 默认全自动」做好并测试效果，指定动作版下一步再接。
> 默认全自动的完整流程 → `auto-pipeline.md`；默认版提示词 → `prompts.md` §0。
>
> 启用后：每阶段 Agent 给提示词与参数 → 用户在即梦操作 → 回传产物 → Agent 质检 → 过闸。
> 提示词一律查 `prompts.md` 模板，**参数（年龄/气质/发型/服装/场景）从用户素材与需求里抽，不写死**。

## M1 白膜动作模板

**目的**：把参考视频里的「人」换成无特征的白色人台（白膜），只保留动作、运镜、节奏——这是「用别人爆款运镜但不搬运形象」的关键一步。

**做法 A（即梦全能参考，推荐）**：
1. 即梦 AI（jimeng.jianying.com）→ 视频生成 → **全能参考**入口。
2. 上传参考视频（单个 ≤15 秒；超长先剪出最想要的 5–10 秒）。
3. 提示词用 `prompts.md` §白膜化模板，用 `@视频1` 指明「动作/运镜完全参考该视频，人物替换为白色紧身人台，无面部特征」。
4. 模型选 Seedance 2.0，比例 9:16，时长与参考片段一致。

**做法 B（现成素材）**：电商素材站/拼多多商家素材里找现成「白模人台走秀视频」，能对上动作需求就直接用，省一次生成。

**过闸标准**：动作与参考视频一致；人台无面部特征、无原视频人物残留；运镜完整。
**不通过时**：把「哪里不像」翻译进提示词（如「转身幅度不够」→ 动作强度调高一档），只重跑本阶段。

## M2 专属 AI 模特

**目的**：从「用户喜欢的人物图片」造出一个**自有、可复用**的 AI 模特形象。

1. **反推提示词**：把用户给的图丢进即梦/豆包的图片理解（或画布的局部重绘面板），让模型输出画面描述；Agent 对照图片把描述改写成结构化提示词（年龄段 / 脸型气质 / 发型 / 身材 / 妆容 / 着装底版 / 背景 / 摄影风格）。
2. **改造定稿**：与用户确认「保留什么、改什么」（例：脸保留、发型改低马尾、底版统一穿白色紧身衣——底版与 M1 人台呼应，利于换装干净）。
3. **生成**：即梦图片生成，比例与成片一致（默认 9:16），**正面全身、自然站立、纯色背景、商业人像摄影风格**；一次出 4 张候选。
4. Agent Read 逐张读图 → 按 `qc-gates.md` 四查 → 用户挑 1 张**定稿**。

**过闸标准**：定稿模特图清晰（脸/手完整）、9:16 全身、纯色背景。
**重要**：定稿这张图就是后续所有视频的「人物锚点」，存 `<选题>/模特/模特-定稿.png` 并登记，**之后每条视频都用这张原图喂**，保证跨条一致。

## M3 画布换装

**目的**：把服装穿到定稿模特身上，产出「试衣图」。

1. 即梦 → **智能画布**：导入定稿模特图 + 服装图（各一个图层）。
2. 用 `prompts.md` §换装模板生成试衣图；服装有多张角度图时一并导入，还原度更高。
3. 批量场景：同一模特 × N 套服装 = 在画布里逐套换服装生成 N 张试衣图；每张都要过质检再进 M4。

**过闸标准**（Agent 读图）：服装**配色/版型/图案/领型**与服装图一致（这是带货的生命线）；脸与定稿模特一致；手部正常；服装边缘无渗色。

## M4 出片（Seedance 2.0）

1. 即梦 → 视频生成 → **全能参考**入口（图片最多 9 张、视频 3 个、音频 3 个，单个 ≤15 秒）。
2. 上传：试衣图（@图片1）、白膜视频（@视频1）。角色一致性靠「同一张试衣图 + 提示词点名」。
3. 提示词按 `prompts.md` §视频动作模板写：**@图片1 是主角，保持 @图片1 的服装与长相；动作与运镜完全跟随 @视频1** + 场景/光线/风格词。
4. 参数：模型 **Seedance 2.0**；比例 9:16；时长先 5–8 秒试；动作强度先中档，动作没跟上再调高。
5. 生成后 Agent 跑 `scripts/qc_frames.py` 抽帧逐帧读。

**过闸标准**：动作与白膜节奏一致、脸不漂移、服装不漂移、无肢体崩坏。
**人脸审核被平台拦截时**的降级口径：改用带货卡点类打码路线（模特图阶段脸部打码，见 `prompts.md` §备注），或改走「首尾帧」入口（首帧=试衣图，尾帧=同图换姿势）规避人脸合成判定。平台规则会变，以当期为准。

## M5 质检与发布包

1. 成片收进 `<选题>/成片/`，ffprobe 记录时长/分辨率进台账。
2. 按 `qc-gates.md` §视频四查出「抽帧质检结论」。
3. 发布包（`<选题>/发布包/`）：成片 mp4 + `发布文案.md`（按 `ops-playbook.md` 模板，含 AI 标注提醒、话题标签、封面建议）。
4. 台账补全：本条视频用的全部提示词、参数、积分消耗、日期。
