# 提示词模板库

> **用法**：`<>` 内是必须从用户素材/需求里抽取的参数位，**禁止拿示例值直接用**（72 号教训：上一期的数值是示范不是默认值）。
> 中文提示词对生成模型语义理解友好，直接用中文。
>
> **路线分叉**：§0 是**入口 ① 默认全自动**（WorkBuddy 内置 `ImageGen` / `VideoGen`，不需要 `@` 引用）；
> §1 起的 `反推提示词 / 白膜化 / 换装 / 视频动作` 是**入口 ② 指定动作版**（即梦网页，用 `@图片1` / `@视频1` 引用素材），暂为占位。

## 0. 默认全自动版提示词（入口 ①）

### 0.1 代生成模特全身照（ImageGen 文生图，1 张）

```
<年龄段><气质>亚洲女装模特，<发型发色>，<身材>，自然裸妆，
正面全身照，自然站立，双臂自然下垂，白色紧身衣打底，
纯色浅灰影棚背景，柔和均匀布光，商业人像摄影风格，
9:16 竖构图，头到脚完整入镜，画面干净，写实
```

参数建议：`size="1024x1536"`、`quality="high"`。
排除：`品牌 logo、文字水印、多余肢体、手指畸形、性暗示姿势、浓妆艳抹`。
**定稿这张就是人物锚点**，之后每套换装都要复用它。

### 0.2 代生成衣服多面拼图（ImageGen × N 套，每套 1 张）

```
2×2 四宫格拼图，四个格子分别是同一件<服装品类>的
【正面平铺】【背面平铺】【侧面/上身侧面】【领口/面料/印花细节特写】，
四格之间留白均匀，格内服装完整不裁切，
纯白背景，电商商品图风格，光线均匀，无人物、无模特、无文字，
颜色与款式：<颜色/图案/版型/领型>
```

三套之间**风格必须明显不同**（例：浅色通勤 / 深色礼服 / 亮色休闲），否则换装视频看不出变化。
同样 `size="1024x1536"`、`quality="high"`；排除 `真人、模特、水印文字、格内混搭其他服装`。

### 0.3 换装试衣图（ImageGen 图生图，每套 1 张）

```
image1 = 模特-定稿.png
image2 = 服装-0X-多面.png

把 image2 四格展示的这件衣服，穿到 image1 的模特身上；
模特的脸、发型、身材、站立姿势与 image1 完全一致，不重画人脸；
服装的配色、版型、图案、领型严格按 image2 正面那一格，
背面与侧面细节与 image2 对应格子一致；
模特正面全身，纯色浅灰背景，商业服装摄影，写实，9:16 竖构图
```

参数：`input_fidelity="high"`、`quality="high"`。
脸若被重画，在提示词末尾追加「脸部与 image1 完全一致，不改变五官」重跑**这一套**（不要连坐其它套）。
排除：`模糊、六指、手部畸形、服装变形、衣服与背景渗色、印花丢失`。

### 0.4 真动片段（可选，VideoGen；默认不开）

对每张试衣图一次：`image=试衣图`、`aspect_ratio="9:16"`、`seconds=2`（或模型支持的最短时长）。

```
模特朝镜头自信走来，自然摆臂，步伐平稳，镜头缓慢跟随平移，
长相与服装与首帧完全一致，不改变服装，
柔和影棚光，写实，画面流畅
```

排除：`模糊、肢体变形、多余手指、面部扭曲、服装变形、闪烁`。
> 开这一档前必须告知积分（约 50–100 分/5 秒片段）。三段生成完交给 `compose_video.py --motion`。

### 0.5 卡点音乐不需要提示词

`beat_music.py` 是程序化合成（4/4 鼓组 + bass + pad + 切点 impact），只调参数不写提示词：
`--segments` 必须等于服装套数，`--bpm` 与 `compose_video.py --seg` 要满足 `seg = 4×60/bpm`。

## 反推提示词（M2 第 1 步，指定动作版）

对参考图让模型输出描述后，按下表整理成结构化提示词。**每项都要与用户确认保留还是改造**：

| 维度 | 抽什么 | 示例口径（仅供格式参考） |
|---|---|---|
| 年龄段 | `<25-30岁 / 30+>` | 25-30岁 |
| 气质脸型 | `<甜美 / 高冷 / 邻家；圆脸 / 瓜子脸>` | 温柔甜美，鹅蛋脸 |
| 发型发色 | `<长发/短发/盘发，黑/棕/挑染>` | 深棕色中长发，空气刘海 |
| 身材 | `<匀称 / 高挑 / 娇小>` | 身材匀称，比例好 |
| 妆容 | `<裸妆 / 精致>` | 自然裸妆 |
| 着装底版 | 固定白色紧身衣（与白膜呼应） | 白色紧身衣 |
| 背景 | 固定纯色 | 纯白色背景 |
| 风格 | 固定 | 商业人像摄影风格，正面全身照，自然站立 |

**合成句式**：`<年龄段><气质>亚洲女装模特，<发型>，<身材>，<妆容>，自然站立姿势，正面全身照，白色紧身衣，<背景>，商业人像摄影风格`。

## 白膜化（M1）

```
人物替换为白色紧身衣人台模型，无面部特征，无发型细节，
动作、运镜、节奏完全参考 @视频1，一镜到底不切镜头，
<背景描述：与参考视频一致或指定影棚纯色背景>，写实风格
```

## 换装（M3，智能画布）

基础版：

```
将 @图片1（服装图）中的衣服穿到 @图片2（模特图）身上，
保持模特的脸、发型、姿势不变，
服装的配色、版型、图案、领型与 @图片1 严格一致，
纯色背景，商业服装摄影
```

要点：服装图有多角度（正面/背面/细节）时全部导入并逐一 @ 引用；试衣后脸若变化，在提示词追加「脸部与 @图片2 完全一致」。

## 视频动作（M4，全能参考 + Seedance 2.0）

**公式**：`[谁/什么] + [做什么] + [在哪/环境] + [光线/风格]`，用 `@` 精确引用素材。

```
@图片1 是主角，长相、发型、服装与 @图片1 完全一致，不改变服装；
动作与运镜完全跟随 @视频1 的节奏：<走姿描述：自信走秀 / 自然摆臂 / 转身定格>；
<环境：<街头 / 影棚 / 客厅 / T台>>，<光线：柔和自然光 / 暖色灯光>；
镜头<运镜：跟随平移 / 缓慢推近 / 环绕>，写实风格，画面流畅
```

**排除词（负面）**：`模糊、肢体变形、多余手指、面部扭曲、服装变形、闪烁`。

**卡点变装变体**（多套服装一条片）：全能参考上传 5–7 张不同服装的试衣图，提示词**分时序**写：`0-2秒 @图片1 日常装…3-5秒 切换到 @图片2 礼服造型，切换卡音乐重拍…`；情绪递进（平实→自信→气场全开）。
