# 提示词模板库

> **用法**：`<>` 内是必须从用户素材/需求里抽取的参数位，**禁止拿示例值直接用**（72 号教训：上一期的数值是示范不是默认值）。
> 中文提示词对生成模型语义理解友好，直接用中文。
>
> **路线分叉**：§0 是**本流程（全自动流水线）**用的提示词（WorkBuddy 内置 `ImageGen` / `VideoGen`，不需要 `@` 引用）；
> §1 起的 `反推提示词 / 白膜化 / 换装 / 视频动作` 是**进阶指定动作版**（即梦网页，用 `@图片1` / `@视频1` 引用素材），暂不启用、**不作为选项展示**。

## 0. 全自动流水线提示词（本流程）

### 0.1 代生成模特全身照（ImageGen 文生图，1 张）

```
<年龄段><气质>亚洲女装模特，<发型发色>，<身材>，自然裸妆，
<机位句：见 §0.6，默认「相机与人物齐平，平视正面全身照，头到脚完整入镜」>，
自然站立，双臂自然下垂，白色紧身衣打底，
纯色浅灰影棚背景，柔和均匀布光，商业人像摄影风格，
9:16 竖构图，画面干净，写实
```

参数建议：`size="1024x1536"`、`quality="high"`。
**`<机位句>` 由第一问之后的 Q3 决定**（§0.6），A1 模特图定下来后，A2 每张试衣图、A4 每段真动片段都复用同一句，一字不改。
排除：`品牌 logo、文字水印、多余肢体、手指畸形、性暗示姿势、浓妆艳抹`。
**定稿这张就是人物锚点**，之后每套换装都要复用它。

### 0.2 代生成衣服多面拼图（ImageGen × N 套，每套 1 张）

```
2×2 四宫格拼图，四个格子分别是同一件<服装品类>的
【正面平铺】【背面平铺】【侧面/上身侧面】【领口/面料/印花细节特写】，
四格之间留白均匀，格内服装完整不裁切，
纯白背景，电商商品图风格，光线均匀，无人物、无模特、无文字，
颜色与款式：<颜色/图案/版型/领型>
```

三套之间**风格必须明显不同**（例：浅色通勤 / 深色礼服 / 亮色休闲），否则换装视频看不出变化。
同样 `size="1024x1536"`、`quality="high"`；排除 `真人、模特、水印文字、格内混搭其他服装`。

### 0.3 换装试衣图（ImageGen 图生图，每套 1 张 / `POSE_MODE=single`）

```
image1 = 模特-定稿.png
image2 = 服装-0X-多面.png

把 image2 四格展示的这件衣服，穿到 image1 的模特身上；
<机位句：与 image1 完全一致，见 §0.6>；
模特的脸、发型、身材、站立姿势与 image1 完全一致，不重画人脸；
服装的配色、版型、图案、领型严格按 image2 正面那一格，
背面与侧面细节与 image2 对应格子一致；
纯色浅灰背景，商业服装摄影，写实，9:16 竖构图
```

参数：`input_fidelity="high"`、`quality="high"`。
**`<机位句>` 必须取 §0.6 里 Q3 选的那一句，与 A1 模特图一字不差**；跨套串机位（一张俯拍一张平视）一票否决。Q3 选「复刻截图」时改用 §0.6 的「保机位」模板。
脸若被重画，在提示词末尾追加「脸部与 image1 完全一致，不改变五官」重跑**这一套**（不要连坐其它套）。
排除：`模糊、六指、手部畸形、服装变形、衣服与背景渗色、印花丢失、机位与参考图不一致`。

#### 0.3.1 多姿势变体（`POSE_MODE=multi`，每套 3 张）

**只替换上面模板里「姿势」那一句，脸 / 发型 / 服装 / 背景描述一字不改** —— 这是跨姿势仍是同一个人、同一件衣服的关键。默认 3 个姿势（`POSES` 可扩）：

| # | 姿势 | 替换进去的姿势句 |
|---|---|---|
| 1 | 站立 | `模特正面全身站立，双臂自然垂放，重心平稳` |
| 2 | 叉腰 | `模特单手叉腰，重心微侧，身体略微转向一侧，仍为正面可见的全身构图` |
| 3 | 回眸 | `模特侧身站立后回头看向镜头，肩膀转向镜头，全身完整入镜` |

```
把 image2 四格展示的这件衣服，穿到 image1 的模特身上；
模特的脸、发型、身材与 image1 完全一致，不重画人脸；
<姿势句>；
服装的配色、版型、图案、领型严格按 image2 正面那一格，
背面与侧面细节与 image2 对应格子一致；
纯色浅灰背景，商业服装摄影，写实，9:16 竖构图，头到脚完整入镜
```

**每套 3 张必须复用同一张 `image1` 定稿模特图 + 同一张 `image2` 衣服拼图**，只换姿势句。出场顺序按套分组（01 站立/叉腰/回眸 → 02 站立/叉腰/回眸 → 03 …），一套衣服连拍 3 个镜头再切下一套。
过闸加查：同一套 3 张脸一致、衣服一致、姿势确实有差异；姿势没变出来只重跑那一张。
参数不变：`input_fidelity="high"`、`quality="high"`；排除词同上，另加 `姿势与上一张雷同`。

### 0.4 真动片段（`MOTION_MODE=video` 才开，默认不开）

对**每个出场镜头**一次：`image=<该镜头试衣图>` 作首帧、`aspect_ratio="9:16"`、`seconds` 取模型支持的最短值（生成 5s 也没关系，`compose_video.py` 会 `trim` 到 `--seg`）。段数 = `SHOTS`：C 档 3 段、D 档 9 段。

```
模特朝镜头自信走来，自然摆臂，步伐平稳，镜头缓慢跟随平移，
长相与服装与首帧完全一致，不改变服装，
柔和影棚光，写实，画面流畅
```

排除：`模糊、肢体变形、多余手指、面部扭曲、服装变形、闪烁`。
> 开这一档前**必须告知积分**：`VideoGen` 约 50–100 分/5 秒片段 —— C 档 3 段 ≈ 150–300 分，D 档 9 段 ≈ 450–900 分，且每段等 1–3 分钟。全部生成完按出场顺序交给 `compose_video.py --motion`（数量必须与 `--images` 一致）。
> 多姿势全开（D 档）时，9 张试衣图各出 1 段；**不要**只给每套的主姿势出片，否则 `--motion` 段数与图片数对不上。

### 0.5 卡点音乐不需要提示词

`beat_music.py` 是程序化合成（4/4 鼓组 + bass + pad + 切点 impact），只调参数不写提示词：

- `--segments` 必须等于 **SHOTS（出场镜头数）**，不是服装套数：A/C 档 3、B/D 档 9。
- `--seg`：single 档 2.0s（= `4×60/bpm`，一小节）；multi 档 **1.0s（120BPM 的 2 拍，仍落在拍线上）**，切得更密、节奏更强。
- `--bpm` 与 `--seg` 只要满足「`seg` 是单拍 `60/bpm` 的整数倍」就卡拍；不是一小节（4 拍）时脚本不再误报。

### 0.6 拍摄角度（Q3 的机位句模板）

> 机位由第一问之后的 **Q3「什么拍摄角度」** 决定，缺省是平视正面全身。
> **机位句必须一字不改地写进 A1 模特图、A2 每张试衣图、A4 每段真动片段**；跨套串角度一票否决。

| 角度 | 机位句（替换 §0.1 / §0.3 里的 `<机位句>`） |
|---|---|
| 平视全身（缺省） | `相机与人物齐平，平视正面全身照，头到脚完整入镜，构图平稳` |
| **俯拍（头顶向下）** | `镜头位于人物头顶上方、从上向下俯拍，模特抬头看向镜头，上身微微前倾靠近镜头，单手叉腰，另一手自然下垂` |
| 45° 斜俯 | `镜头在人物斜上方约 45° 向下拍，模特微微抬头看向镜头，全身完整入镜，画面有纵深` |
| 仰拍 | `低机位从下向上仰拍，模特全身入镜，气场强；注意避免脸部与腿部透视变形` |
| **复刻截图** | 不写文字机位句 —— 以用户给的截图作 `image1`，改用下面「保机位」模板，机位 / 构图 / 人物位置严格照抄 |

**复刻截图 / 换装保机位模板**（截图当 `image1` 时用，脸绝不被重画；下面的姿势、发型、背景要从用户截图里抽，别照抄示例）：

```
保持 image1 画面完全不变：俯拍机位、镜头在人物头顶上方从上向下拍、
模特抬头看向镜头、单手叉腰、另一手扶裙、上身微微前倾、披肩长直黑发、
脸与五官、浅灰白色影棚背景、构图与人物位置，全部严格保持与 image1 一致，
脸绝不被重画。
只把服装替换为 image2 展示的这件衣服，服装配色/版型/图案/领型严格按 image2。
```

> 上面「俯拍 + 保机位」是实测还原度最高的一版，起号类俯拍换装视频可直接套。
> 衣服款式是示范位，从用户素材里抽，别写死：`<方领、公主泡泡袖、胸下收褶的短款上衣，搭配高腰包臀半身裙、裙长在膝上方>`。
> 俯拍等非平视机位对提示词最敏感：生成后必须逐张 `ViewImage` 核机位；脸若被重画，追加「脸部与 image1 完全一致，不改变五官」**只重跑这一套**。
> Q4 选「只要图片」时，§0.4 真动片段不用生成，但 §0.6 的机位句仍要写进每张试衣图。

## 反推提示词（M2 第 1 步，进阶指定动作版）

对参考图让模型输出描述后，按下表整理成结构化提示词。**每项都要与用户确认保留还是改造**：

| 维度 | 抽什么 | 示例口径（仅供格式参考） |
|---|---|---|
| 年龄段 | `<25-30岁 / 30+>` | 25-30岁 |
| 气质脸型 | `<甜美 / 高冷 / 邻家；圆脸 / 瓜子脸>` | 温柔甜美，鹅蛋脸 |
| 发型发色 | `<长发/短发/盘发，黑/棕/挑染>` | 深棕色中长发，空气刘海 |
| 身材 | `<匀称 / 高挑 / 娇小>` | 身材匀称，比例好 |
| 妆容 | `<裸妆 / 精致>` | 自然裸妆 |
| 着装底版 | 固定白色紧身衣（与白膜呼应） | 白色紧身衣 |
| 背景 | 固定纯色 | 纯白色背景 |
| 风格 | 固定 | 商业人像摄影风格，正面全身照，自然站立 |

**合成句式**：`<年龄段><气质>亚洲女装模特，<发型>，<身材>，<妆容>，自然站立姿势，正面全身照，白色紧身衣，<背景>，商业人像摄影风格`。

## 白膜化（M1）

```
人物替换为白色紧身衣人台模型，无面部特征，无发型细节，
动作、运镜、节奏完全参考 @视频1，一镜到底不切镜头，
<背景描述：与参考视频一致或指定影棚纯色背景>，写实风格
```

## 换装（M3，智能画布）

基础版：

```
将 @图片1（服装图）中的衣服穿到 @图片2（模特图）身上，
保持模特的脸、发型、姿势不变，
服装的配色、版型、图案、领型与 @图片1 严格一致，
纯色背景，商业服装摄影
```

要点：服装图有多角度（正面/背面/细节）时全部导入并逐一 @ 引用；试衣后脸若变化，在提示词追加「脸部与 @图片2 完全一致」。

## 视频动作（M4，全能参考 + Seedance 2.0）

**公式**：`[谁/什么] + [做什么] + [在哪/环境] + [光线/风格]`，用 `@` 精确引用素材。

```
@图片1 是主角，长相、发型、服装与 @图片1 完全一致，不改变服装；
动作与运镜完全跟随 @视频1 的节奏：<走姿描述：自信走秀 / 自然摆臂 / 转身定格>；
<环境：<街头 / 影棚 / 客厅 / T台>>，<光线：柔和自然光 / 暖色灯光>；
镜头<运镜：跟随平移 / 缓慢推近 / 环绕>，写实风格，画面流畅
```

**排除词（负面）**：`模糊、肢体变形、多余手指、面部扭曲、服装变形、闪烁`。

**卡点变装变体**（多套服装一条片）：全能参考上传 5–7 张不同服装的试衣图，提示词**分时序**写：`0-2秒 @图片1 日常装…3-5秒 切换到 @图片2 礼服造型，切换卡音乐重拍…`；情绪递进（平实→自信→气场全开）。
