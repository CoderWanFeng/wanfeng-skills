# 质检闸与合规

> **原则**：Agent 必须亲眼读图（Read/ViewImage），不能只听用户说「还行」。每次质检落「结论 + 证据帧」。

## 0. 本流程专用质检（全自动流水线）

> **口径**：`SHOTS = 套数 × 姿势数`（single 档 = GARMENTS、multi 档 = GARMENTS × POSES），`SEG = 2.0s(single) / 1.0s(multi)`。下表里的 N 一律指 **SHOTS（出场镜头数）**，不是服装套数。
> **机位口径**：5 项问答里 Q3 选定的 `CAMERA_ANGLE` 一旦定下，A1 / A2 / A4 所有产物必须是同一个机位；跨套串角度一票否决（俯拍尤其容易翻车）。

| 阶段 | 查什么 | 不合格处理 |
|---|---|---|
| A1 资产 | **`1 + GARMENTS` 张齐全**：1 张模特全身照 + GARMENTS 张衣服多面拼图；模特图头到脚完整、纯色背景、**机位与 Q3 一致**；每套拼图**四格齐全且是同一件衣服** | 只重生成不合格的那一张 |
| A2 试衣 | **SHOTS 张**试衣图，脸与定稿模特一致、**机位与 Q3 一致**；**每张服装配色/版型/图案与对应拼图正面格一致**（一票否决）；各套视觉差异明显。**multi 档加查**：同一套 3 个姿势必须是同一张脸、同一件衣服、**同一个机位**，且姿势确实不同 | 只重跑那一张，带上「哪里不像」改提示词；姿势没变出来重跑该姿势；串机位只重跑该张 |
| A3 音乐 | `beat-report.json` 的 `cut_points` = `[seg, 2×seg, …]`；音乐时长 = `SHOTS × seg`；切点有 impact | 重跑 `beat_music.py`，`--segments` 必须等于 SHOTS |
| A4 成片 | `compose-report.json`：时长 = `SHOTS × SEG`、1080×1920、有 aac 音轨、`faststart=true`；**`motion_source` 与本次组合一致**；video 档 `--motion` 段数 = SHOTS | 检查 `--seg` 是否为单拍整数倍；重跑 `compose_video.py` |
| A5 抽帧 | 逐帧查脸部漂移、**机位跨镜头一致**、服装跨套串色、切点是否干净、无黑帧；**video 档另查首帧与试衣图一致、动作流畅无崩坏** | 系统性漂移 → 回 A2 重跑；个别崩坏帧剪掉或重跑该段 |

**本流程额外四条**：

1. 静帧动效不是「模特真的在走」；用户要真走必须 Q5 开 `MOTION_MODE=video`，并在开工前告知积分。不许拿静帧动效冒充走秀。
2. Q6 的「多姿势」是**静帧图切得更快**，不是模特在动；要「边走边换姿势」只能 Q5+Q6 都开，不许含糊其辞。
3. video 档逐段核首帧：跨镜头换脸、串衣服、**串机位**一票否决，只重跑那一段 VideoGen。
4. 机位句必须逐张核对（尤其俯拍 / 复刻截图）：脸被重画追加「脸部与 image1 完全一致」只重跑这一套，不要连坐其它套。

## 图四查（模特图 / 试衣图）

| # | 查什么 | 不合格的常见表现 | 处理 |
|---|---|---|---|
| 1 | 人脸一致性 | 与定稿模特五官/脸型不符（换装时脸被重画） | 提示词加「脸与 image1 完全一致」重生成 |
| 2 | 服装还原 | 配色/版型/图案/领型与服装图不一致、印花丢失变形 | 服装图多角度补齐再重试；带货场景此项一票否决 |
| 3 | 肢体手指 | 六指、手指粘连、关节反折、腿部穿插 | 调整提示词排除词，只重跑该张 |
| 4 | 边缘瑕疵 | 衣服与背景渗色、边缘锯齿、配饰悬空 | 指明瑕疵位置，只重跑该张 |

## 视频四查（qc_frames.py 抽帧后逐帧读）

| # | 查什么 | 说明 |
|---|---|---|
| 1 | 脸部漂移 | 首帧 vs 中段 vs 尾帧：五官是否始终是同一个人；video 档重点查真动片段 |
| 2 | 服装漂移 | 图案/颜色/版型跨帧是否稳定；裙摆衣服是否中途变形 |
| 3 | 动作与动效 | video 档检查行走、摆臂是否自然，有无多余动作；static 档检查推近与切点是否正常 |
| 4 | 崩坏帧 | 手指崩坏、肢体穿模、画面闪烁（可剪掉或重跑） |

**结论分级**：全过 → 进 A5 发布包；个别崩坏帧 → 剪掉可用段或重跑该段；系统性漂移 → 按问题来源回 A2 或 A4 改提示词参数重跑，不许带病发布。

## 台账（`<选题>/台账.json`）

每次生成登记：`{ "阶段": "A2", "素材": "试衣-01.png", "提示词": "…", "参数": {"工具":"ImageGen 图生图","比例":"9:16","套数":3,"BPM":120}, "问答": {"SOURCE":"generated","GARMENTS":3,"CAMERA_ANGLE":"top","NEED_VIDEO":"yes","MOTION_MODE":"static","POSE_MODE":"multi"}, "档位": {"SHOTS":9,"SEG":1.0}, "结果": "过/第3次过", "积分": 0, "日期": "2026-11-23" }`。
**`问答` 字段必填**（第一问素材来源 + 之后 5 项：`SOURCE` / `GARMENTS` / `CAMERA_ANGLE` / `NEED_VIDEO` / `MOTION_MODE` / `POSE_MODE`），否则复现时不知道当时用的什么机位、切了几个镜头、有没有开真走；`档位` 记 `SHOTS` / `SEG`；video 档另记每段 VideoGen 的提示词与积分。
本流程阶段只写 `A1–A5`，工具写 `ImageGen` / `VideoGen` / `beat_music.py` / `compose_video.py`。
**价值**：迭代提示词时知道上一版错在哪；起号后哪条爆了能复现。

## 合规红线（发布前逐条打勾）

1. **AI 标注**：抖音/视频号/小红书发布时开启「AI 生成内容」标识——不标注有限流、下架、处罚风险。
2. **肖像权**：模特参考图必须有权使用；真人照片造模特须本人同意；**绝不**用明星/网红脸做商业带货。
3. **不冒充真人**：文案/评论区不得谎称真人实拍；账号简介注明 AI 内容。
4. **服装图权利**：自有商品或已授权；别家商品图直接带货有侵权风险。
5. **内容尺度**：展示类视频避免擦边运镜与文案（平台对「AI美女」类目审核最严的是擦边，不是 AI 本身）。
