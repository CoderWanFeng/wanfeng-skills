# 晚枫AI模特（wanfeng-ai-model）

> **一句话**：参考图 → 专属模特 → 多套衣服上身 → 卡点音乐 → 一条能直接发的换装短片。
>
> **两条路线，入口一次选清**：
> **① 默认全自动**（本次已做好，可直接测）：不打开任何网页，素材我也能代生成，换装 / 音乐 / 合成一条龙跑完，直接给 mp4。
> **② 我指定动作**（占位，下一步再做）：用户给动作参考视频 → 白膜化 → 即梦 Seedance 2.0 驱动，Agent 陪跑、逐帧质检。
>
> **模型名必须准确**：教程里说的「CDS2.0」实为字节 **Seedance 2.0**（即梦 AI 内使用），**只在入口 ② 使用**；默认版用 WorkBuddy 内置生成能力，不要许诺 Seedance。

## 一、何时使用

- 「帮我做 AI 模特试衣视频」「让 AI 模特穿上这件衣服走一段」
- 「白膜视频」「把这视频里的人换成我的 AI 模特」
- 「批量生产模特视频 / 一套模特配 N 套衣服」「卡点换装视频」
- 「AI 美女账号起号，教我做这种视频」

**不适用**：真人口播混剪 → `晚枫自动剪视频-Pro`；口播数字人 → `wanfeng-digital-human(-pro)`；给已剪好的视频加包装 → `晚枫自动剪视频`。本 Skill 出的是**无口播、纯画面**的模特展示视频。

## 二、入口二选一（一次列全，选一次，不二次追问）

| 入口 | 状态 | 去哪 |
|---|---|---|
| **① 默认全自动** | ✅ 已实现，可测 | `references/auto-pipeline.md`（本 Skill 的主路径） |
| **② 我指定动作** | ⏳ 占位，下一步启用 | `references/workflow.md` |

选 ① 时再确认一次即可开工（**其余一律走默认，别拆成多轮追问**）：

| 项 | 用户动作 | 默认值 |
|---|---|---|
| 模特全身照 | 上传 1 张 / 说「生成」 | 没给 → 我代生成 1 张 |
| 衣服多面图 | 上传 N 套，每套 1 张多面拼图 / 说「生成」 | 没给 → 我代生成 **3 套** |
| 比例 / 时长 / BPM | 可指定 | **9:16 1080×1920 / 每套 2.0s / 120 BPM**（3 套 = 6.0s） |
| 是否让模特真走起来 | 可指定 | **默认静帧推近动效**（省成本、跑得快）；要真动再开 |

## 三、默认全自动：4 张图 → 一条片

**资产规格（合计 4 张）**

| 资产 | 数量 | 规格 |
|---|---|---|
| 模特全身照 | **1 张** | 9:16 正面全身、自然站立、纯色背景、白色紧身底版、商业人像 |
| 衣服多面拼图 | **每套 1 张 × 3 套** | 一张 2×2 四宫格：**正面 / 背面 / 侧面 / 细节特写**，白底、无模特、同一件衣服 |
| 合计 | **1 + 3 = 4 张** | 一套衣服多个面合成一张图，四个角度一起喂换装，还原度最高 |

> 「一套衣服多个面是一张照片」—— 面数定为 **4**（2×2 四宫格）；套数默认 **3**（你说的最少三套），参数可配置，起号卡点变装可扩到 5–7 套。

**五个自动阶段**

```
A1 素材归位 / 代生成   → 有就上传；没有就代生成 1 张模特 + 3 张衣服多面拼图（共 4 张）
A2 自动换装            → 每套衣服穿到同一张定稿模特身上 → 3 张试衣图
A3 卡点音乐            → 程序化合成（4/4 鼓组 + bass + pad + 切点 impact），不用外部音源
A4 合成短片            → 静帧推近动效（默认）/ VideoGen 真动片段（可选）→ 硬切卡点 → 音乐 → mp4
A5 质检与发布包        → 抽帧逐帧读 → ffprobe 复核 → 发布文案 → 台账
```

关键可执行命令（细节见 `references/auto-pipeline.md`）：

```bash
# A3 卡点音乐（纯 numpy，无需第三方音频库）
python3 scripts/beat_music.py --out <选题>/音乐/卡点音乐.wav --segments 3 --bpm 120

# A4 合成（3 张试衣图 + 音乐 → 6 秒 9:16 成片，自动 -14 LUFS + faststart）
python3 scripts/compose_video.py --images 试衣-01.png 试衣-02.png 试衣-03.png \
    --music 卡点音乐.wav --out 换装成片.mp4 --seg 2.0 --bpm 120

# A5 抽帧质检
python3 scripts/qc_frames.py <成片.mp4>
```

**两条硬约束**

1. **换装必须复用同一张定稿模特图** —— 跨套、跨条人物一致全靠它；换脸等于重新起号。
2. **生成前告知积分** —— `ImageGen` 约 5–10 分/张（代生成最多 4 张 ≈ 20–40 分）；开 `--motion` 用 `VideoGen` 约 50–100 分/5 秒片段（3 段 ≈ 150–300 分，且每段等 1–3 分钟）。**用户确认后才调用**。

## 四、指定动作版（占位，下一步做）

用户给动作参考视频 → 白膜化（只留动作运镜、人物形象清零）→ 专属模特 → 画布换装 → 全能参考 + **Seedance 2.0** 出片 → 抽帧质检 → 发布包。五阶段闸 M1–M5 的完整 SOP 已写在 `references/workflow.md`，**暂不启用**，等默认版测完再接。

## 五、质检（Agent 必须亲眼读图，不能只听用户说）

- **图**：`ViewImage` 读模特图 / 衣服拼图 / 试衣图，按 `references/qc-gates.md` 图四查（人脸一致 / 服装还原 / 肢体手指 / 边缘瑕疵）。服装还原不合格**一票否决**，只重跑那一套。
- **视频**：`scripts/qc_frames.py` 抽帧 → 逐帧读，查脸部漂移、服装跨套串色、切点是否干净。
- **技术复核**：`ffprobe` 查时长 = `N × 2.0s`、1080×1920、有音轨、`moov` 在前。
- 台账 `<选题>/台账.json` 登记每次提示词、参数、积分、日期、质检结论。

## 六、合规红线（发布前最后一道闸）

1. **AI 内容标识**：发布时打开平台「内容由 AI 生成」标注，不标注有限流与处罚风险。
2. **肖像权**：上传的真人照片造模特须取得本人同意；代生成的 AI 脸无此问题；**绝不**用明星/网红脸带货。
3. **不冒充真人**：文案不得暗示真人实拍，账号简介注明 AI 内容。
4. **服装图权利**：代生成的是虚构款可直接用；上传别家商品图带货需自有或授权。
5. **内容尺度**：避免擦边运镜与文案 —— 平台审「AI 美女」类目最严的是擦边，不是 AI 本身。

## 七、起号打法

批量节奏、卡点变装（5–7 套一条片）、发布文案模板、数据复盘 → `references/ops-playbook.md`。
核心口径：**一套定稿模特是资产**，配 N 套服装就是 N 条视频。

## 八、已知限制（对用户坦白）

1. 默认全自动用 WorkBuddy 内置 `ImageGen` / `VideoGen`：**调用前必须告知积分消耗**，生成要等 1–3 分钟。
2. `VideoGen` **没有模型参数**，默认版无法指定 Seedance 2.0；Seedance 2.0 只属于入口 ②（即梦网页，Agent 不能代点）。
3. 默认不开发真动时画面是**静帧推近动效**，不是模特真的在走；要「走来走去」需开 `--motion`，成本明显上升。
4. 手指、服饰细节、人脸跨帧一致性是模型弱项，抽帧质检是硬要求不是可选项。
5. 平台审核规则会变，人脸触发审核时的降级口径见 `references/workflow.md` §M4，发布前以当期规则为准。
