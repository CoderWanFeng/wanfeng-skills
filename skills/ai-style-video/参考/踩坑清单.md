# 踩坑清单

实操中真实踩过的坑，按「症状 → 原因 → 解法」记录。改风格、换选题前先扫一遍。

## 1. 截图放进视频就糊

**症状**：官网截图放进 1080 宽视频后，小字几乎读不清。

**原因**：截图是 1x（1396 宽），裁切后要缩到 0.65x 塞进 1080 宽，**二次降采样**。

**解法**：
```javascript
deviceScaleFactor: 2   // 输出 2792 宽，缩放比升到 0.78x
```
再把裁切框收到「刚好装下证据」的宽度。

**判据**：缩放比 < 0.75x 就别用这张图。

## 2. 自动补丁把绘制语句删了

**症状**：打完补丁后画面只剩背景和几条线，所有文字、卡片、截图全没了。

**原因**：补丁用正则匹配 `base.alpha_composite(layer, (xx, yy))` 这一行，然后把它**替换**成了检测登记代码：
```python
# 错误做法：old_string 被 new_string 取代
s.replace("    base.alpha_composite(layer, (xx, yy))\n",
          "    register_layer_texts(GUARD, layer, x, y, a)\n")
```

**解法**：检测登记必须**追加**在绘制语句之后：
```python
    base.alpha_composite(layer, (xx, yy))
    register_layer_texts(GUARD, layer, x, y, a)
```

**自检**：打完补丁立刻 grep 确认绘制语句还在：
```bash
grep -c "base.alpha_composite(layer, (xx, yy))" 各渲染器
```

## 3. lru_cache 让多张卡片的文字叠在一起

**症状**：5 张步骤卡片全显示最后一张的标题，重叠成一团。

**原因**：
```python
@lru_cache(maxsize=256)
def shadow_card(w, h, ...):
    ...
    return im, pad     # ← 每次返回同一个对象
```
调用方在卡片上 `alpha_composite(文字)`，等于往同一个对象上反复画字。

**解法**：只缓存**不变的部分**（阴影层），卡片每次新建：
```python
@lru_cache(maxsize=256)
def _shadow_layer(w, h, radius, blur, alpha):
    return shadow_image, pad

def shadow_card(w, h, ...):
    sh, pad = _shadow_layer(w, h, radius, blur, alpha)
    im = Image.new("RGBA", sh.size, (0, 0, 0, 0))
    im.alpha_composite(sh)
    c = Image.new("RGBA", (w, h), (0, 0, 0, 0))
    ...  # 卡片面
    return im, pad
```

**判据**：凡是「返回后还要往上面画东西」的函数，都不能整体缓存。

## 4. 半透明填充把字盖成实心块

**症状**：高亮框区域变成一块纯绿/纯色，字完全看不见。

**原因**：在 RGB 图上 `draw.rounded_rectangle(..., fill=(r,g,b,alpha))`，**alpha 被忽略**。

**解法**：在 RGBA 图上做叠加：
```python
ov = Image.new("RGBA", im.size, (0, 0, 0, 0))
od = ImageDraw.Draw(ov)
od.rounded_rectangle((x0, y0, x1, y1), 10, fill=hcolor + (30,))
od.rounded_rectangle((x0, y0, x1, y1), 10, outline=hcolor + (255,), width=5)
im = Image.alpha_composite(im.convert("RGBA"), ov).convert("RGB")
```

## 5. 亮版证据图反反了

**症状**：白底表格变成暗底，灰底卡片翻成浅底——正好反了。

**原因**：无脑反相。但官网页面本来就有两种底色。

**解法**：先判断底色均值再决定：
```python
mean = ImageStat.Stat(im.convert("L")).mean[0]
if mean < 128:
    # 暗底 → 反相，并把灰底压向暖白
    r = r.point(lambda v: min(255, int(v * 0.88 + 40)))
else:
    # 亮底 → 只做暖调
```

## 6. 证据图文件名带 .png 时找不到

**症状**：`FileNotFoundError: 证据图不存在：E09-xxx.png`。

**原因**：查找函数按「基础名 + 后缀」拼接，传入值已带 `.png` 就变成 `E09-xxx.png.png`。

**解法**：同时兼容两种形式：
```python
stem = name[:-4] if name.endswith(".png") else name
order = [stem + "-亮.png", stem + ".png"] if prefer_light else [stem + ".png", stem + "-亮.png"]
```

## 7. 场景切换时文字重影

**症状**：转场那一帧，标题出现两层叠影。

**原因**：当前场景淡出 0.26s，下一场入场 0.26s，有 0.02s 时间窗两层同时存在。

**解法**：出场先淡完再入场，且场景之间留空隙：
```python
a = fin(t - start, 0.26)
if t > start + dur - 0.26:
    a *= fout(t - (start + dur - 0.26), 0.26)
```
```python
SCENES = [
    (0.00, 3.20, sc_hook),
    (3.46, 3.24, sc_proof),   # 3.20 + 0.26 = 3.46，无缝衔接
    ...
]
```

## 8. 全图噪点把画面压黑

**症状**：D 故障艺术版整屏变暗，字几乎看不见。

**原因**：
```python
base = ImageChops.add(base, noise_rgb, scale=2.6, offset=-10)
```
`ImageChops.add` 带 scale 时，**结果是 (a + b) / scale**——等于把整屏亮度除以 2.6。

**解法**：噪点必须做成**稀疏亮点**（大部分透明），再用 scale=1 直接叠加：
```python
im = Image.new("L", (W, H), 0)
for _ in range(9000):
    px[x, y] = random.randint(90, 255)   # 只点亮少量像素
base = ImageChops.add(base, Image.merge("RGB", (nl, nl, nl)))   # 不带 scale
```

## 9. 证据图缩到 60px 高，小字全糊

**症状**：一张卡里并排三张证据图，看不清写了什么。

**原因**：为了排版把证据图缩到 60px 高。

**解法**：证据图显示高度**不低于 150px**，并相应加高卡片（206 → 222）。或者干脆不用截图，改用大字号数字 + 文字说明。

## 10. timeout 命令在 zsh 不可用

**症状**：`zsh:1: command not found: timeout`，且循环里的命令全部静默失败。

**解法**：macOS 默认 shell 是 zsh，没有 `timeout`。直接跑，或用 `gtimeout`（coreutils）。

## 11. 官网首页内容会变

**症状**：同一个选题隔几天做，首页 Hero 标题不一样了（产品从 2.0 跳到 2.5）。

**原因**：官网在更新。

**解法**：每次选题重新截，不要复用旧的截图文件。文案里的产品描述也要跟着更新。

## 12. 裁切框写死像素坐标，换人素材就对不上

**症状**：示例里裁得刚刚好，换一张官网截图就裁到无关区域，甚至裁出一个空块。

**原因**：`(0, 700, 1396, 820)` 这类框只对当初那张截图的分辨率成立。别人的截图宽 1440 还是 2880，同一个像素坐标指向完全不同的位置。

**解法**：把框写成 **0–1 的比例**，如 `(0.05, 0.50, 0.95, 0.58)`。mgkit 和切图工具都认两种写法，比例会按实际图尺寸换算（见 `mgkit._fit_box`）。

## 13. 素材还没到位，渲染直接崩

**症状**：新建的工程一张图都还没截，跑 `--preview` 报 `FileNotFoundError`，连版式都看不到。

**原因**：取图函数把“没图”当错误抛了。

**解法**：缺图返回一张写着「素材待补」的占位卡，只告警不抛异常；渲染完统一报「缺失素材」清单。

两个要注意的点：
- 占位卡**不能**打 `mark_text_layer` 标记，否则一缺图就全是假重叠报错。
- 清单必须按「该放进哪个目录」分组，因为 A–E 要的是 `素材-官网截图-HD/` 里的大图，F–H 要的是 `素材-证据图/` 里裁好的小图。

## 14. 字体路径与 ttc 序号写死，换机器就换字形

**症状**：在自己电脑上好好的，另一台机器上字全变成默认字体，版式全对不上；或者 `.ttc` 取了 index=0 拿到常规体，你以为那是粗体。

**原因**：两个坑叠在一起。① 路径写死了系统目录，Linux / Windows 上不存在；② `.ttc` 是字体集合，必须带 index，而同一套字体在不同系统里 index 完全不同。

**解法**：按**角色**要字体（`sans_bold` / `serif_regular` …），由 `mgkit/fonts.py` 逐候选试，支持 `MG_FONT_*` 环境变量覆盖。

**为什么品牌字体单独分一档**：一开始让所有黑体角色都优先取用户装的品牌字体，结果装了那款字体的机器上，本来用系统黑体的风格全部悄悄换了字形，字宽一变版式就得重排。现在只有显式写了 `brand_*` 的风格会去找品牌字体，没装就退回系统黑体。

**判据**：所有字体解析失败时必须**报错并告诉该导出哪个环境变量**，不能默默退回系统字体——静默退回会让别人在你看不到的机器上把片做坏。

## 15. 拼贴风暗角太重像烛光

**症状**：复古版四边发黑，像在烛光下看纸。

**原因**：暗角遮罩内缩 70px + 高斯模糊 130px + 暗色压到 `(120,104,78)`。

**解法**：内缩放大到 58px、模糊 200px、暗色抬到 `(176,162,134)`，噪点幅度也降下来。

## 16. 暖色版反相后是灰底

**症状**：证据图在奶油色画面上是灰块，很割裂。

**原因**：反相后原深灰卡片变成中灰，和奶油色差太远。

**解法**：反相后把中间调压向暖白：
```python
r = r.point(lambda v: min(255, int(v * 0.88 + 40)))
g = g.point(lambda v: min(255, int(v * 0.83 + 36)))
b = b.point(lambda v: min(255, int(v * 0.76 + 30)))
```

## 17. 检测器误报

**症状**：所有帧都报文字重叠。

**原因**：入场动画期间元素半透明，两层短暂共存。

**解法**：alpha < 0.25 的元素不参与判定；卡片内部文字按 shadow padding 换算绝对坐标再判。

## 18. mgkit 检测器必须自测

**症状**：不知道检测器到底有没有在工作。

**原因**：没有验证就相信「全绿」。

**解法**：造三个用例验证——
1. 故意重叠 38% → 必须检出
2. 不重叠 → 必须通过
3. 重叠但 alpha=0.1 → 必须不误报

```python
g = OverlapGuard(1080, 1920, text_thresh=0.015)
g.reset()
register_layer_texts(g, a, 100, 300, 1.0)
register_layer_texts(g, b, 200, 350, 1.0)   # 重叠
assert g.check("t=1.0"), "检测器失效"
```

**规律**：任何自动化检查工具，上线前必须先造反例证明它能报错。
