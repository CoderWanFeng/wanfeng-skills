# 晚枫AI动画（ai-style-video）

给**任何选题**做竖屏 MG 样片：产品新版速览、功能教程、价格拆解、事件解读、原理科普都行。
不挑题材，只挑素材——只要有能讲清楚的事实 + 能截图的证据，8 种风格任选。

**交付边界**：只出**静音样片**（MP4 + 关键帧检查图 + 重叠检测报告）。配音、字幕烧录、时间轴对齐不在范围内。

> 下文用 `<Skill>` 指代本 Skill 的根目录，用 `<选题>` 指代正在做的这条工程目录。

---

## 开始前必须先问用户的两件事

**顺序不能倒**。风格决定素材规格，先问素材会把人问懵。

### 第 1 步：选风格

把下面这张表原样给用户（不要只列名字），让 TA 拍板。**不要替用户定风格。**

| 代号 | 风格 | 底色 | 字体 | 核心动效 | 气质 | 适合 |
|---|---|---|---|---|---|---|
| A | 深色科技 | `#0A0E14` | 品牌斜体（可退回黑体） | 淡入淡出、错峰 | 冷静专业 | 硬核评测、API 教程 |
| B | 亮色杂志 | `#F7F5F0` 米白 | 黑体正体 | 弹性回弹、遮罩擦除 | 亲切生活化 | 泛用户、工具推荐 |
| C | 复古拼贴 | 牛皮纸 | 衬线 | 盖章、打字机、手绘圈画 | 手作有故事 | 系列片头、想撞脸都难 |
| D | 故障艺术 | 深空 + 噪点 | 黑体 + 乱码 | 解码显现、RGB 色差、信号撕裂 | 锐利实验 | 封面、前 3 秒钩子 |
| E | 8-bit 像素 | 深蓝 + 抖动 | 5×7 点阵 + 黑体 | 精灵、血条、金币雨 | 好玩想玩 | 泛用户、破圈 |
| F | 暖色治愈 | 奶油 | 黑体 | 阻尼弹簧、软体挤压、柔光 | 温暖亲和 | 生活向、日常场景 |
| G | 简笔画 | 纸白 + 点阵 | 黑体 | 线稿逐笔长出、boil 抖动 | 白板讲解感 | 教程、原理拆解 |
| H | 工笔重彩 | 绢本米黄 | 衬线标题 + 黑体小字 | 三矾九染叠色、落印、圈点 | 雅致重彩 | 国潮调性、系列封面 |

拿不准时的默认推荐：**讲价格/参数/对比 → A 或 D；讲怎么用 → B / F / G；要辨识度 → C 或 H。**
详细参数见 `参考/风格库.md`。

停下来等用户回答。用户说"你来定"，就按上面这条默认规则选一个并**说明理由**，再往下走。

### 第 2 步：按风格要素材

风格定了，素材清单就定了。两种规格：

**A / B / C / D / E —— 要 3 张 2x 高清整页截图**，放进 `<选题>/素材-官网截图-HD/`：

| 文件名（必须一字不差） | 装什么 |
|---|---|
| `01-官网首页-新版公告.jpg` | 首页首屏，能一眼看到主题那一句 |
| `03-快速开始-工作区与首次同步.jpg` | 上手路径页（步骤 / 文档 / 操作界面） |
| `07-版本能力-离线同步说明.jpg` | 关键事实页（参数表 / 价格表 / 能力清单） |

**F / G / H —— 要 5 张已经裁好的证据图**，放进 `<选题>/素材-证据图/`：

| 文件名 | 装什么 |
|---|---|
| `E01-能力表-离线同步.png` | 核心事实那一行 |
| `E03-能力表-多人协作.png` | 第二条能力 |
| `E04-能力表-附件版本.png` | 第三条能力 |
| `E06-快速开始-同步地址.png` | 操作步骤或配置界面 |
| `E09-试用额度与限制.png` | 限制 / 条件 / 免责那一块 |

这三条硬要求现在就讲清楚，别等渲染完再说：

1. **截图必须 2x 像素密度**（`deviceScaleFactor: 2`）。1x 截图放进 1080 宽视频要缩到 0.65x，二次降采样，小字必糊。**缩放比低于 0.75x 的图不要给。**
2. **一张图只装一个证据**。裁到刚好装下关键那行，整页塞进去等于没截图。
3. **不改原图内容**。价格、数字、产品名必须和来源一致，只允许裁切、调明度、加高亮框。

素材不齐也能往下走：直接空跑一次，缺的会画「素材待补」占位卡，渲染日志会按目录分组报缺失清单，把它当收材单用。

停下来等用户给素材，或明确说"先用占位图看版式"。

## 执行流程

```
Step 0  环境自检（一次性）  →  字体能不能解析、ffmpeg 在不在
Step 1  选风格              →  【交互停点】用户拍板 A–H
Step 2  收素材              →  【交互停点】用户给图 / 同意先用占位
Step 3  建工程 + 空跑       →  检查图 + 缺失清单，先对版式
Step 4  写文案改裁切框      →  【交互停点】文案口径让用户确认
Step 5  渲染成片 + 收反馈   →  回到 Step 4 迭代
```

### Step 0：环境自检

```bash
# 建工程（默认建在当前工作目录；可用 MG_TOPIC_ROOT 指定别的根目录）
cd <你想放选题的地方>
bash "<Skill>/模板/新建选题.sh" "<选题名>" <风格代号>
```

脚本会把渲染器、`mgkit`、方法论、资料模板一起复制进工程，工程自包含。

字体不需要装任何东西，但有台 Windows / Linux 的机器时先自查：

```bash
python3 "<Skill>/模板/mgkit/fonts.py"
```

六个角色（`sans_bold` / `sans_regular` / `serif_bold` / `serif_regular` / `brand_bold` / `brand_regular`）都会自动找。
找不到时**直接报错**并提示该导出哪个环境变量，不会默默退回系统字体把版式弄乱：

```bash
export MG_FONT_SANS_BOLD="/路/到/字体.ttf"      # .ttc 可带序号："...ttc:2"
export MG_FONT_SERIF_REGULAR="/路/到/宋体.ttf:6"
```

渲染成片还需要 `ffmpeg`。只跑 `--preview`（出检查图）不需要。

### Step 3：先空跑，对版式

```bash
cd "<选题>/MG样片-<风格名>"
python3 build_mg_*.py --preview
```

产出 `检查图-*.png`（9 个场景的关键帧拼图）+ `重叠检测报告.txt`。
新工程没有素材、文案还是示例选题（一个虚构产品）的，这一跑只为看**版式、时长、动画节奏**合不合眼。

把检查图给用户看，问一句：这个节奏和信息量可以么？要加场景还是砍一个？

### Step 4：换成用户的真实内容

三处要改，都在这一个文件里：

1. **文案** → `build_scenes()` 里 9 个场景的字符串。按 `参考/内容编排方法论.md` 的四段式写：

   | 段 | 时间 | 唯一任务 | 画面 |
   |---|---|---|---|
   | 钩子 | 0–3s | 让人停下 | 结论前置 + 核心证据 |
   | 兑现 | 3–8s | 兑现承诺 | 首页 / 入口证据 |
   | 正文 | 8–20s | 交付方法 | 步骤 / 对比 / 参数拆解 |
   | 收尾 | 20–25s | 给看到最后的理由 | 互动提问 |

2. **素材名** → 场景里的 `name=` / `evid_card("…")`，对齐用户实际给的文件名。
3. **裁切框** → A–E 里的 `box=`（F–H 不用改，图是用户自己裁好的）。

**框推荐写成 0–1 的比例**，比如 `(0.05, 0.50, 0.95, 0.58)`，这样用户给的截图是 1440 还是 2880 宽都能裁到同一个位置。写死像素只对当初那张截图成立。

改完重跑 `--preview`，**重叠检测报告必须全绿**，占位卡必须全部换成真图。

文案口径在渲染前给用户过一遍，特别是：
- 「当前有优惠」≠「永久免费」；「某档套餐能用」≠「全都免费」
- 结论必须有证据图能指到，指不到的删掉
- 截图里不能出现 API Key、账户信息、手机号

### Step 5：出成片

```bash
cd "<选题>/MG样片-<风格名>"
python3 build_mg_*.py            # 出无声 MP4（需要 ffmpeg）
```

**技术规格（硬性）**：1080×1920 / 30fps / H.264 / yuv420p / `-movflags +faststart` / 不加音轨。

交付：MP4 + 检查图 + 重叠报告结论。用户提意见就回到 Step 4。

## 素材不齐时的兜底

缺图不会让渲染崩：mgkit 返回一张写着「素材待补」的虚线占位卡，渲染完按目录分组报清单：

```
⚠ 缺 3 张素材，已用占位卡顶替。把下面的文件放进对应目录后重跑：
   /…/<选题>/素材-官网截图-HD
     · 01-官网首页-新版公告.jpg
     · 03-快速开始-工作区与首次同步.jpg
     · 07-版本能力-离线同步说明.jpg
```

两个细节别踩：占位卡故意**不打**文字标记（否则一缺图就全是假重叠报错）；有占位卡时的重叠报告**不算通过**，因为它没测到真实排版。

## 两个可选工具

不是必须用，用户自己截图 / 裁图也行。工具只提供"截得清、裁得准"的默认做法。

**2x 重截官网**（需要 Playwright；浏览器路径可用 `CHROME_PATH` 指定）：

```bash
cd "<选题>"
MG_SITE_BASE=https://你的域名 node "<Skill>/模板/工具-重截高清图.mjs"
```

改脚本里的 `PAGES`（url 随便换，`file` 名字别换，渲染器靠它对号）。

**大图裁成证据图**：

```bash
cd "<选题>" && python3 "<Skill>/模板/工具-切证据图.py"
```

改 `SPECS` 里的源图名、裁切框、高亮框。裁切框同样支持 0–1 比例。
它会自动出两个版本：`原版`（来源原始配色）和 `-亮`（适配亮色系风格），
亮版按底色均值判断该不该反相——白底表格保持浅底只做暖调，深底卡片才反相压向暖白。

## 硬性规则

1. **文字不能重叠** —— 用 mgkit 检测，不靠肉眼。报告必须全绿。
2. **不能越界** —— 底部 22%、右侧 15%、顶部 10% 不放字，平台 UI 会遮。
3. **截图缩放比不低于 0.75x** —— 小字看不清等于没放。证据图显示高度 **≥150px**。
4. **不改原图内容** —— 数字、名称必须和来源一致，只允许裁切、标注、调明度。
5. **口径不夸大** —— 有条件的事说成有条件，不省略限制。
6. **画面里不出现密钥、账号、个人信息。**

### 元素层级

- 用**字号和字重**做层级，颜色只强调 1–2 个词；一屏最多一个强调色
- 入场 5–10 帧、ease-out、位移 16–30px、缩放 0.96→1.0
- 同组元素错峰 0.08–0.15 秒依次入场
- 禁止逐字蹦出、文字持续晃动、用花哨转场掩盖内容单薄

### 新增风格时的两条约定

1. `card()` 一律返回 `pad=0` 并调 `set_content_offset(im, 0, 0)`。带阴影 padding 会让重叠检测坐标和肉眼位置差一个 pad，报告不可信。
2. 半透明叠色不要直接 `ImageDraw.Draw(layer, "RGBA")` 画在有内容的层上——Pillow 是**写入而非混合**，会把已绘内容擦掉。要么画在透明胶子上再 `alpha_composite`（见 H 的 `wash()`），要么先铺不透明底再罩染。

## 常见反馈与改法

| 反馈 | 改法 |
|---|---|
| 字看不清 | 裁切框收窄，或把证据图显示高度加到 ≥150px |
| 画面太空 | 提高 YOFF，把内容重心压向下半屏 |
| 颜色刺眼 | 截图降亮度 / 降饱和，或改用 `-亮` 版证据图 |
| 想要更多动感 | 加错峰入场、弹性回弹、呼吸脉冲 |
| 太正经 / 太轻浮 | 换风格（A/D ↔ F/E/G） |
| 不想撞脸 | 换 C（复古拼贴）或 H（工笔重彩） |
| 素材只有一张大图 | 选 A–E，让渲染器自己裁；别硬上 F–H |
