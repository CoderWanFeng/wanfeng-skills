# 晚枫AI动画（ai-style-video）

> **一句话生成 AI 视频** —— 你给一段描述、一份文档、一张截图、一组数据，都行；我出条 MG 短片，风格 8 选 1（或自定义）、画幅 6 选 1、配音 3 选 1，25 秒讲清楚一件事。

给**任何选题**做 MG 片：产品新版速览、功能教程、价格拆解、事件解读、原理科普都行。
**不挑题材、不挑素材形态**——文字描述 / Markdown 文档 / PDF / Word / 官网截图 / 数据表 / 公告链接，只要能讲清楚一件事，就能进渲染流水线。
8 种内置风格 + I 自定义风格任选；**6 种画幅任选**（9:16 / 2:3 / 4:5 / 1:1 / 16:9 / 4:3），**画幅和风格互相独立**——任何风格都能出任何画幅；**可选配音**：S 静音 / V1 系统电子音（零依赖）/ V2 本地模型克隆音色（可克隆用户自己的声音）。

**交付边界**：MP4 样片（按所选画幅，默认 1080×1920；24–25s、9 场景）+ 关键帧检查图 + 重叠检测报告。选 V1/V2 时多一条 AAC 音轨（可选是否烧字幕）。**逐字级字幕对齐 / 帧级音画精修**不在范围内。

> 下文用 `<Skill>` 指代本 Skill 的根目录，用 `<选题>` 指代正在做的这条工程目录。

---

## 开始前必须先问用户的四件事

**顺序不能倒**。风格决定素材规格，画幅决定版式约束和交付尺寸，配音决定是否要收参考音频 / 装本地模型，先问素材会把人问懵。

**四问都是独立决策**，特别是第 1 步（风格）和第 2 步（画幅）：**不要因为用户选了某个风格就顺手替他选画幅，也不要因为选了画幅就改风格推荐。**

### 第 1 步：选风格

把下面这张表原样给用户（不要只列名字），让 TA 拍板。**不要替用户定风格。**

| 代号 | 风格 | 底色 | 字体 | 核心动效 | 气质 | 适合 |
|---|---|---|---|---|---|---|
| A | 深色科技 | `#0A0E14` | 品牌斜体（可退回黑体） | 淡入淡出、错峰 | 冷静专业 | 硬核评测、API 教程 |
| B | 亮色杂志 | `#F7F5F0` 米白 | 黑体正体 | 弹性回弹、遮罩擦除 | 亲切生活化 | 泛用户、工具推荐 |
| C | 复古拼贴 | 牛皮纸 | 衬线 | 盖章、打字机、手绘圈画 | 手作有故事 | 系列片头、想撞脸都难 |
| D | 故障艺术 | 深空 + 噪点 | 黑体 + 乱码 | 解码显现、RGB 色差、信号撕裂 | 锐利实验 | 封面、前 3 秒钩子 |
| E | 8-bit 像素 | 深蓝 + 抖动 | 5×7 点阵 + 黑体 | 精灵、血条、金币雨 | 好玩想玩 | 泛用户、破圈 |
| F | 暖色治愈 | 奶油 | 黑体 | 阻尼弹簧、软体挤压、柔光 | 温暖亲和 | 生活向、日常场景 |
| G | 简笔画 | 纸白 + 点阵 | 黑体 | 线稿逐笔长出、boil 抖动 | 白板讲解感 | 教程、原理拆解 |
| H | 工笔重彩 | 绢本米黄 | 衬线标题 + 黑体小字 | 三矾九染叠色、落印、圈点 | 雅致重彩 | 国潮调性、系列封面 |
| I | 自定义 | 用户定 | 用户定 | 用户定 | 用户定 | 用户描述与 8 种都不一样的感觉 |

拿不准时的默认推荐：**讲价格/参数/对比 → A 或 D；讲怎么用 → B / F / G；要辨识度 → C 或 H。**
详细参数见 `参考/风格库.md`。

停下来等用户回答。用户说"你来定"，就按上面这条默认规则选一个并**说明理由**，再往下走。

**用户选 I（自定义）**：让用户用文字描述风格要求，或直接发一个文档 / 参考图 / 链接（品牌手册、竞品截图、moodboard 都算）。收到后做三件事：

1. **提炼参数**：把要求归纳成表格那五列——底色 / 字体 / 核心动效 / 气质 / 素材规格。用户没提到的列，从最接近的内置风格补齐。
2. **复述确认**：把归纳结果回给用户确认口径，**确认前不进下一步**。
3. **定底子**：挑一个最接近的内置风格代号当渲染底子（记为 `<底子>`），工程目录名用用户认可的风格名（记为 `<风格名>`）。素材规格仍只能落在 A–E（整页截图）或 F–H（证据图）两种清单之一，第 4 步按对应清单收材。

建工程时带自定义参数（画幅第 2 步定了之后一起传，见 Step 0）：

```bash
MG_STYLE_BASE=<底子> MG_STYLE_NAME=<风格名> bash "<Skill>/模板/新建选题.sh" "<选题名>" I <画幅>
```

自定义改动只在副本里做（配色 / 字体 / 动效 / 版式），并遵守「新增风格时的两条约定」；用户的原始要求与归纳结果写进 `<选题>/选题资料.md` 备查。

### 第 2 步：选画幅

风格定了，接着问出哪个画幅。**这一步和第 1 步没有任何关系**——不要把画幅当风格的附属品，也不要因为用户要做横版就回头劝他换风格。

把下面这张表原样给用户（不要只列比例），让 TA 拍板：

| 代号 | 画幅 | 输出尺寸 | 适合投哪儿 | 会怎么处理竖版内容 |
|---|---|---|---|---|
| 1 | **9:16** 竖屏 | 1080×1920 | 抖音 / 视频号 / 小红书 / B站竖屏 | 原样输出（默认，和历史样片完全一致） |
| 2 | **2:3** 竖版 | 1080×1620 | 小红书封面 / 竖版海报 | 整体缩到 0.844x，左右少量底色补边 |
| 3 | **4:5** 竖版方 | 1080×1350 | Instagram / 公众号长图 | 整体缩到 0.703x，左右底色补边 |
| 4 | **1:1** 方形 | 1080×1080 | 朋友圈 / 公众号方形配图 | 整体缩到 0.562x，左右补边较宽（可换模糊延展背景） |
| 5 | **16:9** 横屏 | 1920×1080 | B站 / YouTube / 公众号横版 | 竖版主画面 + 模糊延展背景，可加右侧标题栏 |
| 6 | **4:3** 横版 | 1440×1080 | 展板 / 培训课件 | 同上，容器窄一点 |

停下来等用户回答。拿不准时的默认推荐：**没明确投放平台就 9:16**，别自作主张换。

**必须提前讲清楚的两件事**（讲晚了就是返工）：

1. **竖版系（1/2/3/4）是全自动的**——改画幅不动版式代码，只是整体缩放 + 补边。**代价是字会变小**：4:5 之后正文小字已经开始吃力，1:1 更明显。用户在意字的大小，就推荐 9:16 或 2:3。
2. **横版（5/6）不是"重新排成横版"**——框架给的是"竖版画面体面地放进横版容器"。用户如果要的是真正的横版信息架构（左主画面 + 右卡片横排），得人工重排，成本约 60–80 处坐标改动。**现在就问清楚 TA 要哪种**，别等渲染完才发现不是他要的。

横版四档做法（自动底板 / 加标题栏 / 自绘侧栏 / 全量重排）见 `参考/画幅适配.md §3`，**选 16:9 或 4:3 就必须读这一节**。

画幅在建工程时定（见 Step 0），之后想换就改 `<选题>/canvas.json` 里的 `ratio` 重跑，风格不用动：

```json
{
  "ratio": "16:9",
  "title": "横版右侧主标题（只有横版用得到）",
  "subtitle": "副标题，可省略",
  "title_role": "serif_bold",
  "subtitle_role": "serif_regular"
}
```

### 第 3 步：选配音

风格和画幅定了，接着问要不要配音。把下面这张表原样给用户，让 TA 三选一：

| 代号 | 方案 | 需要用户给什么 | 电脑门槛 | 效果 |
|---|---|---|---|---|
| **S** | 静音（默认） | —— | 无 | 只出画面，观众自行脑补 |
| **V1** | 系统电子音 | 一份口播稿（也可以省，用 Step 6 的文案自动生成） | macOS / Windows / Linux 自带 TTS | 清晰但机器味重，胜在**零安装、零成本、断网可用** |
| **V2** | 本地模型克隆 | 一段 5–10 秒参考音频 + 口播稿 | Apple Silicon ≥8GB / NVIDIA GPU ≥6GB / Windows ≥16GB 内存 | 像真人，可**克隆用户自己的音色** |

停下来等用户回答。分支处理：

- 用户选 **S**：直接进第 4 步。跳过所有配音流程，交付边界回到"只出无声 MP4"。
- 用户选 **V1**：先查系统 TTS 是否可用（macOS `which say`、Linux `which espeak-ng`、Windows `powershell -c "Add-Type -AssemblyName System.Speech"`），任一可用即可继续；都不好用就老实告诉用户改选 S 或 V2。不用装任何模型。
- 用户选 **V2**：**先做硬件门槛自查**（见 `参考/配音方案.md §3.1`），不达标老实告诉用户改选 V1；达标就把 `参考/配音方案.md §3` 按顺序走一遍：装模型 → 收参考音频 → 让用户在 `<选题>/素材-参考音频/` 放一段自己念的 5–10 秒录音 → 后续在 Step 7 合成。

具体安装、命令、参考音频规范、失败兜底全部在 `参考/配音方案.md`，本步只问方案、不做执行。

### 第 4 步：按风格 + 画幅 + 配音方案要素材

风格、画幅、配音方案都定了，素材清单就定了。图片有两种规格（跟风格挂钩），音频看配音方案，**画幅只影响"这些图最终显示多大"**。

**A / B / C / D / E —— 要 3 张 2x 高清整页截图**，放进 `<选题>/素材-官网截图-HD/`：

| 文件名（必须一字不差） | 装什么 |
|---|---|
| `01-官网首页-新版公告.jpg` | 首页首屏，能一眼看到主题那一句 |
| `03-快速开始-工作区与首次同步.jpg` | 上手路径页（步骤 / 文档 / 操作界面） |
| `07-版本能力-离线同步说明.jpg` | 关键事实页（参数表 / 价格表 / 能力清单） |

**F / G / H —— 要 5 张已经裁好的证据图**，放进 `<选题>/素材-证据图/`：

| 文件名 | 装什么 |
|---|---|
| `E01-能力表-离线同步.png` | 核心事实那一行 |
| `E03-能力表-多人协作.png` | 第二条能力 |
| `E04-能力表-附件版本.png` | 第三条能力 |
| `E06-快速开始-同步地址.png` | 操作步骤或配置界面 |
| `E09-试用额度与限制.png` | 限制 / 条件 / 免责那一块 |

这三条硬要求现在就讲清楚，别等渲染完再说：

1. **截图必须 2x 像素密度**（`deviceScaleFactor: 2`）。1x 截图放进 1080 宽视频要缩到 0.65x，二次降采样，小字必糊。**缩放比低于 0.75x 的图不要给。**
2. **一张图只装一个证据**。裁到刚好装下关键那行，整页塞进去等于没截图。
3. **不改原图内容**。价格、数字、产品名必须和来源一致，只允许裁切、调明度、加高亮框。

**画幅是叠加的缩放**：上面第 1 条算的是"设计画布 1080×1920 里"的比例。选 4:5 再乘 0.703、选 1:1 再乘 0.562、横版再乘 0.45——**画幅越小 / 越横，截图就要给得越清晰**。用户只有 1x 截图又想要 1:1 或 16:9，现在就告诉他要么换 9:16，要么重截 3x。素材清单本身不随画幅变化，横版不需要额外给图。

**音频素材**（只在配音方案 V1 / V2 时才收）：

| 方案 | 素材 | 放哪儿 | 硬性要求 |
|---|---|---|---|
| V1 | 口播稿 | `<选题>/口播稿.md` | 9 段对应 9 场景，**整段合计 ≤ 125 字**（25 秒 × 5 字/秒），超了混流时音频会被视频截尾 |
| V2 | 参考音频 | `<选题>/素材-参考音频/reference.wav` | 5–10 秒 / 单声道 / 无 BGM / 单人 / 44.1kHz 或 48kHz；只用来提取音色，不进成片 |
| V2 | 口播稿 | 同 V1 | 同上 |

素材不齐也能往下走：直接空跑一次，缺的会画「素材待补」占位卡，渲染日志会按目录分组报缺失清单，把它当收材单用。

停下来等用户给素材，或明确说"先用占位图看版式"。

## 执行流程

```
Step 0  环境自检 + 建工程     →  字体能不能解析、ffmpeg 在不在、V2 时顺手查一下硬件门槛
Step 1  选风格              →  【交互停点】用户拍板 A–H 或 I（自定义）
Step 2  选画幅              →  【交互停点】1–6 代号或直接给比例；和 Step 1 互不影响
Step 3  选配音              →  【交互停点】S 静音 / V1 电子音 / V2 模型克隆
Step 4  收素材              →  【交互停点】用户给图 (+ V1/V2 口播稿 / V2 参考音频) / 同意先用占位
Step 5  空跑对版式          →  工程已在 Step 0 建好；检查图 + 缺失清单，顺便验画幅尺寸
Step 6  写文案改裁切框      →  【交互停点】文案口径让用户确认
Step 7  渲染 + 混音 + 收反馈 →  S 直接交付；V1/V2 用 ffmpeg 把配音轨合成进去再交付；回到 Step 6 迭代
```

### Step 0：环境自检

```bash
# 建工程（默认建在当前工作目录；可用 MG_TOPIC_ROOT 指定别的根目录）
# 第 3 个参数是画幅，缺省 9:16；和第 2 个参数（风格代号）互相独立
cd <你想放选题的地方>
bash "<Skill>/模板/新建选题.sh" "<选题名>" <风格代号> <画幅>

# 例：故障艺术 + B站横屏
bash "<Skill>/模板/新建选题.sh" "某产品新版速览" D 16:9

# 自定义风格（I）多传两个环境变量，见第 1 步；画幅照样是最后一个参数
MG_STYLE_BASE=<底子代号> MG_STYLE_NAME=<风格名> bash "<Skill>/模板/新建选题.sh" "<选题名>" I 4:5
```

脚本会把渲染器、`mgkit`、方法论、资料模板一起复制进工程，并把画幅写进 `<选题>/canvas.json`，工程自包含。

**老工程（画幅功能上线前建的）没有 `canvas.json`，改比例也不会生效**——先跑一次升级工具（见 `参考/画幅适配.md §1.3`）：

```bash
cd "<选题>" && python3 "<Skill>/模板/工具-升级画幅.py" <画幅>
```

字体不需要装任何东西，但有台 Windows / Linux 的机器时先自查：

```bash
python3 "<Skill>/模板/mgkit/fonts.py"
```

六个角色（`sans_bold` / `sans_regular` / `serif_bold` / `serif_regular` / `brand_bold` / `brand_regular`）都会自动找。
找不到时**直接报错**并提示该导出哪个环境变量，不会默默退回系统字体把版式弄乱：

```bash
export MG_FONT_SANS_BOLD="/路/到/字体.ttf"      # .ttc 可带序号："...ttc:2"
export MG_FONT_SERIF_REGULAR="/路/到/宋体.ttf:6"
```

渲染成片还需要 `ffmpeg`。只跑 `--preview`（出检查图）不需要。

**配音方案 V2 时**再多做两件：

1. **硬件门槛自查**：跑 `参考/配音方案.md §3.1` 里的三条命令，看 CPU 架构 / 内存 / 是否有独显；不达标就回头告诉用户改选 V1，别硬装。
2. **系统 TTS 可用性**（V1 用得上）：macOS `which say`、Linux `which espeak-ng`、Windows `powershell -c "Add-Type -AssemblyName System.Speech"`。

### Step 5：先空跑，对版式

```bash
cd "<选题>/MG样片-<风格名>"
python3 build_mg_*.py --preview
```

产出 `检查图-*.png`（9 个场景的关键帧拼图）+ `重叠检测报告.txt`。
新工程没有素材、文案还是示例选题（一个虚构产品）的，这一跑只为看**版式、时长、动画节奏**合不合眼。

**这一跑同时验画幅**：关键帧的宽高必须等于第 2 步选的画幅（16:9 → 1920×1080），检查图的格子也该跟着变形。尺寸还是 1080×1920 就说明工程没读到 `canvas.json`，按 `参考/画幅适配.md §1.3` 升级。

把检查图给用户看，问一句：这个节奏和信息量可以么？要加场景还是砍一个？

### Step 6：换成用户的真实内容

三处要改都在渲染器这一个文件里，横版再加一处配置：

1. **文案** → `build_scenes()` 里 9 个场景的字符串。按 `参考/内容编排方法论.md` 的四段式写：

   | 段 | 时间 | 唯一任务 | 画面 |
   |---|---|---|---|
   | 钩子 | 0–3s | 让人停下 | 结论前置 + 核心证据 |
   | 兑现 | 3–8s | 兑现承诺 | 首页 / 入口证据 |
   | 正文 | 8–20s | 交付方法 | 步骤 / 对比 / 参数拆解 |
   | 收尾 | 20–25s | 给看到最后的理由 | 互动提问 |

2. **素材名** → 场景里的 `name=` / `evid_card("…")`，对齐用户实际给的文件名。
3. **裁切框** → A–E 里的 `box=`（F–H 不用改，图是用户自己裁好的）。
4. **横版标题栏**（只在 16:9 / 4:3 需要）→ `<选题>/canvas.json` 的 `title` / `subtitle` / `title_role` / `subtitle_role`。文案直接复用钩子那两句（第 1 段），别另写一套口径。字体角色按风格调性挑，见 `参考/画幅适配.md §3.2`。

**框推荐写成 0–1 的比例**，比如 `(0.05, 0.50, 0.95, 0.58)`，这样用户给的截图是 1440 还是 2880 宽都能裁到同一个位置。写死像素只对当初那张截图成立。

改完重跑 `--preview`，**重叠检测报告必须全绿**，占位卡必须全部换成真图。

文案口径在渲染前给用户过一遍，特别是：
- 「当前有优惠」≠「永久免费」；「某档套餐能用」≠「全都免费」
- 结论必须有证据图能指到，指不到的删掉
- 截图里不能出现 API Key、账户信息、手机号

### Step 7：出成片 + 混音

**7.1 出无声底片**（三种方案都要跑）：

```bash
cd "<选题>/MG样片-<风格名>"
python3 build_mg_*.py            # 出无声 MP4（需要 ffmpeg）
```

**7.2 生成配音轨**（只有 V1 / V2 跑，具体命令在 `参考/配音方案.md`）：

把 `<选题>/口播稿.md` 整段喂给 TTS，输出一条 `<选题>/口播全轨.m4a`：

- **V1**（macOS 举例）：`say -v Tingting -f 口播稿.md -o /tmp/vo.aiff && ffmpeg -y -i /tmp/vo.aiff -c:a aac -b:a 160k -ar 48000 口播全轨.m4a`
- **V2**：起本地模型（GPT-SoVITS / CosyVoice2）→ 提交参考音频 + 整段口播稿 → 输出 wav → 同上转 m4a

**口播稿字数**：中文按 ~5 字/秒估，25 秒对应 **≤ 125 字**。字数超了先砍文案，别指望后期加速——加速后机器味会顶上来。

**7.3 混流**（V1 / V2 才跑，`-c:v copy` 不重编码视频）：

```bash
cd "<选题>/MG样片-<风格名>"
VIDEO_DUR=$(ffprobe -v error -show_entries format=duration -of csv=p=0 MG-样片*.mp4)
ffmpeg -y -i MG-样片*.mp4 -i ../../口播全轨.m4a \
  -map 0:v -map 1:a \
  -c:v copy -c:a aac -b:a 160k -ar 48000 \
  -t "$VIDEO_DUR" \
  -movflags +faststart \
  MG-样片-有声.mp4
```

**为什么不用 `-shortest`**：口播比视频短时，`-shortest` 会把**视频**截到音频长度——最后一段画面就没了。用 `-t "$VIDEO_DUR"` 明确以视频长度为准：音频短则尾部自动静音补齐，音频长则截音频到 25s（此时应该回 7.2 改稿，而不是让成片缺尾）。

**技术规格（硬性）**：30fps / H.264 / yuv420p / `-movflags +faststart`；有声时 AAC 160kbps / 48kHz。分辨率按第 2 步选的画幅走（默认 1080×1920；16:9 是 1920×1080），**成片尺寸必须和画幅表一致**——不一致就是帧尺寸和 `-s` 对不上，ffmpeg 会拉伸而不是报错，用 `ffprobe` 量一下宽高。

**交付**：
- **S**：无声 MP4 + 检查图 + 重叠报告
- **V1 / V2**：有声 MP4 + 无声 MP4（留给用户改口径重混）+ `口播全轨.m4a` + 检查图 + 重叠报告

用户提意见就回到 Step 6。

## 素材不齐时的兜底

缺图不会让渲染崩：mgkit 返回一张写着「素材待补」的虚线占位卡，渲染完按目录分组报清单：

```
⚠ 缺 3 张素材，已用占位卡顶替。把下面的文件放进对应目录后重跑：
   /…/<选题>/素材-官网截图-HD
     · 01-官网首页-新版公告.jpg
     · 03-快速开始-工作区与首次同步.jpg
     · 07-版本能力-离线同步说明.jpg
```

两个细节别踩：占位卡故意**不打**文字标记（否则一缺图就全是假重叠报错）；有占位卡时的重叠报告**不算通过**，因为它没测到真实排版。

## 硬性规则

1. **文字不能重叠** —— 用 mgkit 检测，不靠肉眼。报告必须全绿。
2. **不能越界** —— 默认 9:16 是底部 22%、右侧 15%、顶部 10% 不放字（平台 UI 会遮）。**换画幅后这组数会变**，按 `参考/画幅适配.md §4` 的安全区表走；横版自绘侧栏时先取 `CANVAS.safe_px()`。
3. **截图缩放比不低于 0.75x** —— 小字看不清等于没放。证据图显示高度 **≥150px**。注意画幅会叠加缩放（4:5 ×0.703、1:1 ×0.562、横版 ×0.45）。
4. **不改原图内容** —— 数字、名称必须和来源一致，只允许裁切、标注、调明度。
5. **口径不夸大** —— 有条件的事说成有条件，不省略限制。
6. **画面里不出现密钥、账号、个人信息。**
7. **成片尺寸必须等于所选画幅** —— 帧尺寸和 ffmpeg `-s` 对不上时 ffmpeg 会拉伸而不是报错，交付前用 `ffprobe` 量一次宽高。

### 元素层级

- 用**字号和字重**做层级，颜色只强调 1–2 个词；一屏最多一个强调色
- 入场 5–10 帧、ease-out、位移 16–30px、缩放 0.96→1.0
- 同组元素错峰 0.08–0.15 秒依次入场
- 禁止逐字蹦出、文字持续晃动、用花哨转场掩盖内容单薄

### 新增风格时的两条约定

自定义风格（I）改渲染器副本时同样适用这两条。

1. `card()` 一律返回 `pad=0` 并调 `set_content_offset(im, 0, 0)`。带阴影 padding 会让重叠检测坐标和肉眼位置差一个 pad，报告不可信。
2. 半透明叠色不要直接 `ImageDraw.Draw(layer, "RGBA")` 画在有内容的层上——Pillow 是**写入而非混合**，会把已绘内容擦掉。要么画在透明胶子上再 `alpha_composite`（见 H 的 `wash()`），要么先铺不透明底再罩染。

### 换画幅时的两条约定

和第 2 步（选画幅）配套，自定义风格那两条不受影响。

1. **改画幅只改 `canvas.json`，不碰渲染器里的坐标**。设计画布恒为 1080×1920，画幅差异在输出端映射（`模板/mgkit/canvas.py`）；一旦去改 `W, H = 1080, 1920` 就等于放弃了零回归，竖版横版再也切不回来。
2. **要真横版排版就另建一份工程**（`参考/画幅适配.md §3` 的 C/D 档）。同一份工程里"竖版自动缩放"和"横版全量重排"不能共存；优先停在 C 档（自动底板 + 自绘右侧栏），D 档 60–80 处坐标改动只在用户明确要求时做。

## 常见反馈与改法

| 反馈 | 改法 |
|---|---|
| 字看不清 | 裁切框收窄，或把证据图显示高度加到 ≥150px |
| 画面太空 | 提高 YOFF，把内容重心压向下半屏 |
| 颜色刺眼 | 截图降亮度 / 降饱和，或改用 `-亮` 版证据图 |
| 想要更多动感 | 加错峰入场、弹性回弹、呼吸脉冲 |
| 太正经 / 太轻浮 | 换风格（A/D ↔ F/E/G） |
| 不想撞脸 | 换 C（复古拼贴）或 H（工笔重彩） |
| 素材只有一张大图 | 选 A–E，让渲染器自己裁；别硬上 F–H |
| 改 canvas.json 没反应 | 老工程的 mgkit 是过期副本，跑 `模板/工具-升级画幅.py`（`参考/画幅适配.md §1.3`） |
| 横版画面被拉伸变形 | 帧尺寸还是 1080×1920 但 `-s` 已是横版——`render_frame` 出口没接 `CANVAS.fit_frame`，重跑升级工具 |
| 横版右侧标题字特别小 | `title_role` / `subtitle_role` 写了 `fonts.py` 里不存在的角色名，退回默认位图字体 |
| 竖版换过去字太小 | `fit` 是整体缩放（4:5 ×0.703、1:1 ×0.562）；砍文案放大字号，或回 9:16 / 2:3 |
| 补边和画面边缘有色差 | 背景是渐变，四角取色取不准——`canvas.json` 加 `"mode": "relayout"` 换模糊延展背景 |
| 想要真正的横版排版 | 竖版内容不会自动变横版构图，按 `参考/画幅适配.md §3` 选 C（自绘侧栏）或 D（全量重排） |
| 配音比视频短 | 正常，混流时 `-t "$VIDEO_DUR"` 会让尾部自动静音补齐；想顶满就加字或调 `say -r` 语速 |
| 配音比视频长（音频被截）| 砍稿到 ≤125 字，或在 Step 6 加一个场景 |
| V2 装完模型跑不动 | 硬件不达门槛，回头改选 V1；别硬撑，本地跑 30s 起步的模型最少吃 8GB 显存 |
| V2 克隆不像本人 | 参考音频太短 / 有 BGM / 有他人声；让用户重录 5–10 秒安静朗读 |

## 文件组织

```
<选题>/
├── 素材-官网截图-HD/          # 2x 整页原图（A–E 用）
├── 素材-证据图/               # 裁好的证据图，原版 + -亮（F–H 用）
├── 素材-参考音频/             # V2 才用：reference.wav（5–10s，克隆音色用）
├── canvas.json                 # 画幅配置：ratio + 横版标题栏（渲染器自动读取）
├── 口播稿.md                   # V1 / V2 才用：9 段，对应 9 场景
├── 口播全轨.m4a                # V1 / V2 中间产物：合成好的完整配音轨
├── mgkit/                      # 从 Skill 复制过来，工程自包含（含 canvas.py）
├── MG样片-<风格名>/
│   ├── build_mg_*.py           # 渲染器（文案 / 素材名 / 裁切框都在这）
│   ├── 检查图-*.png            # --preview 产出
│   ├── 重叠检测报告.txt         # 含缺失素材清单
│   ├── MG-样片*.mp4            # 无声底片（S 方案最终交付）
│   └── MG-样片-有声.mp4        # V1 / V2 混音后的最终交付
├── 内容编排方法论.md
└── 选题资料.md                 # 事实 / 口径边界 / 文案 / 风格、画幅与配音方案记录
```

`canvas.json` 长这样（横版才用得到后面几个字段）：

```json
{
  "ratio": "16:9",
  "title": "右侧主标题",
  "subtitle": "副标题",
  "title_role": "serif_bold",
  "subtitle_role": "serif_regular",
  "mode": "relayout"
}
```
