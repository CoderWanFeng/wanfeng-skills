# 晚枫AI动画 · ai-style-video

> **一句话生成 AI 视频** —— 你给一段描述、一份文档、一张截图、一组数据，都行；我出条 25 秒 MG 短片，风格 8 选 1、画幅 6 选 1、配音 3 选 1。
>
> SkillHub 安装：https://skillhub.cn/skills/user_bf8c5b73/wanfeng-ai-style-video

## 能吃进去什么

**不挑素材形态**：文字描述 / Markdown 文档 / PDF / Word / 官网截图 / 数据表 / 公告链接——只要能讲清楚一件事，就能进渲染流水线。

## 怎么用（四步开场）

1. **选风格** —— A 深色科技 / B 亮色杂志 / C 复古拼贴 / D 故障艺术 / E 8-bit 像素 / F 暖色治愈 / G 简笔画 / H 工笔重彩；8 种都不满意就选 **I 自定义**，用文字描述或直接发参考图，agent 会归纳参数并借最接近的渲染器改造。
2. **选画幅** —— 9:16 竖屏（抖音/视频号/小红书/B站竖屏）/ 2:3 小红书封面 / 4:5 Instagram / 1:1 朋友圈 / **16:9 横屏**（B站/YouTube/公众号横版）/ 4:3 展板课件。**画幅和风格互相独立**，任何风格都能出任何画幅。
3. **选配音** —— S 静音（默认） / **V1 系统电子音**（零依赖，一行命令） / **V2 本地模型克隆音色**（可选装 GPT-SoVITS / CosyVoice2，用户提交 5–10 秒参考音频就能克隆"自己的声音"）。
4. **交素材** —— 图片按风格走：A–E 要 3 张 2x 高清整页截图；F–H（含自定义按 F–H 规格时）要 5 张裁好的证据图。音频按配音方案走：V1 交口播稿；V2 交口播稿 + 一段参考音频。素材不齐先空跑，缺的会画「素材待补」占位卡。

之后 agent 会：建工程（风格 + 画幅一起定）→ 空跑对版式 → 换成你的真实文案与素材 → 渲染无声底片 → V1/V2 时合成配音轨并用 ffmpeg 混入 → 交付。

**画幅怎么落地**：竖版系（9:16 / 2:3 / 4:5 / 1:1）全自动，整体等比缩放 + 底色补边，不用改任何版式代码；横版（16:9 / 4:3）给的是"竖版主画面 + 模糊延展背景 + 可选右侧标题栏"的自动底板，想要真正的横版左右分栏得按 [参考/画幅适配.md](参考/画幅适配.md) 人工重排——**这一步 agent 会先跟你对齐预期，不会默默给你一条拉伸的视频**。

## 交付物

- **S 静音**：无声 MP4（按所选画幅，默认 1080×1920）+ 关键帧检查图 + 重叠检测报告
- **V1 / V2 有声**：有声 MP4 + 无声 MP4（留给后续改口径重混，不用重渲染画面）+ `口播全轨.m4a` + 检查图 + 重叠检测报告

## 不在范围内

- **逐字级字幕对齐** / **帧级音画精修** —— 只保证 `-t "$VIDEO_DUR"` 级别的截断兜底（音频比视频长会被截，短则自动静音补齐）
- **烧字幕** —— 需要就用 ffmpeg subtitle 滤镜自己叠一层
- **付费 TTS** —— 全流程本地跑，`say` / `espeak-ng` / `System.Speech` / GPT-SoVITS / CosyVoice2 / F5-TTS 都是开源方案
- **横版自动重排** —— 竖版内容不会自己变成横版构图；框架给自动底板，真横版信息架构要人工重排（见 [参考/画幅适配.md](参考/画幅适配.md) §3）

## 本地直接使用（不走 SkillHub）

克隆本仓库后，把 `skills/ai-style-video` 作为 skill 目录接入即可；或手动建工程（第 3 个参数是画幅，可省略，默认 9:16）：

```bash
bash "<Skill>/模板/新建选题.sh" "<选题名>" <风格代号> [画幅]        # A–H，例：D 16:9
MG_STYLE_BASE=<底子> MG_STYLE_NAME=<风格名> \
  bash "<Skill>/模板/新建选题.sh" "<选题名>" I 4:5                 # I 自定义
```

已经建好的老工程（画幅功能之前建的）改 `canvas.json` 不生效，先升级一次：

```bash
cd "<选题>" && python3 "<Skill>/模板/工具-升级画幅.py" 16:9
```
