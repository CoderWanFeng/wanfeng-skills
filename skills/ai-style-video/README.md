# 晚枫AI动画 · ai-style-video

> SkillHub 安装：https://skillhub.cn/skills/user_bf8c5b73/wanfeng-ai-style-video

把任意素材做成 **8 种风格（或用户自定义风格）** 的竖屏静音 MG 短视频：1080×1920、24–25 秒、9 场景、无音轨。

## 怎么用

1. **选风格**：A 深色科技 / B 亮色杂志 / C 复古拼贴 / D 故障艺术 / E 8-bit 像素 / F 暖色治愈 / G 简笔画 / H 工笔重彩，或 **I 自定义**——用文字描述你要的感觉，或直接发文档 / 参考图，由 agent 归纳参数并借最接近的渲染器改造。
2. **交素材**：A–E 要 3 张 2x 高清整页截图；F–H（含自定义按 F–H 规格时）要 5 张裁好的证据图。素材不齐先空跑，缺的会画「素材待补」占位卡。
3. **等样片**：agent 建工程 → 空跑对版式 → 换成你的真实文案与素材 → 渲染 MP4 + 检查图 + 重叠检测报告。

完整流程与硬性规则见 [SKILL.md](SKILL.md)。

## 本地直接使用（不走 SkillHub）

克隆本仓库后，把 `skills/ai-style-video` 作为 skill 目录接入即可；或手动建工程：

```bash
bash "<Skill>/模板/新建选题.sh" "<选题名>" <风格代号>
```

## 交付边界

只出**静音样片**（MP4 + 关键帧检查图 + 重叠检测报告）。配音、字幕烧录、时间轴对齐不在范围内。
