## 这个范例演示什么

### 封面（cover-v1.html）

**视觉锤 + 3 卡片流水线** 的典型范式：
- 视觉锤：大汉字"穿越"（160px 黑字 + 橙色 ::after 偏移副本）
- 信息区：3 卡片纵列，**STEP 02 · Diffusion 扩散模型 高亮绿色**（核心步骤）
- 顶部栏：`AI · 图像生成 · 父亲节` + `AIHOT · 2026-06`（左 kicker + 右英文副标）
- 角标：`3 分钟讲清`（橙底白字，旋转 6deg）
- 底部脚注：`EP.01 · 3 STEPS · 1 PHOTO`（左）+ `<账号名> · <slogan>`（右）

### 配图（fig-01-section1-5-tips.html）

**5 卡片横排 + 1 高亮 + 1 推荐** 的 fig-template-1 用法：
- 5 张并列卡片：场景 / 动作 / 穿着 / 摄影词汇 / 保留原图
- **诀窍 3** 黄色高亮（黄色 = 强调）
- **诀窍 5** 绿色推荐（绿色 = 推荐 / 灵魂）
- 角标：`人人都能用`（蓝色，旋转 -4deg）

## 设计要点（学这个范例）

1. **视觉锤用大汉字，不用数字 / emoji** — 中文汉字 + 橙色 ::after 偏移 = 风格标志
2. **3 卡片流水线时，让核心步骤高亮绿色** — 读者一眼锁定关键
3. **角标放卖点（"3 分钟讲清"）** — 不放装饰性图标
4. **底部脚注分两段** — 左 = 系列期号 `EP.01`，右 = 账号占位符 `<账号名>`
5. **5 卡片不要撑满宽度** — 内容紧凑比视觉平衡重要
