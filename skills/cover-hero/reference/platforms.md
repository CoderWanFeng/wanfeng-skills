## 二、平台微调规则（HyperFrames + 平台适配层）

HyperFrames 是**底色风格**（米白底 + 圆点纹理 + 黑顶栏 + 偏移黑阴影 + 橙/绿强调）。每个平台加一层**适配装饰**：

### 1. 标准模式（公众号 / 知乎 / B站 / 微博 / OG / Twitter）

**无任何适配层**，完全用默认 HyperFrames：

```css
/* 全部用 reference/visual-system.md 里的默认 */
--paper: #f3efe6;
--ink: #0b0d12;
--accent: #ff5b1f;
--accent-2: #6cd76b;
```

### 2. 高反差模式（小红书）

小红书信息流密度高、内容杂，封面需要**跳出来**：

```css
/* 1. 顶栏从 36px → 44px，更显眼 */
.top-bar { height: 44px; }

/* 2. 圆点纹理从 18px → 24px（更大更稀疏，3 米外能看见） */
body {
  background-size: 24px 24px;
}

/* 3. 主标从 42px → 56px（小红书缩略图小，必须更大） */
.info .title { font-size: 56px; }

/* 4. 卡片边框从 2.5px → 3px */
.card { border-width: 3px; }

/* 5. 主强调色 #ff5b1f → #ff2d55（小红书品牌红，提升点击） */
--accent: #ff2d55;

/* 6. 元素 ≤ 5 个仍是硬约束 */
```

### 3. 戏剧模式（抖音）

抖音封面是 9:16，信息层级竖向堆叠，需要**强视觉锤**：

```css
/* 1. 视觉锤从 160px → 240px（竖屏中央，3 米外能看清） */
.hammer .big { font-size: 240px; }

/* 2. 顶栏从 36px → 56px */
.top-bar { height: 56px; }

/* 3. 主标文字 ≤ 8 字（抖音封面文字多必划走） */
.info .title { font-size: 64px; max-chars: 8; }

/* 4. 角标从 5deg → -3deg（竖屏反方向更稳） */
.badge { transform: rotate(-3deg); }

/* 5. 卡片偏移阴影从 4px → 8px（更"立体"） */
.card { box-shadow: 8px 8px 0 #0b0d12; }

/* 6. 元素减到 4 个（视觉锤 + 主标 + 角标 + 脚注，删除卡片） */
```

## 三、平台 × 产物 决策树

```bash
# 用户输入：1. 文章主题 + 内容 → 2. 平台选择 → 3. 产物类型选择

node pick-template.js \
  --platform <平台> \
  --type <产物类型> \
  --style <风格档位> \
  --output <输出路径>
```

**参数对照**：

| 参数 | 取值范围 | 默认值 |
| --- | --- | --- |
| `--platform` | `wechat` / `xhs` / `douyin` / `zhihu` / `bilibili` / `weibo` / `og` / `twitter` | `wechat` |
| `--type` | `cover` / `figure` / `frame` | `cover` |
| `--style` | `default` / `compact` / `bold` | `default` |
| `--output` | 文件路径 | `<platform>-<type>-<timestamp>.html` |

### 风格档位（基于 HyperFrames 内部变化）

| 档位 | 适用场景 | 变化 |
| --- | --- | --- |
| `default` | 默认 | 完全 HyperFrames 标准 |
| `compact` | 信息密度高（教程/横评） | 卡片紧凑、字号略小 |
| `bold` | 强吸睛（封面/故事） | 视觉锤更大、装饰更多 |

> ⚠️ **档位变化只调字号 / 间距 / 元素个数，不换字体 / 不换配色 / 不加渐变 / 不去偏移黑阴影**。

## 五、平台硬性约束（不可越界）

| 平台 | 硬性规则 |
| --- | --- |
| 公众号 | 封面图 ≤ 2MB，比例必须 2.35:1 |

| Twitter Card | 同 OG，文字必须安全区内 |

## 六、为什么不允许"非 HyperFrames 风格"

> **核心原则**：所有视觉选项都基于 HyperFrames 技术方案。

具体含义：

- ✅ **允许**：调字号 / 间距 / 元素个数 / 配色（在 HyperFrames 6 色调色板内）/ 主标字数
- ❌ **不允许**：换字体（不能换成思源黑体 / 微软雅黑）/ 改圆点纹理（必须保留）/ 去掉偏移黑阴影（风格标志）/ 用渐变 / 用 emoji 当主视觉锤 / 引入玻璃拟态 / 加投影模糊 / 加旋转动画

如果用户想要"完全不同的风格"，告诉他"本 skill 不覆盖，请用其他工具（如 Figma / PS）"。
