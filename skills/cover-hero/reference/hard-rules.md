# 封面三大硬性要求（强制）

> 封面是公众号 / 小红书 / 抖音 / 知乎 / B站 / 微博 / OG / Twitter 等平台文章 / 视频的第一道门。这三个要求是**强制项**，违反任一条 = 封面不合格。

---

## 要求 1：名人 / 大公司形象必须出现（强制）

如果文章里出现了 **AI 科技圈名人**或 **大公司名字**，封面上**必须出现**这个名人的头像或这个大公司的 Logo。

### 为什么强制

- 🎯 **点击率提升 2-3 倍**：粉丝看到"哦是 Sam Altman"会优先点开
- 🏷️ **品牌识别**：Logo 比抽象符号更易建立"这篇是讲 XX 的"的认知
- 🔍 **搜索筛选**：读者用「Karpathy」「OpenAI」搜索时，封面直接命中

### 识别名单（持续补充）

**AI 圈名人**：Sam Altman、Andrej Karpathy、Lex Fridman、Yann LeCun、Andrew Ng、Demis Hassabis、Dario Amodei、李开复、周鸿祎、王小川…

**大公司**：OpenAI、Anthropic、Google DeepMind、Meta AI、NVIDIA、Microsoft、阿里、字节、腾讯、百度、华为、智谱、月之暗面…

**标记工具**（高识别度品牌）：Cursor、Claude Code、Codex、Windsurf、Cline、Aider…

### 实现方式（不调 AI 生图）

- **名人**：
  - 优先查找公开头像素材（Wikipedia / 官方账号头像 / Twitter / 公众号名片）→ 下载 PNG → 嵌入封面
  - 找不到：用文字代替（如 `Sam Altman` 中文名 + 小头像轮廓）
- **大公司**：
  - 优先从官网 / [Brandfetch](https://brandfetch.com) / [Simple Icons](https://simpleicons.org) 下载官方 Logo（PNG/SVG）

### 例外

- 纯工具评测（无具体人/公司）→ 视觉锤区放工具 Logo 或产品截图
- 纯技术原理（如 token 压缩算法）→ 视觉锤区放符号（⚡、⚙️）

## 要求 2：文字必须通俗易懂（强制）

封面上的**所有文字**（主标、副标、卡片标题、角标）必须让**不懂技术的人也能秒懂你在讲什么**。

### 反面案例（禁用）

- ❌ `基于 LLM 推理成本结构的 token 压缩技术解析`
- ❌ `Transformer 架构中的多头注意力机制`
- ❌ `OpenAI Function Calling 实战应用`

### 正面案例（小白能秒懂）

- ✅ `让 AI 每月省 2 万 token 费`
- ✅ `AI 是怎么「读懂」你说话的`
- ✅ `让 AI 帮你点外卖`

### 翻译公式

```
技术词 → 生活化比喻 / 数字 / 动作
"Token 压缩" → "省 95% AI 费"
"Diffusion 模型" → "AI 是怎么画画的"
"Function Calling" → "让 AI 帮你做事"
"Agent 工作流" → "AI 团队替你干活"
```

### 平台主标字数限制（多平台专属）

不同平台的信息流缩略图大小不同，**主标字数必须按平台限制**：

| 平台 | 主标字数上限 | 原因 |
| --- | --- | --- |
| 抖音 | **≤ 8 字** | 3 秒法则，竖屏小缩略图 |
| 小红书 | **≤ 20 字** | 缩略图小，文字多必划走 |
| B 站 | ≤ 16 字 | 视频封面 16:10 横屏 |
| 公众号 / 知乎 / 微博 | ≤ 14 字 | 默认限制 |
| OG Card / Twitter Card | **必须 ≤ 30 字且在中央 1200×600 安全区** | 部分平台裁切边缘 |

## 要求 3：图标必须一看就懂（强制）

如果封面放了**任何图标**（人物、设备、工具等），它必须**一眼就能识别**——不允许观众需要想一下才能理解。

### 判断标准

- 3 秒内能说出"这个图标是 X"
- 不需要先读文字才能看懂图标
- 不抽象、不变形、不艺术化到认不出

### 反面案例

- ❌ 抽象几何形状（立方体、球体、线条）—— 不知道在指什么
- ❌ 过度艺术化的 AI 插画人物 —— 看不清是男人还是女人
- ❌ 极简线条 Logo —— 不知道代表哪个工具

### 正面案例

- ✅ 明确的工具图标（VSCode 方块+代码、GitHub 猫、Figma 圆角矩形）
- ✅ 真实设备照片风（电脑、手机、摄像头）
- ✅ 标志性符号（OpenAI 的螺旋、Twitter 的鸟、Tesla 的 T）

### 实现要求

**全部用纯 SVG 自绘**（不外链、不用图标字体），保证离线可渲染、可重排色。

---

## 核心原则（总览）

> **封面上的东西不要太多，但是要足够清楚、足够吸引人。**

- ✅ **多不如精**：1 个强视觉锤 + 1 个名人/Logo + 3 张卡 = 刚好
- ❌ **少不漏关键**：没有名人/Logo + 看不懂的文字 = 直接划走
- ⚖️ **判断标准**：5 秒测试 —— 朋友刷到，5 秒内能不能说出"哦这是讲 XX 的"

## 配图硬性要求（继承）

正文配图继承相同原则：

- 顶栏必填：`SECTION X · 中文标签` + 右侧英文副标
- 标题区：橙色 kicker + 中文主标（46-54px）
- 卡片描边 2.5px，黑色偏移阴影 `5px 5px 0 ink`
- 字号经验值：主标 42-54px / 卡片标题 16-22px / 卡片描述 12-13px / 顶栏与脚注 12-13px
- 底部脚注：`FIG.NN · §X · KEYWORD`

配图数量**没有固定值**，先判断"哪些小节真的值得用图说清楚"再决定张数——1 张也行，7 张也行，0 张也行（如果整篇就是 FAQ / 安装命令）。
