# 踩坑速查（v3 主流程）

只覆盖 **切段 / 素材 / 提示词排版** 三类问题。v2 遗留路径的鉴权、路由、后端错误码见 `legacy-integration.md` §11。

## 文稿与切段

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 平台把 `[A]` / `[B]` 当成正文念出来 | 单括号稿与双括号语法不匹配 | 先把 `[A]` 全替换成 `[[A]]`，再打印每段 `text` 确认没残留标签 |
| 某段超过目标平台上限 | `speech_rate_cps` 估低了 | 按 4 字/秒重估；实在压不下来就在标点处强制断 |
| 情绪没生效 | 写了 `neutral` 这类非法值 | 只有 9 个合法值，中性用 `calm`（`script-writing.md` §3） |
| 整条声音/表情一个调 | 没逐段标情绪 | 用 `[[A:happy]]` `[[A:calm]]` 逐段标 |
| 一段里塞了两个场景 | 切段没按场景边界 | 场景变化必须断段（`[[A:happy\|scene=...]]`） |
| 明明该 B-roll 却仍占了 persona 参考 | 没写 `[[BROLL]]` | 补上，或直接把该段 `kind` 改成 `"b"` |

## 素材

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 平台报"人脸过小 / 不清晰" | 参考照分辨率够但人脸占比不够 | 让用户重拍，脸占画面 1/3 以上 |
| 平台报"检测到多人" | 参考素材里有其他人 | 标 ⚠️ 缺失，要求重录；不能靠切段修 |
| 参考音频有底噪 | 马路边、办公室环境录的 | 标 🔄 建议替换，室内重录 |
| 只有视频没有音频文件 | 用户没意识到音频要单独提出来 | 用 `ffmpeg -i 自拍.mov -vn -ac 1 -ar 32000 -b:a 128k voice.mp3` 抽 |
| `sips` 或 `ffprobe` 命令找不到 | 系统未装 ffmpeg 或路径没在 PATH | macOS：`brew install ffmpeg`；Windows 装 ffmpeg 加进 PATH |
| 抽帧后图片是空的 / 旋转 90 度 | 素材带 EXIF 旋转元数据 | 用 `sips -r 0 --resampleWidth 512 in.jpg --out out.jpg` 归一化 |

## 提示词

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 生成出来"嘴在动但不对词" | 目标平台其实不接受参考音频 | 见 `platform-notes.md` §2，改用能对口型的平台 |
| 画面风格跟 prompt 不搭 | 平台默认吃中文但模型更懂英文 | 保留六要素字段名不变，把值改成中英对照（本 skill 不代翻） |
| 结构化字段的平台报错 | 有未知字段被填进去了 | 把 `prompts/seg_XXX.txt` 里 `# 以下为 ... 特有字段` 一节删掉再贴 |

## 交付层

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `README-for-platform.md` 打开看不出下一步 | 段表缺"开工顺序建议" | 补上：先跑最短的一段，效果满意再补齐 |
| `segments.json` 与实际平台上限不符 | `target_platform` 选错或表过期 | 更新 `platform-notes.md` §5，重跑 S1 切段 |
| prompts/ 里段号对不上 `segments.json` | 手工改过其中一份没同步另一份 | 只改 `segments.json`，让 S3 重跑生成 prompts |

## 兜底排查顺序

1. 文稿 → 标记与切段是否合规；
2. 素材 → 是不是过了 `material-prep.md` §7 的验收；
3. 平台 → `platform-notes.md` §1 上限是否被踩；
4. 都过了还不对 → 打开 `README-for-platform.md` 从平台方视角走一遍，看哪一步需要人肉补。
