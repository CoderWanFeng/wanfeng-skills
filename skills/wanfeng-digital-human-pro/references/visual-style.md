# 视觉规范：B-roll 与封面

这份只在「要让画面好看」时才需要读。数值和做法来自一次真实成片复盘，是用户明确认可的基准。

## B-roll 的视觉约定

| 维度 | 做法 |
| --- | --- |
| 底色与层级 | 暖白留白，白色圆角信息卡，轻边线与克制阴影；重要数字明显大于说明文字 |
| 配色 | 蓝色强调主信息，绿色表达辅助信息，橙色只作少量点缀；避免金币堆叠、徽章堆砌这类广告感 |
| 动效 | 信息逐项入场、轻位移、淡入淡出；清单最后转合计；关键动作对齐「说到这条信息」的时刻 |
| 事实口径 | 数字、条件、日期写准；不同概念不要混成一个奖励；保留「以账号当前规则为准」这类必要限定 |

### 返工教训

第一版样片获得认可后，整片却错用了旧渲染器的场景布局，前后风格完全断裂，只能全部重做。

正确做法：**以获认可的样片为唯一审美基准，独立重绘全部场景**，而不是给旧版改颜色、删标签。

## 观众画面与制作者信息必须分离

**不进入成片**：`B-ROLL` 字样、段号、`05 / 09`、版式示意、制作进度条、镜头职责、占位说明。

**可以进入成片**：主标题、任务名称、奖励数字、必要的条件说明、日期地点。

| 情况 | 做法 |
| --- | --- |
| 需要记录制作信息 | 放分镜表、渲染日志或内部验收拼图，不烧进视频 |
| A-roll 暂时缺失 | 纯色占位即可，不写「此处待生成」 |
| 画面里有兑换码、链接、二维码 | 打码或不使用；不添加扫码引导 |
| 图片自带 AI 生成标识 | 保留，它不是可以随便删的制作者备注 |

## 系列封面的约定

封面和 B-roll 是两套视觉，不要把极简信息海报的构图直接搬到封面。

| 维度 | 做法 |
| --- | --- |
| 背景 | 暖灰、米色的真实办公背景，不是纯白信息海报 |
| 人物 | 本人坐办公椅，居中或略偏左的正面半身；脸、眼镜、衣领清楚 |
| 标题 | 放顶部；超粗黑字与白字黑描边组合；部分字可略斜体；信息点少、缩略图可读 |
| 强调 | 关键数字用浅金色突出 |
| 品牌 | 官方 Logo 放人像身侧，不遮挡脸和标题 |
| 不复制 | 历史截图里的观看数、时长、底部描述、平台外框、其他产品 Logo |

**动手前先要参考**：让用户提供 3–5 张历史封面，分别提炼「视频内页风格」和「系列封面风格」，不要凭想象统一成一种。

## 品牌校正

- 正确拼写是 `WorkBuddy`，不是 `WorkBody`。
- 生成图常把图标画错或把字标拆成两行。最终必须用**官方原始素材**校正，不凭记忆重画。
- 原图裁切坐标按**真实像素尺寸**算，不能照搬屏幕预览坐标。预览缩小后直接取坐标会裁错区域。

## 一句话原则

先定事实和样片，再定最终声音与时间轴；先试最短数字人，再补齐；封面看系列参考；交付只给观众该看到的内容。
