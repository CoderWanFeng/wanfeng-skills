# 视觉风格选项（4 选 1 · 用户决定）

> Step 0 第一问：**封面/视觉用哪种风格？** 默认 `swiss-grid`。
> 每种风格都有独立的色彩 token、字体、节奏。切换风格必须同步切 composition 模板。
> 详细视觉规范见 [`reference/03-visual-spec.md`](../reference/03-visual-spec.md)。

> ⚠️ **本页示例以「程序员晚枫」账号为参考**。风格对比图中的 IP 信息是该账号的示例数据。
> 用户使用本 skill 时，应替换为自己的 IP 信息。

---

## 4 种风格一览

| # | 风格 | 视觉调性 | 适合选题 | 主色调 |
|---|---|---|---|---|
| **A** | **swiss-grid**（默认）| 极简瑞士国际主义 · 网格 · 红黑白 | 工具实操 / 行业判断 / 知识科普（**主战场**）| 白底 + Helvetica + `#E30613` 红 + 黑 |
| B | warm-grain | 暖色杂志 · 电子墨水 · 流体背景 | 节日特别篇 / 教程类 / 长讲解（vlog 风格）| 米色 `#F5EFE6` + 棕红 `#A04830` + 衬线字体 |
| C | nyt-graph | 纽约时报图解 · 数据可视化 · 报纸感 | 行业判断 / 数据驱动选题（涨粉专业感，AI / 财经 / 时政都适用）| 米色底 + 黑 + 经典红 `#A23B26` + 衬线字体 |
| D | embedded-captions | 人物出镜 + 字幕 + 暖色 | 个人故事 / 经验复盘 / 人物访谈 | 暖底 + 大字幕 + Helvetica |

| 视觉 token | 值 |
|---|---|
| 底色 | `#F5EFE6`（米色 / 电子墨水纸感）|
| 强调 | `#A04830`（棕红）|
| 字体 | `Source Han Serif SC` / `Songti SC`（衬线，区别于 swiss-grid 的无衬线）|
| 装饰 | 颗粒底纹 + 流体色块 + 棕红装饰线 |
| 节奏 | 慢呼吸（短段 2.5s / 长段 ≤ 8s / gap 0.2s）|

**适用场景**：
- 春节/中秋/节日特别篇
- 教程类（需要长讲解感）
- Vlog / 生活分享
- "为什么这个 AI 改变了我的生活"类选题

**警示**：变体 v1/v2/v3 同样适用；黑条 y=1050 硬约束仍生效。

## 切换风格的操作清单

从 A 切到 B/C/D 时，必须同步做这些事：

- [ ] Step 2 视觉规范文件 `visual-spec.md` 改写
- [ ] composition 模板换成对应风格的 HTML（`src/<style>/composition.template.html`）
- [ ] 封面骨架换成对应风格的 HTML（从对应风格的 v1 复制）
- [ ] 黑条 logo/名称/副标从工具列表里重新选
- [ ] 字号经验值按新风格重新校准（warm-grain / nyt-graph 通常用更大的字号）
- [ ] Step 4 的 `resync.py` 跑（CSS 改了）

| # | 坑 | 修法 |
|---|---|---|
| 1 | 切了风格但 composition 还是旧的 | 用 `npx hyperframes init <style>` 重新初始化 |
| 2 | 黑条 y=1050 在暖色底上看不清 | 把背景色统一改纯白 |
| 3 | 衬线字体在 windows 渲染失败 | 加 `font-family: "Songti SC", "Source Han Serif", serif;` 回退 |
