# 视觉规范 · ASCII 草图

> 给 swiss-grid 视觉规范配 ASCII 草图，让排版规则一眼看懂。
> 所有数字基于 **3:4 1080×1440 封面画布** 和 **9:16 1080×1920 视频画布**。

> ⚠️ **本页草图以「程序员晚枫」账号为示例**。底部 IP 信息（`@程序员晚枫 · 科技不高冷，AI 很好用`）是该示例账号的真实数据。
> 用户使用本 skill 时，应替换为自己的 IP 信息（或按 Step 0 开关②保持不放）。

> ⚠️ **每个封面独立，不属于系列**。除非用户明确说"这是系列第 X 期"，否则顶部红条右侧不放期号，主标左下也不放 `№ 编号`。
> 下面草图中的 `№ 003` 是历史示例（系列视频），新制作的封面默认不放。
