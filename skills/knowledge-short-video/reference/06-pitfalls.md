# 六、踩坑清单 + 五条铁律

> 全部来自实战任务复盘沉淀（netflix-headroom-save-token / ai-photo-father / opencode-free-model / glm52 / hyperframes-pr-to-video-skill / ai-cut pipeline 等）。
> 这一章**每条都对应返过工的坑**，照着过一遍能少 90% 返工。

## 6.0 五条「硬错误」（违反即拒绝渲染 / 必须立刻修）

> 借鉴自 [ai-cut pipeline](../..) 的 V9 教训。**这些不是警告，是阻断性硬错误**：lint / QA / resync 工具在做完自检后会**直接报错并中止**，不会产出一个残缺视频。
> 任何一条为真 → 修完再继续。

| # | 错误 | 触发场景 | 修法 |
|---|---|---|---|
| H1 | **段数与模板占位符对不上** | 模板里 `__S1_*__ ~ __S9_*__` 占位符数量 = 9，但 segments.txt 只有 6 段（漏 3 段）或 11 段（多 2 段） | 把 segments.txt 改到**与模板占位符完全一致**；或调整模板的 scene 区块到相同段数。**段数对不上 = lint 拒绝** |
| H2 | **残留 `__XXX__` 占位符** | resync 跑完后，模板里还有未被替换的 `__S5_HOOK__` 之类（一般是 scene 删了但占位符没清） | 在模板里 grep `__[A-Z_]+__`，所有未被替换的都补上 timeline 字段（或删掉未用的 scene）|
| H3 | **配音片段时间重叠** | timeline.json 里相邻段的 `start/end` 重叠（V9 全黑根因） | 检查拼接：正常应是 `gap=0`（紧挨），**重叠**才报。修法：重新拼接 wav，重新生成 timeline.json，**不要**手动改时间 |
| H4 | **timed 元素缺 `data-track-index`** | 某个真正的 clip `<div class="clip">` 漏了 `data-track-index`（根时间线本身豁免，只有真 clip 才查）| 给每个真 clip 补 `data-track-index="N"`（根时间线不用）|
| H5 | **BGM 音量 > 0.25** | 背景音乐音轨（不带 `data-duration`）音量过大压旁白 | 旁白音轨（带 `data-duration`）满音量是正常的，**只有** BGM 会被查。把 BGM 音量降到 ≤ 0.25 |

## 6.2 6 条最容易翻车的点（必查）

> **先过 §6.0 五条硬错误**（H1-H5），再过下面的常规 6 条。硬错误未消除，强行 render = 残缺视频。

1. **第一步就把 TTS 调了** → 文本没确认就合成 = 100% 返工。先 segments.txt 后 TTS。
2. **画面禁用词写进画面**（`// 共情` `// 受挫`）→ 观众看不懂。kicker 用 `// 周二下午` 这种内容回声。
3. ~~每期都用同一模板~~ → ~~审美疲劳~~ → **已统一 swiss-grid**，不再换模板（品牌识别优先）。
4. ~~选了模板但没测 cover~~ → ~~封面/视频脱节~~ → **已取消候选测试**（统一 swiss-grid）。
5. **浮动徽章压住正文** ⭐ → 见 [视觉规范 §3.4](../reference/03-visual-spec.md) 浮动元素布局 SOP。
6. **封面出多个尺寸再裁切** → 唯一 3:4 1080×1440，平台自动适配，不要裁切。

把这 6 点过一遍，能少 90% 返工。

## 6.3 六条铁律（必背 · 任何一条违反都返工）

### 1. **Step 0 必走 · 4 开关**

[Step 0](../reference/04-production.md#step-0--开始前-4-个开关必走--不可跳过) **一次性问完 4 个开关**（用户沉默走默认）：

- ① 封面风格 = **A · swiss-grid（默认）** / warm-grain / nyt-graph / embedded-captions
- ② IP 信息 = **不放（默认）** / 放
- ③ 引导关注 = **不引导（默认）** / 引导
- ④ 配音大模型 = **系统默认 TTS 默认** / 自定义

**同任务变体之间必须保持一致**（v1/false、v2/true = 不可）。

### 2. **一帧 ≤ 8 秒 + GSAP 动画驱动**

竖版节奏快，超 8 秒观众就走神。**最终产物必须是动画视频**（GSAP `fromTo` 驱动动效），**不允许** ffmpeg concat 静态图。

### 3. **TTS 配音先问用户 · 默认就够用**

- **默认** = 系统默认 TTS，速度 **1.0x**（1.3x 仅 dev 预览，不用于发布）
- **自定义** = 用户提供 4 个参数 / API 文档 / 客户端代码（[3 种接入方式](../reference/04-production.md#511-自定义-tts-的-3-种接入方式用户任选)）
- 用户沉默或回"用默认" → 走默认。**不要替用户选**。

### 4. **画面禁用创作稿术语**

kicker 用 `// 周二下午` `// 我也是`，**不要**用 `// 共情` `// 钩子` `// 受挫`。

### 5. **小白能看懂是硬要求**

术语翻译 + 类比 + 数字 + 原始数据 + 行动项拆分，**每条稿子必过 7 项自检表**（[§2.6.6](../reference/02-script.md)）。

### 6. **发布包固定 3 文件**

竖版短视频最小发布包 = **3 文件**（视频 + 1 张封面 + 1 份文案），不要默认全套。**Step 7 第一件事：先问用户"要几个文件"**。
