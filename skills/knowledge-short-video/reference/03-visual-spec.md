# 三、视觉规范（4 种风格可选 · Step 0 由用户决定）

> **核心**：Step 0 第一问 **"封面/视觉用哪种风格？"** 用户沉默 → 默认 `swiss-grid`（账号已统一）。
> 4 种风格的对比、适用场景、ASCII 草图见 [`assets/style-options.md`](../assets/style-options.md)。
> 切换风格必须**同步切换 composition 模板**（不是只换封面骨架），详见 [§3.8 切换风格的操作清单](#38-切换风格的操作清单)。

## 3.1 风格选择 SOP（4 选 1）

**第一句话**问用户：

> "封面/视觉用 **4 种风格里的哪种**？
>
> - **A · swiss-grid**（默认）：白底 + Helvetica + 红黑，账号已统一
> - **B · warm-grain**：暖色杂志 + 衬线字体，节日/教程/vlog
> - **C · nyt-graph**：纽约时报图解 + 数据可视化，行业判断
> - **D · embedded-captions**：人物出镜 + 字幕，个人复盘
>
> 用户不指定 → A · swiss-grid"

**判定逻辑**：

```
Step 0 第一问
  ↓
用户选 A → §3.2 swiss-grid DNA（默认）
用户选 B → §3.3 warm-grain DNA
用户选 C → §3.4 nyt-graph DNA
用户选 D → §3.5 embedded-captions DNA
  ↓
同步切换 composition 模板 + 封面骨架
```

> ⚠️ **重要**：风格一旦选定，整个任务（含所有变体 v1/v2/v3）必须保持一致。同一期不同版本不能"上半部分 swiss-grid、下半部分 warm-grain"。

## 3.2 swiss-grid（默认 · 已沉淀）

| 项 | 值 |
|---|---|
| **配色 token** | `--bg: #fff` / `--ink: #0a0a0a` / `--red: #E30613` |
| **字体** | `Helvetica Neue` Bold 700-900 + `JetBrains Mono` |
| **字号上限** | 巨型数字 200-560px / 主标 132-168px / 标签 28-40px |
| **节奏约束** | 短段 1.5s / 长段 ≤ 5s / gap 0.15s / 硬切不用弹性 |
| **动效规则** | 进场淡入 0.22-0.34s / 退场淡出 0.12s / stagger 0.04-0.06s |
| **装饰元素** | 红色顶部横条 + 黑色底部横条 + grid line + 装饰横条（默认）<br>`№ 编号` / 期号 / 系列标识 — **可选**，仅用户明确说"这是系列第 X 期"时才放 |

> ⚠️ **底色硬约束**：视频本体**只能**用白底 `--bg: #fff`，**禁止**用黑底/深色背景。
> composition CSS 第一行就要写：
> `:root{--bg:#fff; --ink:#0a0a0a; --red:#E30613; ...}`
>
> 即使封面用了黑底风格，**composition 也必须白底**——黑底视频 → 黑屏或观众认不出是同一系列。

## 3.6 IP 信息开关（默认关闭）

> **默认值**：`ip_info: false`（**不放** IP 信息）
> 用户选 `true` 时，**由用户提供**自己的 IP 名称 + slogan

**为什么默认 false**：

- 商业感越弱，平台越推荐（小红书/抖音算法偏向"非营销"内容）
- 用户关注靠的是"内容有用"，不是"画面上有作者名"
- 防止品牌植入感影响内容可信度

**开启后**（用户提供 IP 名 + slogan）：

- 封面**底部**：`@<用户IP名>` + `<slogan>`（slogan 可选）
- 视频**脚注**：`@<用户IP名>`（slogan 可选）
- 字体：Helvetica Neue 22-24px / 灰 `#999`

**关闭时**：

- 封面/视频脚注只放黑条工具栏（不显示作者信息）
- 用户只能通过水印或评论区置顶知道作者

## 3.3 封面设计规范（swiss-grid 体系 · 锁定版）

> **核心原则**：封面**就是视频第一帧**——风格、字体、配色、版式与视频本体严格一致。
> 用户在信息流停留不到 0.3 秒，必须用视觉瞬间传递两件事：
> 1. **这期讲什么**（大字号主标题，一眼可读）
> 2. **核心数字/反常识钩子**（视觉锤，第一眼抓住注意力）
>
> ⚠️ 封面的 ASCII 草图见 [`assets/cover-layouts.md`](../assets/cover-layouts.md)。

### 3.3.1 品牌色彩体系（与视频本体一致）

| 层级 | 颜色 | 色值 | 用途 |
|---|---|---|---|
| 底色 | 纯白 | `#fff` | 全幅背景（与视频本体一致）|
| 主文字 | 墨黑 | `#0a0a0a` | 主标题、副标题、说明文字 |
| 强调色 | Netflix 红 | `#E30613` | 强调数字、装饰横条、进度条、kicker |
| 辅助色 | 浅灰 | `#e0e0e0` | 网格底纹、分割线 |

**配色禁忌**：
- ❌ 不要引入金色（`#F5C518`）—— 已废弃
- ❌ 不要引入暗底（`#070B14`）—— 已废弃
- ❌ 不要引入其他颜色（蓝/绿/紫/橙）—— 破坏系列感
- ✅ 只能使用白 + 黑 + 红 3 色

### 3.3.2 格式与尺寸（3:4 竖版唯一）

| 版式 | 尺寸 | 平台 |
|---|---|---|
| **3:4 竖版（唯一）** | **1080 × 1440** | 小红书、抖音、视频号、B 站竖屏、公众号头图 |

> **为什么用 3:4 不用 9:16**：
> - 9:16 视频帧在某些平台展示位会被裁切（顶部/底部被切）
> - 3:4 是各平台通用的封面比例，**不会被裁切**
> - 视频本体仍然是 9:16，封面 3:4 是单独的发布物

**禁止 9:16 / 16:9 / 1:1 多尺寸**：只出一张 3:4，平台自动适配。**禁止裁切**。

### 3.3.3 字体体系（与视频本体完全一致）

| 用途 | 字体 | 字重 |
|---|---|---|
| 主标题 | Helvetica Neue | 700-900 |
| 副标题 | Helvetica Neue | 500-700 |
| 数据 | JetBrains Mono | 500-700 |
| kicker | Helvetica Neue | 500-700 |

**回退字体**（系统不支持 Helvetica 时）：`PingFang SC` / `Source Han Sans CN` / `system-ui`

**字号经验值**（1080×1440 画布内）：
- 巨型数字：180-420px
- 主标：100-140px
- 副标：36-60px
- kicker：24-36px
- 脚注：18-24px

### 3.3.4 主标题设计规则（swiss-grid 排版）

- 用 swiss-grid 排版（左侧视觉锤 + 右侧信息区 / 上下二分 / 大数字矩阵）
- 不用暗底金字风格的金色发光阴影
- 不用人物出镜
- 不用标题拆分错位排布

**核心结构**：
1. 顶部红色横条（`<主题> · KICKER` + **可选期号**，仅系列视频才放）
2. 主视觉区（巨型数字 / 核心问句 / 视觉锤）
3. 信息卡片（3 个概念 / 关键点）
4. 底部装饰（脚注 + 工具条）

### 3.3.5 封面简化原则（关键）

> 字越少越像封面，字越多越像幻灯片。一眼没看懂 = 划过去 = 0 个点击。

**3 个硬要求**：

1. **字要少** — 内容块数 ≤ 5
2. **重点要突出** — 1 个核心问题 + 1 个核心转换 + 1 句话解释
3. **普通人能看懂** — 每个词都让"没接触过<主题>的人"秒懂

**反面 vs 正面**：

| ❌ 错误 | ✅ 正确 |
|---|---|
| 6 块内容（红条+Hero+等式+徽章+5 卡片+工具条+底部）| 4 块内容（红条+Hero 问句+核心转换+工具条+底部）|
| 长副标「腾讯元宝父亲节穿越合影活动刷屏，3 分钟讲清 AI 图像生成原理」| 短副标「从一张全白雪花图，30 步长出合影」|
| 5 个提示词诀窍（卡片堆叠）| 1 个核心问题「AI 怎么画出合影？」+ 1 个核心转换「噪声 → 合影」|

**自检清单**（每次做封面后过一遍）：
- [ ] 内容块数 ≤ 5？
- [ ] 视觉锤字号 ≥ 180px（3:4 画布内）？
- [ ] 副标 ≤ 20 字？
- [ ] 没有任何术语需要解释？
- [ ] 给一个"没接触过<主题>的人"看，他 5 秒能说出这期讲什么？

### 3.3.6 装饰元素（4 件套必选 + 1 件可选 · 与视频本体完全一致）

> ⚠️ **每个封面都是独立的，不属于系列**。除非用户明确说"这是系列第 X 期"，否则不要加 `№ 编号` / 期号 / 系列标识。

| 元素 | 必选 | 位置 | 样式 |
|---|---|---|---|
| 顶部红条 | ✓ | `top: 0` | 高度 64px，背景 `#E30613`，左侧 kicker 英文大写，**右侧不放期号** |
| 工具条（黑条） | ✓ | `top: 1050px` | 背景 `#000`，padding 36px 48px，白色工具 logo + 名称 + 标签 |
| 底部 | ✓ | `bottom: 40px` | `border-top: 1px solid #000`，padding-top 20px，@<IP名> + slogan（可选，由用户提供）|
| 网格线 | ✓ | 满画布 | 极淡灰线 `#e0e0e0`，1px，间距 80px |
| 装饰横条 | ✓ | 强调字下方 | 高度 4-8px，红色 `#E30613` |
| `№ 编号` / 期号 | **可选** | 主标左下 | 红色 `#E30613`，JetBrains Mono，48px — **仅系列视频才放** |

**禁止装饰**（暗底封面的装饰已废弃）：节点网络 / 发光圆 / 斜切装饰线 / 金色发光阴影。

### 3.3.7 黑条统一规范（跨期视觉对齐 · 硬约束）

> 黑色横条的位置和尺寸必须完全一致——否则用户在小红书 / 抖音 / 视频号滑动浏览系列封面时会很乱。

**强制规范**（每期封面都要遵守，**不允许修改**）：

```css
/* 黑条固定参数（1080×1440 画布内） */
.tool {
  position: absolute;
  left: 0; right: 0;
  top: 1050px;          /* 固定 y 位置，不允许改 */
  background: #000;
  padding: 36px 48px;   /* 固定 padding，不允许改 */
}
.tool-row {
  display: flex; align-items: center; gap: 30px;
}
.tool-logo {
  width: 100px; height: 100px;        /* 固定尺寸 */
  background: #E30613;
  border-radius: 8px;
  font: 900 64px/1 ...;
  color: #fff;
  flex-shrink: 0;
}
.tool-name {
  font: 900 70px/1 ...;               /* 固定 70px */
  letter-spacing: -2px;
}
.tool-tag {
  font: 400 22px/1.3 ...;             /* 固定 22px */
  color: #999;
  letter-spacing: 2px;
  text-transform: uppercase;
}
```

**关键尺寸表**（封面对齐的硬约束）：

| 项目 | 固定值 | 误差容忍 |
|---|---|---|
| **y 起始位置（top）** | **1050px** | ± 0px |
| **黑条总高** | **172px** (padding 36 + logo 100 + padding 36) | ± 0px |
| **黑条总宽** | **1080px**（满画布宽度）| ± 0px |
| **左右 padding** | **48px** | ± 0px |
| **上下 padding** | **36px** | ± 0px |
| **Logo 尺寸** | **100×100px** | ± 0px |
| **Logo 圆角** | **8px** | ± 0px |
| **工具名字号** | **70px** | ± 0px |
| **副标字号** | **22px** | ± 0px |
| **Logo ↔ 名称 gap** | **30px** | ± 0px |

**填充规则**（黑条里写什么）：

| 期数类型 | 黑条内填什么 |
|---|---|
| 工具/产品评测 | 工具 logo + 工具名 + "Free · Local · Open Source" 副标 |
| 平台活动赞助 | 平台 logo + 平台名 + "活动名 · 入口" 副标 |
| 课程/教程 | 课程 logo + 课程名 + "讲师 · 价格" 副标 |
| 开源项目 | GitHub Cat + 项目名 + "Star · Contributors" 副标 |

> ⚠️ **绝对禁止**：
> - 改黑条高度 / 改黑条起始位置 / 改 logo 尺寸 / 改 logo 颜色（必须 `#E30613`）/
> - 黑条宽度不满画布 / 黑条用圆角或阴影

> 下次做新封面时，**直接复制上一期的 `.tool` CSS 一行不改**，只换里面的文字和 logo 字母。

### 3.3.8 从口播稿到封面的映射

| 口播稿字段 | 封面元素 | 处理规则 |
|---|---|---|
| 核心数字 / 反常识钩子 | 视觉锤（巨型红字）| 200-560px，红色 `#E30613` |
| 主题词 / 工具名 | 主标（黑字）| 132-168px，墨黑 `#0a0a0a` |

| 行动项 / 工具名 | 底部黑条 | 白字 + 工具 logo |

## 3.4 浮动元素（徽章）布局 SOP

> 浮动徽章（−95%、NEW、HOT 等）一放就挡正文——本期踩坑 3 轮才到位。

**SOP**：

1. **先预留空白区**：用 grid placeholder 或注释标记浮动元素将要占的位置
2. **浮动元素和正文区保持 ≥ 40px 缓冲带**（CSS 里写 `top: X+40px`）
3. **位置选择优先级**：右上 → 右下 → 左下（**避开顶部红条和 kicker**）
4. **绝对不要压在主标 / 等式 / 对比条上**
5. **Chrome headless 渲染后必须肉眼检查重叠**（CSS 计算和实际像素可能差几像素）
6. **如果空间不够**：扩大浮动元素所在的空白区（上下移动对比条 / 等式），**不要缩小徽章**

**实战案例**（netflix v2 徽章 3 轮修正）：

| 轮次 | 徽章位置 | 问题 | 修法 |
|---|---|---|---|
| 1 | top:560, 等式上方 | 压住"2500 tokens" | 挪到 top:200 右上 |
| 2 | top:200, 右上 | 压住顶部红条和 kicker "TOKEN · 节约方案" | 挪到 top:1060 右下空区 |
| 3 | top:1060, 180×180 + bars 下移到 top:1280 | ✅ 干净不挡 | 通过 |

## 3.5 封面的迭代与变体管理

> 用户经常说"再调调"、"换个重点"。同 DNA 出多个版本是常态。

**SOP**：

1. **同一 DNA 可以出 v1 / v2 / v3 ...**，新建子目录 `03-Cover/v2/`，**绝不覆盖** v1
2. **每个变体单独 HTML + PNG**，便于回滚
3. **变体之间的差异**写到 `decision.md` 的 v2 章节
4. **用户选哪个发布都行** —— 保留所有变体让用户拍板

**实战案例**（netflix-headroom-save-token）：

| 版本 | 视觉重点 | 用户反馈 |
|---|---|---|
| v1（swiss-grid）| "好几万 AI 账单 / −95%" | "再调调，重点不够突出" |
| v2（swiss-grid 数字冲击）| "AI 成本 ÷ 20 / −95% 徽章 / 对比条" | "用这版，发布" |

**踩坑教训**：
- 不要试图用一个封面同时讲完所有重点 → 用 v1 讲故事钩子，v2 讲数字冲击
- v1 和 v2 的 HTML 不要共用一份 → 改一处会影响发布
- 用户的"重点不够突出"反馈 → 通常是**核心数字没在第一眼**位置

## 3.6 封面制作流程 SOP · 10 步

| Step | 内容 |
|---|---|
| 1 | 提取封面信息（核心数字 / 钩子 / 主题词）|
| 2 | 选定 swiss-grid 模板（参考上一期的封面）|
| 3 | 画布创建：1080 × 1440（3:4），底色 `#fff` |
| 4 | 背景层：白底 + 网格线 |
| 5 | 顶部红条：kicker（默认不放期号，系列视频才加）|
| 6 | 主视觉区：视觉锤（巨型数字 / 核心问句）|
| 7 | 浮动徽章（按 §3.4 SOP 布局）|
| 8 | 工具条：黑底白字横条（[§3.3.7 规范](../reference/03-visual-spec.md#337-黑条统一规范跨期视觉对齐--硬约束)）|
| 9 | 底部黑条：脚注 |
| 10 | Chrome headless 渲染 + 肉眼检查重叠 |

**验证检查清单**：
- [ ] 配色是否严格限定在白 + 黑 + 红 3 色？
- [ ] 字号梯度是否清晰（巨型数字 180+ / 主标 100+ / 副标 36+）？
- [ ] 浮动徽章和正文是否有 ≥40px 缓冲带？
- [ ] 顶部红条 + 底部黑条是否对齐？
- [ ] **3:4 比例正确（1080×1440）？**（不是 9:16）
