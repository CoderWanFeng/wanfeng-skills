# 二、口播稿创作（"写什么" · Step 0）

> 拿到选题后，先按本章规则把口播稿写好再进入 Step 1（拆 segments.txt）。
> 每条稿子必须按 §2.1 先归入三类之一，再按 §2.2-2.8 写正文。

---

## 2.1 三类内容栏目（先归类，再动笔 · 通用）

> 所有口播稿**必须先归入以下三类之一**，不要混成"什么都讲一点"。
> **三类栏目是通用框架，A/B/C 命名不变，但用户必须把"工具 / 行业 / 热点"替换为自己的主题**（如：美食主题 → A=菜谱实操 / B=食材科普 / C=餐厅探店）。

### A · 主题实操（主战场 · 涨粉 + 引流）

| 项 | 值 |
|---|---|
| 时长 | **90-180s** |
| 字数 | **400-800 字** |

**写法公式**：

```
一个普通人能用的场景（学习 / 工作 / 生活）
+ 这个场景下 <主题> 怎么用
+ 普通人容易踩的坑
+ 效果怎么量化（省了多少钱 / 多少时间）
+ 第一步该怎么开始
```

**开头示例**（AI 主题）：
- "我用了 3 个免费 AI 工具，省了每月 200 块的会员费。"
- "学生免费用 Cursor 一年，申请流程 5 分钟讲清。"
- "本地部署 DeepSeek，免费不求人。"

**开头示例**（美食主题）：
- "这道糖醋排骨我做了 20 次才稳定，今天把不翻车版本给你。"
- "3 步搞定一道不翻车的番茄炒蛋，厨房新手也能学会。"

**开头示例**（职场主题）：
- "我用这份简历模板，3 年换了 2 次工作没被 HR 刷过。"
- "5 个 Excel 函数，帮你每天省 1 小时。"

**结尾必须导向下一步**：
> 下一条我直接拆解，怎么用这工具/方法 5 分钟搞定你的 XX 任务。

### B · 主题判断 / 行业洞察（建立专业感）

| 项 | 值 |
|---|---|
| 时长 | **60-120s** |
| 字数 | **280-540 字** |

**写法公式**：

```
一个 <主题> 新闻 / 行业事件
+ 大多数人以为 A
+ 真正的问题是 B
+ 对普通人意味着什么
+ 你该先做哪 3 件事
```

**开头示例**（AI 主题）：
- "OpenAI 涨价 26 倍，你该怎么办。"
- "免费 AI 工具用得越爽，越要小心。"
- "这波 AI 裁员，真正受影响的是哪些人。"

**开头示例**（美食主题）：
- "预制菜进校园这件事，家长最该看的不是新闻标题。"
- "为什么你做的红烧肉永远不如饭店的？3 个被忽略的细节。"

**开头示例**（职场主题）：
- "今年大厂都在裁 35 岁员工，但有 3 类人反而涨薪。"
- "跳槽涨薪 30% 的人，都做对了这 1 件事。"

### C · 主题热点大白话（拉播放 · 每周 ≤ 2 条）

| 项 | 值 |
|---|---|
| 时长 | **60-90s** |
| 字数 | **280-400 字** |

**写法公式**：

```
一个 <主题> 新闻 / 热点事件 + 表面现象 + 真正关键是什么 + 对普通人意味着什么 + 你该怎么做
```

### ⚠️ 新闻 vs 知识自检（写完必问）

> 把新闻部分全部删掉，剩下的内容还能独立成立吗？
> - **能** → 新闻只是钩子，知识是主体 → **通过**
> - **不能** → 你在做新闻搬运 → **重写**

## 2.2 第一句话必须把人留住（最高优先级）

> ⚠️ 这是整个指南里最重要的一条，没有之一。前 3 秒留不住人，后面写得再好也没用——用户已经划走了。

**第一句话（前 3 秒）必须完成以下任意一项**：

| 钩子类型 | 效果 | AI 主题示例 | 美食主题示例 | 职场主题示例 |
|---|---|---|---|---|
| **反常识冲突** | 用户"诶？不对吧" → 想继续看 | "AI 工具越免费，越要小心" | "饭店的糖醋排骨其实没放糖" | "加班最多的人，升职加薪最少" |
| **信息差暗示** | 用户"他有我不知道的东西" → 想验证 | "Cursor 用了一周才发现，3 个免费替代品" | "饭店大厨从不焯水的牛肉" | "HR 看简历只看前 3 行" |
| **数字锚点** | 用户被具体数字吸引 → 想了解 | "我用 3 个免费 AI 工具，省了每月 200 块" | "这道菜成本 8 块，餐厅卖 48" | "5 个 Excel 函数，每天省 1 小时" |
| **直接打脸** | 用户"他在说我们做错了？" → 想反驳 | "你以为 AI 省钱，其实是 AI 烧钱" | "你以为的健康早餐其实最伤胃" | "你以为的稳定工作其实最危险" |
| **身份点名** | 用户"说的是我" → 想看下去 | "学生党注意了，免费 AI 工具申请全攻略" | "厨房新手必看，3 道菜不会翻车" | "工作 3 年的你，是不是开始焦虑了" |

**禁止使用的开头**：
- ❌ "今天教大家…"
- ❌ "你有没有发现…"
- ❌ "大家好，我是…"
- ❌ 任何铺垫词（"其实啊""话说回来""大家都知道"）

**检查标准**（写完开头第一句，问自己三个问题）：
1. 普通人刷到这条，会在 3 秒内划走吗？ → 会 = 重写
2. 第一句能让目标用户想"然后呢？"吗？ → 不能 = 重写
3. 如果把第一句删掉，后面的内容还能成立吗？ → 能 = 第一句没用，重写

## 2.3 人设锚点（让用户记住你是谁）

> ⚠️ 流量高但不涨粉，核心原因就是缺这条。
> 用户看完觉得"讲得不错"，但不记得是谁讲的 → 不关注。

**每篇稿子必须至少有一个"人设锚点"**——让目标用户看完知道"这是谁讲的"。

> 用户按自己账号定位填写 `<IP名>` / `<slogan>` / `<主题>`。下面是占位示例。

| 插入位置 | 写法示例（用户替换 `<IP名>` / `<主题>`）|
|---|---|
| 开头钩子之后（推荐） | "我是<IP名>，专门帮你找免费、好用的 <主题>。" |
| 反转之后 | "我是<IP名>，真用过 50+ <主题> 工具的 <人设身份>。" |
| 结尾互动之前 | "关注<IP名>，<主题> + 工具推荐，只讲真话。" |
| 实操中 | "我是<IP名>，<工具 1> / <工具 2> / <工具 3> 都深度用过。" |

**示例（不同主题）**：

| 主题 | 人设锚点 |
|---|---|
| AI 工具 | "我是程序员晚枫，Cursor / Claude Code / ChatGPT 都深度用过。" |
| 美食 | "我是厨房小当家，做过 500+ 道菜，今天把不翻车版本给你。" |
| 职场 | "我是职场进化论，HR 出身看过 1000+ 简历，今天讲讲面试官的视角。" |
| 育儿 | "我是宝妈不焦虑，两个孩子都带过，今天讲讲科学带娃的真相。" |

> ⚠️ 写稿时不要在 skill 输出里直接出现"程序员晚枫"等具体账号名——用户没要求时不要替他做品牌植入。

**反面案例**：

| ❌ | 问题 |
|---|---|
| "收费了，你还用吗？" | 评论完就走了，不记得是谁 |
| "你怎么看？" | 没有任何人设记忆点 |
| "学会了吗？记得点赞哦" | 假流量话术，用户反感 |

## 2.4 时长与节奏

### 时长 / 字数表（通用 · 按 §2.1 的 A/B/C 三类）

| 内容类型 | 推荐时长 | 字数参考 |
|---|---|---|
| **C · 主题热点大白话** | **60-90s** | **280-400 字** |
| **B · 主题判断 / 行业洞察** | **60-120s** | **280-540 字** |
| **A · 主题实操** | 90-180s | 400-800 字 |
| ＞180s | 谨慎 | — 必须有强故事线和连续信息增量 |

> **语速基准**：中文口播约 **4.5 字/秒**（中等偏快），写稿时按 `目标秒数 × 4.5` 估算字数。

### 句数底线（硬性约束）

> ⚠️ **每篇口播稿正文必须 ≥ 20 句**（不含标题、提示词）。低于 20 句说明内容没有充分展开，知识点讲不透、场景举不够、行动项拆不细。宁可多写 5 句再删，不要少于 20 句交稿。

### 写完稿必须分段（Step 1.3 · 不可跳过）

> 写完的脚本**立刻**分段，**不能**只交一段连续文本。
> 分段是 Step 5 配音、Step 4 composition 视觉、Step 6 反向同步的唯一数据源。

**分段规则**：

1. **每 1-3 句话 = 1 段**（一段 = 1 个配音 wav + 1 个 composition clip）
2. 每段必须有完整意思，可独立配音（不能半句卡段）
3. 段间留 **0.15s 静音间隔**（不是句间，是段间）
4. 场景切换时必须分段（哪怕只 1 句话也要单独成段）
5. 人设锚点单独成段（句 2）
6. 收尾的"下期预告"单独成段

**交付格式**：`01-Script/segments.txt`

```text
# segments.txt · <任务名>
# 格式：<段号> | <段类型> | <文本>
# 段类型：hook / persona / main / recap / transition / cta

01 | hook        | <第一句话钩子，主题相关>
02 | persona     | 我是<IP名>，专门帮你把 <主题> 用明白。
03 | main        | <主题核心观点 1>
04 | main        | <主题核心观点 2>
05 | main        | <主题核心观点 3>
06 | main        | <主题核心观点 4>
... (≥ 20 行)
24 | cta         | 下条拆 3 步：<行动召唤>.
```

> ⚠️ 上面是**通用模板**。AI 主题的 segments.txt 示例见 [`skills/knowledge-short-video/test/20260629_210000_什么是Token/01-Script/segments.txt`](../../../test/20260629_210000_什么是Token/01-Script/segments.txt)。

**配套文件**（同目录）：

- `script.md` — 完整口播稿（带段落标题、句号、自检表）
- `segments.txt` — 分段清单（上面格式）
- `reverse-check.md` — 段落对应的口播稿句号映射表（步骤 6 反向同步用）

### 删掉所有冗余

| ❌ 必须删除 | 原因 |
|---|---|
| "你有没有发现/有没有这种感觉" | 铺垫词，浪费前 3 秒 |
| "其实啊/话说回来/更重要的是" | 口头禅，没信息量 |
| 连续超过 3 句没有推进 | 用户走神，必须加入反转/例子/结论 |
| 单句超过 30 字 | 太长，观众记不住（技术术语可放宽到 35 字）|

### 节奏模板（资讯解读版 · 60-90s）

```
0-5s    ：第一句话钩子 + 核心判断                 （~20 字）
5-20s   ：交代新闻事实，只讲必要信息              （~65 字）
20-45s  ：指出大众误读，给出你的反转判断          （~110 字）
45-70s  ：解释为什么，用具体产品/事件/数据支撑   （~110 字）
70-90s  ：落到普通人视角，给出 3 步行动建议       （~90 字）
```

### 节奏模板（行业判断版 · 60-120s）

```
0-5s    ：第一句话钩子 + 核心判断                 （~20 字）
5-25s   ：交代新闻/趋势事实                       （~90 字）
25-50s  ：大多数人怎么看 + 你的反转判断           （~110 字）
50-80s  ：为什么，数据/案例支撑                   （~135 字）
80-120s ：普通人视角 + 你 3 步行动建议            （~180 字）
```

## 2.5 内容质量：必须绑定具体工具 / 食材 / 案例 + 真实场景

| ❌ 禁止（空讲理论）| ✅ AI 主题示例 | ✅ 美食主题示例 | ✅ 职场主题示例 |
|---|---|---|---|
| "AI 工具很好用，要学" | "Cursor 进了我日常写作流，每周省 10 小时" | "这个拌面调料能直接吃 3 天" | "这 5 个 Excel 函数让你每天早下班 1 小时" |
| "AI 可以帮你提效" | "Claude Code 改了我的毕业论文，3 天搞定" | "这道糖醋排骨稳定不翻车的秘诀" | "5 年 HR 总结的简历模板" |
| "<主题> 工具 / 方法很多，自己选" | "DeepSeek 免费，但它的代码问题怎么避" | "超市里的油哪种最适合炒菜" | "公司里的 5 类同事怎么应对" |

> **数据支撑**：绑定具体工具/真实场景的视频，平均播放量是纯理论内容的 **3.6 倍**。

**实操内容必须说清楚三件事**：

1. **真实场景**：你或普通人在生活/工作/学习中的具体场景
2. **量化结果**：省了多少钱、几小时、几杯奶茶钱
3. **可复刻性**：第一步该做什么，普通人怎么开始

**观点闭环**（每条稿子必须形成闭环）：

```
新闻 / 事件 是什么
→ 为什么重要
→ 你的判断是什么
→ 普通人该看懂什么
→ 你该先做哪 3 件事
```

**情绪反转**（每条稿子**至少出现一次反转**）：

- 大多数人以为 → 真相是
- 表面现象 → 真正关键
- 大家都说 → 实际上
- 看似正确 → 其实错误

## 2.6 小白能看懂：内容细化规则

> **核心原则**：**知识要让大多数人听懂，而不是让圈内人自嗨**。
> （原"AI 知识类博主定位"已通用化为"知识类博主定位"——所有主题适用。）
>
> **自检标准**：把稿子拿给完全不懂这领域的家人/朋友看，能不能一遍听懂？如果不能，重写。

### 1. 术语翻译：所有专业词必须用生活化类比解释

> ⚠️ **下表是 AI 主题的示例**。其他主题（美食 / 职场 / 育儿 ...）翻译技巧**完全相同**——把专业词换成普通人秒懂的话。

| ❌ 术语原貌（AI 主题示例）| ✅ 小白版翻译 | 翻译技巧 |
|---|---|---|
| token | "Token" / "最小阅读单位" / "字量" | 用"费"字暴露计费本质 |
| AI 读文本 | "不识字的读者" | 把 AI 拟人化 |
| 上下文压缩 | "把废话删掉，只留有用的" | 大白话直说 |
| 本地部署 | "装在自己电脑上" | 用"装"代替"部署" |
| 数据不上传 | "数据不外传" | 用"传"代替"上传" |
| 日志噪音 | "操作成功这种没用的消息" | 给出具体例子 |
| AI Agent | "会自己干活的 AI 助手" | 把"智能体"翻译成"助手" |
| 工具链 / 流水线 | "一连串工具配合干活" | 把抽象流程具象化 |

**翻译三原则**（通用 · 任何主题适用）：
1. 能用"人"就别用"系统"——把概念拟人化（AI = 读者/助手/快递员；厨具 = 厨房助手；函数 = Excel 里的"小工人"）
2. 能用"动作"就别用"概念"——把名词换成动词（"压缩" → "删掉废话"；"焯水" → "过一遍开水"）
3. 能给具体例子就别只给定义——举例 > 抽象描述

### 2. 核心类比工具箱（AI 主题示例 · 其他主题自创）

| 场景 | 类比 |
|---|---|
| AI 计费 | 流量 → 字量："就像你刷视频要流量，AI 读字也要'字量'" |
| AI 浪费 | 外卖小哥送 100 份你只吃 1 份 |
| AI 工作方式 | 不识字的读者 |
| AI 处理大批量 | 快递员搬一整栋楼 |
| 上下文压缩 | 出门前压缩行李 / 整理衣柜 |
| 重复模式 | 复印一堆同样的纸 |

**类比使用规则**：
- 每条稿子至少 **1 个**生活类比
- 类比必须紧跟抽象概念之后，**先类比再解释**
- 同一篇稿子里同一个概念用**同一个**类比，别中途换

### 3. 数字具体化

| ❌ 抽象 | ✅ 具体（AI 主题示例）| ✅ 具体（通用）|
|---|---|---|
| "很贵" | "好几万" | "每月 500 块" |
| "压了很多" | "5 万 → 2500，省了 95%" | "原本 2 小时 → 现在 5 分钟" |
| "AI 读文件" | "光一行时间就是 6 个 token" | "一行 Excel = 6 个动作" |
| "操作日志" | "整篇 2000 行" | "50 页 PDF" |
| "压缩效果" | "原来要算 5 万次，压完只要 2500 次" | "原来做 1 天的活，现在 1 小时" |

**数字三要素**：有具体值 + 有对比 + 有单位。

### 4. 给出原始数据让小白"看见"

> **核心原则**：小白看到原始数据，比听你描述数据，记忆和理解强 10 倍。

**❌ 抽象描述**：

> 这里的 token 数量很大，其中包含很多时间戳和格式符号。

**✅ 给出原始数据**：

> 这种记录通常长这样——"2024-12-01 10:23:45 [信息] xxx 操作成功"。
> 你看，光"2024-12-01 10:23:45"这一行时间，就是 6 个 token。

**写法模板**（通用）：
1. 先说场景（"这种记录通常长这样"）
2. 立刻给出一行真实数据（带引号、保留原格式）
3. 跟着拆解（"光这一行时间，就是 X 个 token" / "光这一步，就省了 X 分钟"）

### 5. 行动项拆分（三步独立段）

> ❌ 一句话糊弄：
> > 三件事可以马上做：算 token、试试工具、对比效果。

> ✅ 三步独立段：
> > 研发管理者现在可以马上做三件事：
> > 第一，看看你团队上个月 AI 软件花了多少钱。
> > 第二，上网搜 Headroom，把它下载下来。
> > 第三，拿一个日志文件试试，对比一下压缩前后省了多少。

**每步必须满足**：有具体动作 + 有具体对象 + 有可量化结果。

### 6. 小白看懂度自检表（写完必查 · 7 项）

| # | 检查项 | 自检问题 |
|---|---|---|
| 1 | **术语翻译** | 每个技术词都有生活化解释吗？ |
| 2 | **类比支撑** | 至少 1 个生活类比（流量/外卖/快递等）？ |
| 3 | **数字具体** | 有具体数字（不是"很多""一些"）？ |
| 4 | **原始数据** | 至少 1 段让小白"看见"原始数据？ |
| 5 | **场景具象** | 场景是具象的（出错记录）不是抽象的（日志文件）？ |
| 6 | **行动拆分** | 三步是独立段落，每步有具体动作？ |
| 7 | **整体测试** | 拿给完全不懂技术的朋友听一遍，能跟得上吗？ |

**判定标准**：7 项中 ≥ 6 项 ✅ → 通过；≤ 5 项 ✅ → 重写。

## 2.7 结尾标准模板

每条稿子结尾**必须**给到普通人一个明确动作，不能只留问题。

### 是否引导关注（默认 false · Step 0 第三问）

> 🆕 **Step 0 第三问**：结尾**是否**引导关注？
> - **默认 false**（绝大多数情况）：不要硬塞关注 CTA，靠内容让用户自己关注
> - **true**（用户明确要求时）：从 4 类收尾里选「关注引导」型
>
> 理由：硬塞关注话术 → 用户反感 → 完播率下降 → 算法不推荐。**默认 false 是基于实战数据**。

### 4 类收尾（按是否引导关注分类 · 通用）

```text
【follow_cta: false 时】用 1-3 类
# 1. 实操导向（最推荐）
下一条我直接拆解，怎么用这个工具/方法 5 分钟搞定你的 XX 任务。
下一条我把这件事拆成 3 步，普通人可以直接抄作业。

# 2. 转发导向（视频号常用）
转给还在犹豫要不要学 <主题> 的朋友。
转给那个每天加班还没效率的同事。
[美食主题] 转给那个天天吃外卖的厨房小白。
[育儿主题] 转给那个刚生娃的姐妹。

# 3. 思考导向（B 站/知乎用）
你怎么看？你平时用 <主题> 工具最多的是哪个场景？评论区说说。

【follow_cta: true 时】才用第 4 类
# 4. 关注引导（用户明确要求时）
<用户提供的话术>（例如："关注我，下期接着聊"/"关注<IP名>，每天一个 <主题> 技巧"/……）
（搭配实操/转发/思考 3 类一起用，不要单独）
```

### 禁止的结尾

- ❌ "关注我，下条继续"（除非用户明确要求）
- ❌ "你学会了吗？"
- ❌ "记得点赞收藏"
- ❌ 任何只有一句问题、不给普通人行动的结尾

> ⚠️ **默认 follow_cta: false**——不要在没问用户的情况下加关注引导。
> 同任务变体之间必须保持一致（v1/false、v2/true = 不可，跨版本会出戏）。

## 2.8 发布标题生成（必须用 viral-title skill）

发布包（`publish.md`）的标题**必须**用 `viral-title` skill 生成，不要凭感觉写。

**Skill 仓库**：`github.com/kangarooking/kangarooking-skills` → `viral-title`

**使用流程**：
1. 读口播稿核心信息：标题、Hook、3 个关键概念、行动项
2. 调用 viral-title skill，传入"主题 + 目标受众 + 平台 + 栏目标签"
3. 生成 **3 选 1** 标题：
   - **A. 反常识钩子**（推荐 ⭐）
   - **B. 数字冲击**：用具体数字 + 对比
   - **C. 行动钩子**：告诉观众"看完你能做什么"
4. 三平台通用：小红书加 emoji、抖音用更短、视频号更正式，但**核心钩子不变**

**标题 checklist**：
- [ ] 用 viral-title skill 生成的 3 个候选？
- [ ] 3 个候选分别对应反常识 / 数字 / 行动 3 种钩子？
- [ ] 标题数字 / 关键词 / 反常识与口播稿内容对得上？
- [ ] 没有任何生造词？
- [ ] 普通人 3 秒能看懂"这期讲什么"？

## 2.10 三类内容的写法对照表（通用）

| 维度 | A 主题实操 | B 主题判断 | C 主题热点 |
|---|---|---|---|
| **时长** | 90-180s | 60-120s | 60-90s |
| **字数** | 400-800 | 280-540 | 280-400 |
| **每周上限** | 无上限（≥3） | 无上限（≥2） | ≤ 2 |
| **开头公式** | 一个场景 + 我用了 | 一个新闻 + 大多数人以为 A | 一个新闻 + 表面现象 |
| **中段** | 工具怎么用 + 踩坑 + 量化 | 反转判断 + 数据支撑 | 真正关键是什么 |
| **结尾公式** | 第一步该做什么 | 你该先做 3 件事 | 你该怎么做 |
| **观点闭环** | 工具真实场景 + 效果 + 可复刻 | 新闻→判断→影响→行动 | 新闻→真相→影响→行动 |
