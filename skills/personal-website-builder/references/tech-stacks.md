### React / Next.js 反问

如果用户提到 React 或 Next.js，反问：

```
你想用 React / Next.js 做什么类型的网站？
- 个人博客 → 推荐 Astro + React（更轻量）
- 知识库 → 推荐 Next.js + MDX（生态丰富）
- AI 导航 → 仍推荐 Vue 3（你确定要用 React 吗？）
- 作品集 / 简历 → 纯 HTML 就够了，React 反而重

确认是用 Next.js 吗？还是改用推荐方案？
```

### 模糊描述反问

```
想更精准推荐，能告诉我：
1. 大概多少篇内容？（决定要不要框架）
2. 主要是中文还是英文？
3. 想要深色模式 / 评论系统 / 搜索等高级功能吗？
```

## 混合类型

如果用户说"博客 + 作品集"：

```

```

## 框架 vs 静态 HTML 的判断

**用框架的条件**（满足任一）：
- 内容会持续增长（>10 篇）
- 需要搜索 / 分类 / 标签
- 想要评论 / RSS / 暗黑模式

**用纯 HTML 的条件**（满足任一）：
- 内容固定，少量修改
- 想部署到任意静态托管
- 不想跑 `npm install`
