# 晚枫开源管家 · opensource-housekeeper

> SkillHub 安装：https://skillhub.cn/skills/user_bf8c5b73/wanfeng-opensource-housekeeper

给**完全不懂技术的人**做开源项目陪跑：从「听说这个项目很厉害」到「我真的用起来了」全程带路。

## 能做什么

- **每次打开先问一句「今天想找哪方面的 AI 项目？」**（v2.1.0 新增）：用户只要回一个方向，
  我就去**国内外所有主流开源平台**把项目找出来、去重筛好、讲成人话
  （GitHub / GitLab / Codeberg / Bitbucket / Hugging Face + 国内 AtomGit / Gitee / GitCode / GitLink / CODING / OSChina / ModelScope / OpenI / AI Studio 等，
  完整清单见 [references/platform-coverage.md](references/platform-coverage.md)）
- **学用开源项目（主打）**：找到想学的项目 → 用人话讲清它是干嘛的 → 拉下来装好依赖跑起来 → 带你读懂结构 → 改一处验证 → 真正用出效果
- **发布自己的项目**：把本地项目（代码、纯文档、图片集、电子书、笔记都算）上架到 GitHub / AtomGit / Gitee
- **整理知识库**：把项目整理成结构化的仓库 Wiki 文档

所有术语都有大白话解释，所有命令先讲原理再执行，每一步失败都有人话兜底。

> 记一句：**「找」看全平台，「发」看三家**。只有找项目时才需要全平台覆盖，发布仍以三平台为主推。

## 怎么用

纯对话式 skill：安装后直接打开，它会先问你「今天想找哪方面的 AI 项目？」——回个数字就行，
剩下的找、筛、装、跑、改都由它做完。也可以直接说——

- 「今天想找点 AI 项目，你帮我找找」
- 「最近有什么好用的本地大模型 / AI 画图开源项目？」
- 「这个项目很火，帮我装上跑起来，顺便教会我用」
- 「把我这个文件夹推到 GitHub」
- 「看不懂这个仓库，带我读一遍」

完整流程与规则见 [SKILL.md](SKILL.md)，平台清单见 [references/platform-coverage.md](references/platform-coverage.md)。
