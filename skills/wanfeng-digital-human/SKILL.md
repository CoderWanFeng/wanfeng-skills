# 晚枫数字人

把一段你的视频、一张你的照片，变成一条会说话的数字人短片：画面里是你，声音是你的，说的是你写的那句话，还带一条字幕。长度 4–10 秒。

## 你要做的事，只有三步

| 步 | 你做什么 | 花多久 |
|---|---|---|
| 1 | 给我一段你自己的视频（10 秒以上最好），或者一张正脸照片 | 现成的就行 |
| 2 | 告诉我一句想说的话，40 字以内 | 1 分钟 |
| 3 | 看一眼费用，确认；等 1–3 分钟拿走视频和字幕 | 3 分钟 |

视频不到 10 秒也能做，只是我会再要你一段 15–20 秒的录音，用来学你说话的声音。

## 要花多少钱

| 项目 | 金额 | 说明 |
|---|---|---|
| 学会你的声音 | 9.9 元 | 一次性，以后做多少条都免费复用 |
| 生成一条视频 | 约 2 元 | 480P 约 1.1 元 |
| 合计 | 第一次约 12 元，之后每条约 2 元 | 先只做声音、你听过满意了再做画面，不会白花钱 |

## 要开通什么

一个 MiniMax 平台的账号。四步，五六分钟：

1. 打开 `platform.minimaxi.com`，注册并登录（免费）
2. 账户管理 → 实名认证（学你说话的声音必须要）
3. 账户管理 → 余额 → 充值，先充 20–30 元，够做两条
4. 账户管理 → 接口密钥 → 创建 API Key，拿到那串字符

拿到后直接发给我，我存到本机，不外传、之后也不再显示。

## 做不到的

- 30 秒以上的长视频、多段拼接、插入其他画面 —— 用「晚枫数字人 Pro」
- 逐帧对齐的口型 —— 能做到大致同步
- 换背景、换衣服 —— 由你的素材决定

# 执行说明（给 AI 看的，不必念给用户）

## 怎么对话

- **一轮只问一件事。** 不要一次列出"视频、文案、录音"，用户会不知道先动哪个。
- **拿到就检查，用一句话给结果。** 不念技术字段、不说工具名。
- **花钱前报数，等明确同意。** 没回应就停在那里。
- **不说术语。** 不出现 `.env`、参数名、命令名这类词；说"我帮你存好了"就够了。

## 三步流程

**第 1 步 · 素材。** 拿到路径立刻检查，把结果翻成一句话：

```bash
cd <技能目录> && PY=python3
$PY scripts/clip.py --face "<用户给的路径>" --inspect
```

| 检查结果 | 这么说 |
|---|---|
| 视频 10 秒以上 | 「收到，8.2 秒，竖屏，够用。声音我直接从这段视频里学，不用另外录音。」 |
| 视频不足 10 秒 | 「收到，6.8 秒，画面没问题。但学声音至少要 10 秒，等下我再跟你要一段录音。」 |
| 照片 | 「照片可以，但不会有说话时的表情和头动；而且照片没声音，要另外给一段录音。」 |
| 没给素材 | 三条拍摄要点：正脸看镜头、光线均匀别背光、背景干净、画面里别有别人 |

**第 2 步 · 台词。** 按 4 字/秒估时长，只回一个结论：「27 字，读出来约 6 秒，正合适。」超过 40 字就让用户删到 40 字以内。台词里混进 `[A]`、`[[BROLL]]` 这类标记要删掉，否则会被念出来。

**第 3 步 · 报价，等同意。** 先跑一次不花钱的预演：

```bash
$PY scripts/clip.py --face <素材> --text "<台词>"
```

> 这条 7 秒，约 11.74 元：学会你的声音 9.9 元（一次性）+ 台词 0.02 元 + 画面 1.82 元。
> 建议先只做声音（约 9.92 元），你听过像不像自己，再做画面。**要开始吗？**

用户明确说「开始」之后，先只做声音：

```bash
$PY scripts/clip.py --face <素材> --text "<台词>" --run --stop-at voice
```

把试听音频交到用户手上（`present_files`），问一句「像不像」。满意再出画面：

```bash
$PY scripts/clip.py --face <素材> --text "<台词>" --run --voice-id <上一步的 voice_id>
```

**`--voice-id` 必须带。** 不带会重新学一遍声音，等于再付 9.9 元。

## 关于 Key

开工前先查一次，零费用：

```bash
$PY scripts/clip.py --check-key
```

三种结果：`未配置`（还没开通，走那四步）、`Key 类型不对`（拿的是订阅套餐的 Key，要重新建）、`已配置`（可以开工；若提示"只在这次有效"，顺手存成长期配置）。

没配就按「要开通什么」那四步讲，**一次给一步**，同时把素材要过来，两条线并行。用户把 Key 发来后，你帮忙写进技能目录下的配置文件，只回一句「已经存好，只在本机，不会外传」——不要把配置路径和变量名念给用户。

## 红线

| # | 规则 | 原因 |
|---|---|---|
| 1 | 不加 `--run` 就绝不加 | 加了就真花钱 |
| 2 | 每次 `--run` 前报价格、等明确同意 | 9.9 元不是小钱 |
| 3 | 第二次跑必须带 `--voice-id` | 不带等于重复付费 |
| 4 | 视频不足 10 秒不要硬上，先要录音或改用平台声音 | 硬上会失败，白跑 |
| 5 | 不显示 Key、不外传用户的素材 | 隐私 |
| 6 | 报错先看 `references/troubleshooting.md`，别盲目重跑 | 重跑会重复计费 |
