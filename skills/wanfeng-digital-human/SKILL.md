# 晚枫数字人

把一段你的视频、一张你的照片，变成一条 4–10 秒的数字人短片。画面里的你在说话，那句台词由模型念出来。

**这条路只有一个出口：软件积分。** 不填密钥、不绑支付、不产生任何费用，用完只扣账号里的积分。想用自己的声音、想做长视频，那是 Pro 的事。

## 一图看懂流程

![晚枫数字人 · 执行流总览](assets/execution-flow.png)

> 输入是「一段你的视频或一张正脸照片 + 一句台词」，出口是「一条 4–10 秒的数字人短片」。
> 中间八步分三段：收素材 / 出片子 / 交付，其中换原声和挂字幕是可选动作。

图由 `scripts/make_flow_diagram.py` 生成，改完文案重跑脚本即可（Pillow 自绘，1080 宽）。

## 你要做的事，只有三步

| 步 | 你做什么 | 花多久 |
|---|---|---|
| 1 | 给我一段你自己的视频（3 秒以上就行），或者一张正脸照片 | 现成的就行 |
| 2 | 告诉我一句想说的话，30 字以内 | 1 分钟 |
| 3 | 等 1–2 分钟，拿走视频 | 2 分钟 |

全程不花钱。你要付出的只有时间，和账号里本来就有的积分。

## 声音：有配音，但不是你的音色

**生成出来就是带声音的**，不用另外配音。但声音有三种来路，差别要讲清楚：

| 方案 | 怎么做 | 听到的是谁 | 口型 | 花钱吗 |
|---|---|---|---|---|
| **默认**：模型念台词 | 生成时只给文本台词 | 通用音色，不是用户本人 | 大致同步 | 0，含在积分里 |
| **换原声**：事后贴自己的录音 | 用户录同一句台词 → 本机贴上去 | **用户自己** | 只对齐时长，不逐字同步 | 0，本机 ffmpeg |
| **克隆音色**：一句话克隆 | —— | —— | —— | 这条线**不做**，走 Pro |

三条边界，别越：

1. **生成那一刻，声音不能指定**。只能给台词文本，由软件念；传一段音频进去驱动口型，这条线做不到。
2. **换原声是「贴」，不是「对口型」**。画面说话节奏是按模型自己的读法生成的，换成用户的录音后，嘴型会和字错位——台词越短越不明显，所以这条线建议 ≤15 字再换原声。
3. **想一次成型、声音就是本人** → 走 Pro。别在免费线上反复试，那是拿积分换失望。

## 能做到 / 做不到

| 能做到 | 做不到 |
|---|---|
| 4–10 秒的短片，画面里是你 | 30 秒以上的长视频、多段拼接 |
| 一句台词，模型念出来（自带配音） | 上传一段音频让画面按它对口型 |
| 事后把成片换成自己的原声 | 克隆你的音色（这条线不做声音克隆） |
| 竖屏、横屏、方屏 | 换背景、换衣服 |
| 从视频里挑一张正脸当基准 | 逐帧对齐的口型（只能做到大致同步） |
| 视频自带字幕文件（可选） | 保证每帧都像你本人 |

**如果你要的是「我的声音 + 我的脸 + 一条完整口播」**，直接说「用晚枫数字人 Pro」，别在这条线上耗。

# 执行说明（给 AI 看的，不必念给用户）

## 怎么对话

- **一轮只问一件事。** 不要一次列出「视频、文案、尺寸」，用户会不知道先动哪个。
- **拿到就检查，用一句话给结果。** 不念技术字段、不说工具名、不提任何平台或品牌。
- **零成本这条必须说清。** 用户问价时，答案是「不花钱，只用你账号里的积分」，不要补充任何第三方服务。
- **不说术语。** 不出现参数名、命令名、配置文件这类词；说「我帮你处理好了」就够了。

## 第 1 步 · 素材

拿到路径先体检，用一句话反馈：

```bash
cd <技能目录> && python3 scripts/prep.py inspect --face "<用户给的路径>"
```

| 结果 | 这么说 |
|---|---|
| 视频 ≥3 秒、有正脸 | 「收到，6.8 秒，竖屏，够用。我从这段里挑一张正脸当基准。」 |
| 视频 <3 秒 | 「这段有点短，画面会不够稳。能再给一段 3 秒以上的吗？没有的话我先用这张照片试。」 |
| 照片 | 「照片可以，但说话时头不会动，看起来更像一张会动的照片。有视频的话效果更好。」 |
| 没给素材 | 三条拍摄要点：正脸看镜头、光线均匀别背光、背景干净、画面里别有别人 |

## 第 2 步 · 抽参考帧（这一步决定像不像你）

从视频里抽 3 张候选帧，挑「睁眼、嘴闭合、正脸」的那张：

```bash
python3 scripts/prep.py frames --face "<素材>" --out output/frames
```

产出 3 张候选图 + 一张拼图。**自己看一眼再选**，别默认第一张——抽到张嘴或闭眼的帧，成片会显得表情怪。选定后导出竖屏参考图：

```bash
python3 scripts/prep.py crop --frame output/frames/frame_2.jpg --ratio 9:16 --out output/reference.jpg
```

把参考图给用户确认一句：「用这张当基准，可以吗？」

## 第 3 步 · 台词

按 4 字/秒估时长，只回一个结论：「27 字，读出来约 7 秒，正合适。」

- 超过 30 字：让用户删，或者拆成两条。
- 台词里混进 `[A]`、`[[BROLL]]` 这类标记要删掉，否则会被念出来。
- 用户没想好台词：给 3 条 15–25 字的候选，让他选一条改。

## 第 4 步 · 生成

用**这个软件自带的视频生成能力**：把参考图 + 台词交给它，参数固定为

| 项 | 值 | 为什么 |
|---|---|---|
| 时长 | 5 秒（台词长可到 8–10 秒） | 这条线只做短片，越长越容易崩 |
| 画幅 | 跟随参考图（竖屏素材就用竖屏） | 避免黑边和裁切 |
| 分辨率 | 720P 或软件默认档 | **没有 1080P 这一档，别报给用户** |

生成前把「产出、时长、画幅」给用户确认一遍。生成后**必看一遍成片**：脸有没有变形、口型是否大致对得上、有没有多余的手或字幕。

## 第 5 步 · 交付

给用户三样东西，说三句话：

1. 视频文件（直接给路径/预览）；
2. 「这句台词是模型念的，不是你的声音」——**不许说成「你的声音」**；
3. 「一共没花钱，只用了你账号里的积分」。

想要自己的声音怎么办：让用户**录一句同样的台词**发来，用

```bash
python3 scripts/prep.py audio --video <成片> --audio <录音> --out output/成片-原声.mp4
```

替换后必须说明：**这是把你的原声贴上去，口型只对齐时长，不保证逐字同步**。

## 可选 · 字幕

用户要字幕时，把台词和时间轴写成 srt 挂上去（软字幕，播放器可开关）：

```bash
python3 scripts/prep.py subtitle --video <成片> --srt <字幕.srt> --out output/成片-字幕.mp4
```

没有现成 srt 就按台词长度均分时间段，别声称「逐字对齐」。

## 红线

| # | 规则 | 原因 |
|---|---|---|
| 1 | 这条线**只用软件积分**，绝不调用任何需要付费的接口、绝不引导用户去开密钥 | 承诺了零成本就必须是零成本 |
| 2 | 不提任何平台名、模型名、积分之外的计费方式 | 用户只关心「花不花钱」 |
| 3 | 不把模型念的台词说成「你的声音」 | 那不是他的声音，是冒充 |
| 4 | 时长不超过 10 秒，超了就劝退到 Pro | 这条线做长片必崩 |
| 5 | 素材里出现别人，先问一句「这是你本人吗、有没有授权」 | 肖像权 |
| 6 | 生成失败先看 `references/troubleshooting.md`，别连续重试烧积分 | 积分也是成本 |
| 7 | 交付前必须自己看过成片 | 脸崩、多手、乱字幕都要拦下来 |
