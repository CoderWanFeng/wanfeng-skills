# 本地媒体工具

这条技能的引擎**只做本地媒体处理**，不含任何 API 客户端、不含计价、不含密钥。

画面由软件自带的积分能力生成，声音是模型自己念的，所以引擎里剩下的只有 ffmpeg 封装：

| 模块 | 作用 | 是否联网 |
| --- | --- | --- |
| `src/ai_digital_human/media/ffmpeg.py` | 探测、抽帧、归一化比例、拼接、替换音轨、转码 | 本地 |
| `src/ai_digital_human/media/placeholder.py` | 占位片生成（Pro 用，轻量版保留能力） | 本地 |
| `scripts/prep.py`（在技能根目录） | 对外入口：体检 / 抽参考帧 / 裁比例 / 贴音轨 / 挂字幕 | 本地 |

## 依赖

- `ffmpeg` / `ffprobe`（`brew install ffmpeg`，Windows 需加入 PATH）
- Python 3.9+，**不需要任何第三方包**

## 改代码

引擎源头是原项目的 `src/`。改逻辑先改源头，验证后再同步到本目录，不要在技能包里直接改，否则两边会分叉。

## 别在这里加接口

这条技能对外承诺「零成本」。如果哪天需要接付费接口，那是 Pro 的事，不要往这里加——一旦这里有客户端，红线（只用积分）就守不住了。
