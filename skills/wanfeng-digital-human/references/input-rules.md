# 素材与台词要求

## 一、形象素材

### 规格

| 项 | 视频 | 图片 |
|---|---|---|
| 时长 | 3 秒以上（越长越稳，超过 15 秒只取前面用） | — |
| 体积 | ≤ 50MB | ≤ 30MB |
| 分辨率 | 建议 ≥ 720×720 | 建议 ≥ 720×720 |
| 比例 | 竖拍横拍都行，输出跟随素材 | 同左 |
| 格式 | mp4 / mov（手机原片直接给） | jpg / png |

手机竖拍视频带 `rotation` 元数据，脚本会按实际观看尺寸处理，不用先转码。

### 怎么拍效果最好

| 要点 | 为什么 |
|---|---|
| 正脸看镜头，头部占画面 1/3 以上 | 占得越小，生成后越容易被拉糊 |
| 光线均匀，别背光 | 逆光会让脸部细节丢失，模型只能猜 |
| 背景干净、不动 | 背景越乱，重绘时越容易「长出」奇怪的东西 |
| 视频里自然说话 5–8 秒 | 模型需要看到说话时的口型和头动 |
| 不要滤镜、不要美颜过重 | 生成结果会继承素材的质感，过度磨皮会像假人 |
| 手不要入镜 | 半身取景最省事，生成式模型画手最容易翻车 |

### 参考帧怎么挑（最关键的一步）

从视频里抽 3 张候选，按这个顺序看：

1. **睁眼**——闭眼帧生成出来会一直是半睡状态；
2. **嘴闭合**——张嘴帧会把口型定在「正在说话」的那一帧，成片显得怪；
3. **正脸、不歪头**——侧脸会让脸型左右不对称；
4. **光线均匀**——半边脸在阴影里的帧，生成后会带一块暗斑。

三条里通常只有一张同时满足。宁可重抽，也别将就。

### 会出问题的情况

| 现象 | 原因 | 处理 |
|---|---|---|
| 生成的脸不太像 | 素材侧脸、低头、遮挡 | 换正脸正对镜头的帧 |
| 画面很糊 | 原素材分辨率低 | 换 720P 以上素材 |
| 手、手指变形 | 生成式模型的通病 | 素材里手不出镜 |
| 背景扭曲 | 背景有大量细节或文字 | 换纯色墙、虚化背景 |
| 多人出现在画面 | 模型不知道该跟谁 | 素材里只出现一个人 |

**照片能用，但效果差一档**：图片没有说话时的头部微动和表情变化，生成结果更像「一张会动的照片」。能拍视频就别用照片。

## 二、台词

### 字数换算

中文口播约 **240 字/分钟 ≈ 4 字/秒**。

| 想要时长 | 字数上限 | 实际产品时长 |
|---|---|---|
| 4 秒 | 16 字 | 4 秒（下限） |
| 6 秒 | 24 字 | 6 秒左右 |
| 8 秒 | 32 字 | 8 秒左右 |
| 10 秒 | 40 字 | 10 秒 |

这条线**建议写到 30 字以内**：越短越稳，脸崩的概率越低。超过 40 字直接劝退到 Pro。

### 写法

直接写你会说出口的话，不加旁白说明。

| 别这么写 | 改成 |
|---|---|
| `[A] 大家好，我是……` | `大家好，我是……` |
| `（镜头拉近）今天讲三个点` | `今天讲三个点` |
| `大家好，我是XX。今天给大家分享一个关于AI数字人的知识点，希望对你有所帮助` | `很多人以为做数字人要先学剪辑。其实你只要会说话就够了。` |

三条经验：

1. **一句话一个意思。** 10 秒塞不下两个论点。
2. **开头三个字就要有信息。** 「大家好我是……」这种开场在这条时长里是浪费。
3. **短句比长句好。** 逗号多的句子，模型念起来会赶。

### 会被念出来的东西

- `[A]` `[B]` `[[BROLL]]` 这类标记要删掉；
- 英文缩写容易被逐字母读（`API` → 「A-P-I」），想读成词就写中文；
- 数字建议写成汉字（`40` → `四十`），避免读法歧义；
- 括号里的注释也会被读出来。

## 三、素材检查清单

交给生成之前，三十秒自查：

- [ ] 素材里只有一个人，正脸，看镜头
- [ ] 视频 3 秒以上、50MB 以内
- [ ] 参考帧：睁眼、嘴闭合、正脸、光线均匀
- [ ] 台词 30 字以内，没有标记符号
- [ ] 想清楚了：这条是发竖屏还是横屏？
