# 出问题了看这里

先看报错属于哪一类，再动手。**不确定原因时不要直接重跑——失败的视频任务也可能计费。**

## 一、脚本直接拦下的（还没花钱）

| 提示 | 原因 | 怎么改 |
|---|---|---|
| `缺少 API Key` | 还没配 Key，**多数情况是用户压根没开通 MiniMax** | 先把 `references/onboarding.md` 的四步走完，别只说"缺密钥" |
| `Key 是订阅通道的` | 用了 `sk-cp-` 开头的 Key | 换成按量付费的 Key（`sk-` 开头） |
| `音源时长不合规` | 音源不足 10 秒 | 单独录一段 15–20 秒的，用 `--voice-source` 传 |
| `形象素材里没有音轨` | 视频静音 | 同上，或加 `--system-voice` |
| `文案太长` | 超过 40 字 | 按提示删字数，或拆成两条 |
| `文案太短` | 不足 8 字，合成后低于 2 秒 | 补到 10 字以上 |
| `文案里出现了文稿标记` | 混进了 `[A]` `[[BROLL]]` | 删掉，只留纯台词 |
| `参考视频只有 X 秒` | 素材短于 2 秒 | 换素材 |
| `图片 X MB 超过 30MB` | 体积超限 | 压缩后再传 |

## 二、接口返回的错误码

| 码 | 含义 | 动作 |
|---|---|---|
| `1004` `login fail` | 鉴权失败：Key 不是开放平台的，或已失效/被撤销 | 去「账户管理 → 接口密钥」重新建一个，把新 Key 交给技能 |
| `2049` `invalid api key` | Key 不对：多是 `sk-cp-` 订阅 Key，或复制时缺了字符 | 换按量付费的 Key；重新完整复制一次 |
| `2038` | 无音色复刻权限：账号没实名认证 | 账户管理 → 实名认证；急的话先用 `--system-voice` |
| 余额不足 / `insufficient balance` | 没充值或余额耗尽 | 账户管理 → 余额 → 充值；或 `--resolution 480P` 降单价 |
| `1002` | 限流 | 等 30 秒再跑，别并行跑多条 |
| `1026` / `1027` | 内容审核未通过 | 换说法或换素材，重试无用 |
| `2013` | 参数不合法 | 多半是参考音频/视频时长越界，看报错里的字段名 |

> 上面这几个码的**文案**以接口实际返回为准。凡是"鉴权 / 余额"类的报错，先跑一次 `--check-key` 确认 Key 存在，再检查是不是拿错了 Key 类型——这是最高频的原因，不是余额问题。

## 三、成片出来了但不对

### 声音不像本人

按可能性排序：

1. **音源太短或太杂。** 10 秒勉强够，但相似度低。15–20 秒安静环境录音明显更准。
2. **音源里有音乐或回声。** 克隆会把背景音也学进去。
3. **用了 `--system-voice`。** 成片里是平台内置音色，不是克隆结果。
4. **音源本身语气不自然**（在念稿）。克隆学的是音色 + 说话方式，念稿会得到一股"念稿感"。

### 嘴型对不上

生成式模型的固有偏差，不是配置问题。可以改善的：

- 台词分段越短越准，但这条片子只有一段，没有分段空间
- 避免爆破音密集的句子（"b p m f"连成串）
- 语速快的句子口型更容易糊，写文案时多用逗号断开

**期望管理**：能对到"大致同步"，做不到逐帧精确。真需要逐帧对齐，得用专门的 lip-sync 工具做后处理。

### 画面糊 / 脸不像

| 原因 | 处理 |
|---|---|
| 素材分辨率低 | 换 720P 以上 |
| 脸部占画面太小 | 重拍，头部占 1/3 以上 |
| 原素材逆光、欠曝 | 换正面均匀光的素材 |
| 原素材美颜过重 | 关掉美颜重拍——生成会继承那种"塑料感" |

### 成片比台词短

正常。脚本用 `tpad` 补末帧 + `trim` 对齐音频长度，最后成片长度 = 台词音频长度。如果请求了 6 秒但台词只有 4.2 秒，成片就是 4.2 秒，**但按 6 秒计费**。

### 画面比例不对 / 有黑边

脚本会按素材自身的比例归一化，理论上不该有黑边。如果出现：

- 素材本身带黑边（比如横屏内容塞进竖屏画布导出）→ 先裁掉黑边再给脚本
- 强制指定了不匹配的 `--ratio` → 去掉这个参数用 `auto`

## 四、任务卡住不动

视频任务通常 40–120 秒完成。超过 10 分钟还在等：

1. 先确认任务真的卡了，不是网络断了——看脚本打印的任务 ID，去开放平台控制台查
2. 默认超时 900 秒，可以用 `--timeout` 调整
3. 控制台显示成功但脚本没拿到链接：链接有时效，重新跑 `--run` 会重新生成（**会再计费**），不如去控制台下载原片，然后本地手动换音轨

## 五、想重跑但不想重复花钱

| 情况 | 做法 |
|---|---|
| 只想换台词 | 同一条命令改 `--text` 重跑，加 `--voice-id <上次的>` 跳过复刻 |
| 只想换形象素材 | 同上，音色复用 |
| 上次卡在生成画面 | 音色已克隆，用 `--voice-id` 复用，只重新生成画面 |

每次跑完的 `job.json` 里记了 `voice_id`、`task_id`、费用明细。重跑前先看它。
