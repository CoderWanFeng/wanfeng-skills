# 出问题了看这里

这条线不花钱，但**积分也是成本**。别连续重试，先判断属于哪一类。

## 一、素材阶段

| 现象 | 原因 | 怎么改 |
|---|---|---|
| 抽出来的三张全是侧脸 / 低头 | 原视频本身就没正对镜头 | 换一段正脸素材，或直接用照片 |
| 抽到的是闭眼 / 张嘴的帧 | 时间点没踩准 | 手动指定别的时间点再抽，或换一张 |
| `找不到素材` | 路径带空格没加引号，或文件不在 | 把完整路径复制过来，加双引号 |
| `读不到尺寸` | 文件损坏或格式特殊（如 HEIC 视频） | 先用系统工具转成 jpg / mp4 |
| 参考图裁完脸偏到一边 | 原图人不在画面中央 | 裁之前先手动裁一版居中的图再跑 |
| 竖屏素材裁成 9:16 后脸太大 / 太小 | 原图取景太近或太远 | 换一张取景适中的帧 |

## 二、生成阶段

| 现象 | 原因 | 怎么改 |
|---|---|---|
| 提示积分不足 | 账号积分用完了 | 等下一个发放周期，或改去做别的；**不要引导用户去付费** |
| 生成任务失败 / 超时 | 平台排队或参数不合规 | 换一张更清晰的参考图，把台词缩短，重试**一次**；再失败就换素材 |
| 生成了但时长比台词短 | 请求时长小于台词长度 | 把台词删短，或把时长档位调大一档 |
| 画面里有第二个人 / 多余的手 | 参考图里带了别人或手部 | 重新裁参考图，只留头肩 |
| 脸明显变形 | 参考图分辨率低、逆光、遮挡 | 换帧；优先挑光线均匀、正脸、嘴闭合的那张 |
| 生成的内容被拦 | 台词或画面触发了内容审核 | 换说法或换素材，**重试无用** |

## 三、成片阶段

### 声音不像本人

这条线**本来就不克隆声音**，成片里是模型念的通用音色。用户如果在意，两条路：

1. 自己录一句同样的台词，用 `scripts/prep.py audio` 贴回去（口型只对齐时长，不保证逐字同步）；
2. 想要真正克隆音色 → 让他改用「晚枫数字人-Pro」。

**不许把模型音色说成「你的声音」。**

### 嘴型对不上

生成式模型的固有偏差，这条线做不到逐帧音素对齐。能改善的：

- 台词短一点，一句话一个意思；
- 少用爆破音扎堆的句子（b p m f 连成一串）；
- 语速别太快，文案里多用逗号断开。

### 字幕对不上

- 软字幕是按写好的 srt 挂上去的，srt 的时间轴必须自己核过；
- 没有 srt 时按台词长度均分，只能说「大致对齐」，别说「逐字对齐」。

### 画面有黑边 / 比例不对

- 参考图本身带黑边 → 先裁掉再当参考；
- 生成时选的画幅和参考图不一致 → 跟随参考图，不要强行指定。

## 四、要不要重试

| 情况 | 建议 |
|---|---|
| 素材问题（糊、侧脸、多人） | **先换素材**，重试同样的输入只会得到同样的结果 |
| 台词太长 | 先删字，再生成 |
| 平台报错 / 超时 | 最多重试 1 次，中间隔一会儿 |
| 成片只是「不够像」 | 换一张参考帧通常比反复生成更有效 |

## 五、什么时候该劝退到 Pro

出现下面任意一条，直接告诉用户这条线做不了，别硬撑：

- 要 30 秒以上，或要分成多段再拼；
- 要自己的音色、要逐段情绪；
- 要口播 + 录屏 / 图表 / 动效混剪；
- 要批量做系列内容、要时间码表和字幕文件交付。

话术：「这条线只能出 4–10 秒的零成本短片，你要的这套得走 Pro，那边有完整的口播生产线。」
