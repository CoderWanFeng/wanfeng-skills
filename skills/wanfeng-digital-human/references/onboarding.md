# 开通 MiniMax：从零到拿到 Key

这个技能的所有能力（克隆音色、合成台词、生成画面）都跑在 MiniMax 开放平台上。**账号、实名、余额这三样缺一样，接口就会报错**——而且报错信息对小白毫无意义（`1004 login fail`、`2049 invalid api key`）。

所以这项检查要放在**对话最前面**，不要等到收完素材、报完价、准备生成时才说"你还没配密钥"。

## 一分钟版

| 步 | 做什么 | 大概耗时 |
|---|---|---|
| 1 | 打开 <https://platform.minimaxi.com>，手机号注册并登录 | 2 分钟 |
| 2 | 账户管理 → 实名认证（个人/企业） | 个人通常当天，个别要 1 个工作日 |
| 3 | 账户管理 → 余额 → 充值（建议先充 20–30 元） | 即时到账 |
| 4 | 账户管理 → 接口密钥 → 创建新的 API Key，复制出来 | 1 分钟 |

拿到的这串字符就是 API Key，只显示一次，**关掉页面就没法再看全文**，所以复制后先存到密码管理器或记事本。

## 详细说明

### 1. 注册

大陆站点 <https://platform.minimaxi.com>，海外站点是 `platform.minimax.io`。**两边的账号、Key、余额完全不通用**，人在国内就用大陆站点，否则会一直鉴权失败。

### 2. 实名认证（最容易卡住的一步）

不实名，音色复刻接口直接返回 `2038`——技能里"克隆自己的声音"这条路就断了。

- 个人认证：身份证 + 人脸，多数几分钟出结果
- 企业认证：要营业执照，通常要等审核

**只要走克隆音色就一定需要实名。** 只想先用内置声音试水（`--system-voice`），可以暂时跳过——成片里会是平台合成的声音。

### 3. 充值

按量付费账户要先有余额，否则调接口返回余额不足。

建议第一次充 **20–30 元**，够跑两条完整片段：

| 项 | 金额 |
|---|---|
| 音色复刻（一次性，之后可复用） | 9.90 元 |
| 台词合成 | 约 0.02 元 |
| 数字人画面 1080P | 约 1.8 元 / 条 |
| 数字人画面 480P | 约 1.1 元 / 条 |

> 具体单价以开放平台为准。技能里的报价是用 `references/cost.md` 的单价估的，不是账单。

### 4. 创建 API Key

账户管理 → 接口密钥 → **创建新的 API Key**，起个名字（比如 `digital-human`）方便以后区分，然后复制。

**别拿错 Key。** 平台上有两种：

| Key | 用在哪 | 这个技能能用吗 |
|---|---|---|
| 按量付费的 Key（`sk-` 开头） | 调所有模态模型 | 能 |
| 订阅通道的 Key（`sk-cp-` 开头，Coding/套餐） | 订阅套餐专用 | **不能**，调了报 `2049` |

很多人电脑里早就存着 `sk-cp-` 的 Key，一看"我有 Key"就直接填进去，然后一路报错——这是最高频的坑。

## 把 Key 交给技能

最省事：用户直接把 Key 发给助手，助手存到本机，只回一句「已经存好，只在本机，不会外传」。**之后不要再显示、不要念出配置文件路径。**

自己在命令行跑的话（非技术人员可跳过），把 Key 填进技能目录的配置文件，模板在 `templates/env.example`，只有一行要填：

```
MINIMAX_API_KEY=你复制的那串字符
```

**不要把 Key 写在聊天记录、文档或截图里。**

## 验证 Key 能用

不用花钱，跑一次预演就知道：

```bash
$PY scripts/clip.py --face 某个素材.mp4 --text "这是一句测试台词，大概二十个字。"
```

脚本末尾会检查 Key 是否存在。**更彻底的验证**是 `--run --stop-at voice`（约 9.92 元）——能出音频就说明 Key、实名、余额三样全通。

## 常见报错对照

| 报错 | 真实原因 | 去哪修 |
|---|---|---|
| `1004 login fail` | Key 不是开放平台的，或已失效 | 重新创建 API Key |
| `2049 invalid api key` | 用了 `sk-cp-` 订阅 Key，或 Key 复制缺字符 | 换成按量付费的 Key |
| `2038` | 未实名认证，无复刻权限 | 账户管理 → 实名认证 |
| 余额不足 / `insufficient balance` | 没充值或余额耗尽 | 账户管理 → 余额 → 充值 |
| `1002` | 调用太频繁 | 等 30 秒，别并行跑多条 |

## 给 Agent 的话术要点

- **先问"你有没有 MiniMax 账号"，不要假设对方有。**
- 缺 Key 时不要只说"缺密钥"——很多人没听过 MiniMax，不知道那是什么。要说清**这是什么、为什么需要、去哪弄、要花多久**。
- 实名认证可能要等审核，所以**建议用户先去注册实名，同时把素材要过来**，两条线并行，别让人干等。
- 一次只给一步，别把注册、实名、充值、建 Key 四件事一次性糊上去。
