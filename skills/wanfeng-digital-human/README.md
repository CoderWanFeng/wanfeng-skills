# 晚枫数字人

把一段你的视频、一张你的照片，变成一条会说话的数字人短片：画面里是你，声音是你的，说的是你写的那句话，还带一条字幕。长度 4–10 秒。

## 你要做的事，只有三步


| 步 | 你做什么                                                | 花多久     |
| ---- | --------------------------------------------------------- | ------------ |
| 1  | 给我一段你自己的视频（10 秒以上最好），或者一张正脸照片 | 现成的就行 |
| 2  | 告诉我一句想说的话，40 字以内                           | 1 分钟     |
| 3  | 看一眼费用，确认；等 1–3 分钟拿走视频和字幕            | 3 分钟     |

视频不到 10 秒也能做，只是需要再补一段 15–20 秒的录音，用来学你说话的声音。

## 要开通什么

一个 MiniMax 平台的账号，四步，五六分钟：

1. 打开 `platform.minimaxi.com`，注册并登录（免费）
2. 账户管理 → 实名认证（学你说话的声音必须要）
3. 账户管理 → 余额 → 充值，先充 20–30 元，够做两条
4. 账户管理 → 接口密钥 → 创建 API Key，拿到那串字符

拿到后交给技能，存在本机，不外传也不会再显示。

## 出来的片子是什么样

- **画面是 AI 按你的素材重新演绎的**：长相、衣着、背景来自你的素材，构图和口型会有轻微变化，这是生成式模型的特性。适合口播、种草、节日问候这类近景说话画面。
- **最短 4 秒**：台词只够 2 秒也按 4 秒计费。
- **口型大致同步**：做不到逐帧对齐，需要精确对齐要用专门的唇形工具后处理。

## 安全设计

不加 `--run` 就只体检报价，一个接口都不调。Agent 误触也不会产生费用。

## 命令行用法

```bash
python3 -c "import requests" || pip install -r requirements.txt   # 依赖只有 requests
python3 scripts/clip.py --check-key                               # 先看 Key 配好了没

python3 scripts/clip.py --face 我的视频.mp4 --text "一句话"                        # 体检 + 报价，零费用
python3 scripts/clip.py --face 我的视频.mp4 --text "一句话" --run --stop-at voice   # 只做声音
python3 scripts/clip.py --face 我的视频.mp4 --text "一句话" --run --voice-id <ID>   # 出画面
```

## 和完整版的区别


|      | 晚枫数字人               | 晚枫数字人 Pro            |
