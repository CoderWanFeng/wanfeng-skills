# 晚枫数字人

把一段你的视频、一张你的照片，变成一条 4–10 秒的数字人短片：画面里的你在说话，那句台词由模型念出来。

**完全零成本。** 只消耗这个软件自带的积分，不绑支付、不填密钥、不产生任何费用。

## 你要做的事，只有三步

| 步 | 你做什么 | 花多久 |
|---|---|---|
| 1 | 给我一段你自己的视频（3 秒以上就行），或者一张正脸照片 | 现成的就行 |
| 2 | 告诉我一句想说的话，30 字以内 | 1 分钟 |
| 3 | 等 1–2 分钟，拿走视频 | 2 分钟 |

不用注册别的账号，不用充值，不用填任何密钥。

## 它能做到 / 做不到

| 能做到 | 做不到 |
|---|---|
| 4–10 秒的短片，画面里是你 | 30 秒以上的长视频、多段拼接 |
| 一句台词，模型念出来 | 克隆你的音色（这条线不做声音克隆） |
| 竖屏、横屏、方屏 | 换背景、换衣服 |
| 从视频里挑一张正脸当基准 | 逐帧对齐的口型（只能做到大致同步） |
| 可选的字幕文件 | 保证每帧都像你本人 |

## 钱的事

**不花钱。** 生成只扣你账号里已有的积分，不产生任何 RMB 费用。

积分是软件自带的额度，按周期发放；够不够、用去哪了，在账号页面能看余额和消耗。积分用完时生成会暂停，等下个周期自动恢复——这条线没有「充值」这个概念，我也不会引导你去开通任何付费服务。

## 产出

```
output/
├── reference.jpg        从你视频里挑出来的参考帧
├── 成片.mp4             4–10 秒的数字人短片
└── 成片-原声.mp4         （可选）换成你自己录的台词
```

## 出来的片子是什么样

- **画面是 AI 按你的素材重新演绎的**：长相、衣着、背影来自你的素材，构图和口型会有轻微变化，这是生成式模型的特性。适合口播、种草、节日问候这类近景说话画面。
- **声音是模型的通用音色**：它会念出你写的那句话，但那不是你的嗓子。想用自己的声音，可以自己录一句同样的台词发来，我帮你贴回去——但口型只对齐时长，不保证逐字同步。
- **口型大致同步**：做不到逐帧对齐。

## 本地工具（零成本、不联网）

技能自带几个本地小工具，负责画面之外的脏活：

```bash
python3 scripts/prep.py check                                  # 看本机 ffmpeg 是否就绪
python3 scripts/prep.py inspect --face 我的视频.mp4            # 体检：时长/尺寸/有无音轨
python3 scripts/prep.py frames --face 我的视频.mp4 --out output/frames   # 抽 3 张候选参考帧
python3 scripts/prep.py crop --frame output/frames/frame_2.jpg --ratio 9:16 --out output/reference.jpg
python3 scripts/prep.py audio --video 成片.mp4 --audio 录音.m4a --out 成片-原声.mp4
python3 scripts/prep.py subtitle --video 成片.mp4 --srt 字幕.srt --out 成片-字幕.mp4
```

全部用本机 ffmpeg 完成，不调任何接口，不产生费用。
