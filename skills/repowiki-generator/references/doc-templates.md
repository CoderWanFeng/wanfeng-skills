# 文档结构模板

本文档给出 repowiki 中每一类 Markdown 文件的完整骨架模板。AI Agent 在生成 repowiki 时，应按照对应模板填充实际内容。

## 通用骨架

所有 repowiki 文档都遵循以下五段式骨架：

```markdown
# <文档标题>          ← H1，等于文件名（去 .md 后缀）

<cite>                  ← 自定义 HTML 块，引用源文件
**本文引用的文件**
- [path/to/file](file://path/to/file)
</cite>

## 目录                ← 必需章节，列出全部章节
1. [章节1](#章节1)
2. [章节2](#章节2)

## 章节1               ← 至少包含"简介"
（正文...）

## 章节2
（正文 + mermaid 图 + 图表来源）

**章节来源**            ← 每个章节末尾标注引用源
- [src/x.py](file://src/x.py#L1-L50)
```

## 模板裁剪原则

**每个项目不需要全部模板**：

| 项目类型 | 必选 | 可选 | 不选 |
|----------|------|------|------|
| Python 库（带 CLI） | 项目概述、快速入门、安装指南、命令行使用、核心功能详解、API 参考、开发者指南 | 批量处理 | GUI 使用、Web 界面使用 |
| Python 库（纯 API） | 项目概述、快速入门、安装指南、核心功能详解、API 参考、开发者指南 | 批量处理 | 命令行使用、GUI 使用、Web 界面使用 |
| Web 前端（React/Vue） | 项目概述、快速入门、安装指南、Web 界面使用、核心功能详解、API 参考、开发者指南 | — | 命令行使用、GUI 使用 |
| 后端服务（Go/Java） | 项目概述、快速入门、安装指南、命令行使用、API 参考、开发者指南 | 批量处理、核心功能详解 | GUI 使用、Web 界面使用 |
| CLI 工具 | 项目概述、快速入门、安装指南、命令行使用、核心功能详解、开发者指南 | 批量处理 | GUI 使用、Web 界面使用、API 参考（除非有 SDK） |
| 桌面 GUI 应用 | 项目概述、快速入门、安装指南、GUI 使用指南、核心功能详解、开发者指南 | 命令行使用、API 参考 | Web 界面使用、批量处理 |

**裁剪后保持结构一致**：即使只有 3 个顶层文档，每个文档仍须遵循五段式骨架（标题、cite、目录、章节、章节来源）。
