# 许可 · 晚枫自动剪vlog（mograph-vlog）

> 本 skill 已**开源**，采用 **MIT-0**（与 `mograph` / `mograph-pro` 一致）。

---

## 一、许可范围

- `SKILL.md`、`README.md`、`CHANGELOG.md`、`references/`、`scripts/` 等全部代码与文档：**MIT-0**，可自由使用、修改、商用、再分发，无需署名。
- 用本 skill 产出的成片、旁白稿、字幕、封面：版权归你所有，可商用、可发布、可再编辑。

## 二、素材与人物

- 本 skill **不自带任何视频、照片、字体、音乐或音色**，运行时只处理用户自己提供的素材。
- 用户随手拍里出现的他人、儿童、证件、投屏账号、门店内部，其肖像与隐私授权由使用者自行确认；技能只做选镜头与脱敏副本的提示，不代表已获授权。
- 示例与文档中不写真实姓名、账号、密钥。

## 三、声音与第三方服务

- 可选的本人克隆旁白由**用户已配置的 MiniMax 账号**生成，费用与调用发生在用户自己的账户上；API 密钥只在用户本机原配置处读取，不写入任务文件、渲染计划、日志或发布包。
- 未获授权或服务不可用时，退回环境声 / 音乐字幕版，不替换成公共音色，不自动开通付费服务。

## 四、第三方组件

渲染依赖 **Pillow** 与系统 **ffmpeg**（均为开源，遵循各自上游许可）。本 skill 不捆绑 Node、浏览器或任何云端渲染服务。
