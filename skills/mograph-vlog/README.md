# 晚枫自动剪vlog（mograph-vlog）

> **把随手拍的视频和照片放进一个目录，AI 自己看素材、选形式、写旁白、排转场和动效，先给你几秒样片，再出成片。**
> 不需要口播视频、不需要稿子、不需要字幕、不需要数字人，也不套固定版式和封面模板。
> 真人口播包装、每句弹卡、数字人混剪、固定底图封面在姊妹技能 **晚枫自动剪视频-Pro（`mograph-pro`）**，两条线互不影响。

---

## 一、30 秒看懂

| | 本 skill（vlog 线） | `mograph-pro`（口播 / 数字人线） |
|---|---|---|
| 要给什么 | 一个装随手拍视频、照片的目录 | 对镜头讲话的口播视频，或一份文稿 |
| 谁定形式 | AI 看完镜头自己选（时间线 / 蒙太奇 / 混剪 / 路线 / 环境声） | 晚枫固定整屏排版、圆形人头、步骤条 |
| 旁白 | AI 按镜头事实写第一人称口语 | 用已有口播原声，或按稿生成数字人 |
| 画面文字 | 与讲的内容语义相关即可，**不逐条念** | 说什么出什么，卡点对应每句话 |
| 封面 / 小绿书 | 不自动做，要就按本期素材另排 | 固定底图换字换 logo、成套贴图 |
| 工具 | 本地 Python + Pillow + ffmpeg | 同一套本地渲染，外加数字人引擎 |

## 二、装上以后怎么说人话

> 这些是我随手拍的视频和照片，帮我剪成一条 vlog。没有稿子，你先看素材选形式、写旁白，动画丰富一点，先给我看 5 秒。

其他常用说法：

- 「先看稿」→ 只出旁白稿，不渲染。
- 「先出 5 秒，我要看两个素材之间切换的效果」→ 只渲覆盖这 5 秒的镜头。
- 「用我的克隆声音配音，返回太慢就加速 1.2 倍」→ 复用已配置的 MiniMax 音色，本地一次性加速并实测时长回填。
- 「只要竖版，发视频号」→ 只交 9:16 一版，不产横版。

## 三、快速入口

```bash
# 1) 素材只读扫描：时长 / 旋转 / 音轨 / 色彩 + 抽帧接触表
python3 scripts/vlog_scan.py --assets <素材目录> --out <选题>/剪辑过程/vlog/检视

# 2) Agent 真看接触表后写镜头判断、第一人称旁白与 JSON 计划（脚本不猜故事）

# 3) 先校验计划，再按秒数出样片，最后才出成片
python3 scripts/vlog_render.py --plan <计划.json> --out <选题>/剪辑过程/vlog/样片.mp4 --validate-only
python3 scripts/vlog_render.py --plan <计划.json> --out <选题>/剪辑过程/vlog/样片.mp4 --preview-seconds 5
python3 scripts/vlog_render.py --plan <计划.json> --out <选题>/剪辑过程/vlog/母版.mp4
```

内置动效：`typewriter` 打字、`stamp` 贴纸弹入、`arrow` 描线箭头、`progress` 进度、`frame` 画框展开，外加照片轻推近；
内置转场：`cut`、`fade`、`wipeleft`、`slideleft`、`smoothup`、`circleopen`。
**这是基础入口，不是创意上限**——更复杂的路线另写任务级渲染器或用现有合适工具。

## 四、几条硬规则

1. **看素材再写正文**：拍摄时间是元数据不是证据，不根据文件名、酒店、菜品编地点、价格、对话或反馈。
2. **旁白不念花字**：屏幕上的字与讲的内容相关即可；同一句话不在贴纸和底部字幕各来一遍。
3. **加速只做一次**：原速合成 → `atempo` 一次 → `ffprobe` 实测 → 回填时间轴；放不下就改稿改镜头，不二次加速。
4. **画幅按平台单独排**：竖版 9:16、横版 16:9，禁止拉伸；竖拍素材要确认旋转元数据真的转正。
5. **原片只读、付费要授权**：不修改素材、不偷偷换音色、不自动开付费服务、不把未生成的东西说成已完成。

完整流程与契约见 [references/vlog-workflow.md](references/vlog-workflow.md)，规则出处见 [SKILL.md](SKILL.md)。

## 五、FAQ

**只有几段模糊随手拍也能剪？** 能。先扫描 + 抽帧，能用的镜头不够就明确说缺什么，而不是硬凑或杜撰。

**没配过克隆声音怎么办？** 先出音乐 + 环境声 + 画面文字版；要人声再按已配置的 MiniMax 音色生成，密钥不进任务文件与日志。

**能不能顺便做口播弹卡？** 不能，那是 `mograph-pro` 的路。本技能不进口播版式，免得把 vlog 剪成课程包装。

**脚本跑通就算成片了？** 不算。`--validate-only` 与单元测试只证明输入契约；成片要抽帧看图、听声、核秒数。
