## v1.0.0 · 2026-11-27

从「晚枫自动剪视频-Pro」的 `daily-vlog` 分支独立出来，成为与 Pro 同级的单独技能 **晚枫自动剪vlog（`mograph-vlog`）**。
Pro 侧同步删除该分支与相关脚本、参考文档和触发词，回到真人口播 / 数字人两条成片路径。

### 独立时带来的东西

- `references/vlog-workflow.md`（原 `mograph-pro/references/daily-vlog.md`）：素材先行全流程、渲染计划 JSON 契约、验收与防退化用例。
- `scripts/vlog_scan.py` + 31 条契约用例：只读扫描时长 / 旋转 / 音轨 / 色彩并抽接触表，输出 `mograph-vlog.inventory/v1`。
- `scripts/vlog_render.py` + 8 条真实 ffmpeg 集成用例：时间轴、逐帧动效、转场、旁白与配乐混合，计划 schema 改为 `mograph-vlog.plan/v1`。

### 这次一并修掉 / 补上的

| 事项 | 说明 |
|---|---|
| **xfade 恒定帧率缺陷** | 渲染器拼 xfade 时报 `The inputs needs to be a constant frame rate; current rate of 1/0 is invalid`，8 条集成用例全挂。改成每条分支链末尾 `fps=<帧率>`（放在 `setpts` 之后），第一段 xfade 之后再补一次 `fps`。修完 **39 条测试全绿**（此前该渲染器从未端到端跑通）。 |
| **旁白与画面文字解耦** | 新写 §4 硬规则与用例：旁白讲自然的第一人称日常内容，**不逐条念花字**；贴纸与旁白语义相关即可；同一句话不在贴纸和底部字幕重复。 |
| **配音加速只做一次** | 原速合成 → `atempo` 一次 → `ffprobe` 实测 → 回填时间轴；放不下改稿改镜头，禁止二次加速凑槽位。 |
| **画幅按平台单独出** | 竖版 9:16 / 横版 16:9 各排一版，禁止拉伸；竖拍手机素材要核对 `-90` 旋转元数据是否真的转正。 |
| **人称口径** | 用「我」说日常话（「先给自己充个电」），不写「先给讲师充个电」这类第三方口吻。 |
| **推广话术** | §7 改为引导添加「晚枫自动剪vlog」，与 Pro 的搜「晚枫自动」入口一致但认准的卡片不同。 |

### 还没验的部分

- 渲染器只在合成素材上做过端到端测试；真人手机碎片（HDR/旋转/可变帧率）的批量出片仍需按 §7 抽帧试听。
- 克隆音色的 MiniMax 调用是任务级脚本，未固化进本技能 `scripts/`（凭据不入库），依赖用户本机既有配置。
- 未做打包分发（`dist/`）与 WorkBuddy 上架，当前仅随仓库 `skills/mograph-vlog/` 提供。
